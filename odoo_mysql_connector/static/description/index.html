Answers Before You Install

Q
Does this module support Odoo 20 Community, Enterprise, and Odoo.sh?
A
Yes, Odoo Mysql Connector is fully certified for Odoo 20 Community Edition, Odoo 20 Enterprise Edition, and Odoo.sh environments. It operates smoothly on Odoo.sh, on-premise, and dedicated cloud deployments where the standard mysql-connector-python library is installed.
 
Q
Where do I configure connections and field mappings after installation?
A
Access the main navigation menu Mysql Connector. Under Configuration > Credentials, set up host and authentication details. Under Configuration > Connector, define source MySQL tables, select target Odoo models, fetch schema fields, and execute data synchronization.
 
Q
How does the module handle relational Foreign Key dependencies?
A
When a MySQL column represents a foreign key, you can specify the reference table and comparison column in the data mapping view. The system performs validation to ensure the parent reference table is synchronized first. Once the foreign table records exist in Odoo, primary table records link directly to them without broken references.
