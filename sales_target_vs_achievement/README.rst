Sales Target VS Achievement
===========================

Sales target and achievement based on each salesperson's individual target

Key Features
------------

* Salesperson Target Setting
* Daily, Monthly and Yearly Time Spans
* Automatic Achievement Calculation
* Automatic Team Target
* Target and Achievement Analysis
* Role-Based Access and Tracking

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
