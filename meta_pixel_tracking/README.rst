Meta Pixel Tracking
===================
Meta Pixel Tracking module for Odoo 20 enables you to effortlessly implement
tracking events to gather valuable data from your Odoo website for analysis
using Meta Pixel.

Key Features
------------
* Event Tracking
* Easy Configuration
* Conversion Analytics

Installation
------------
No external dependencies.

Configuration
-------------
* Meta Pixel Account: Create a Meta Pixel account if you don't have one:
    -> Go to Business settings in Business Manager of your Meta business account.
    -> Select your business.
    -> Click Data sources.
    -> Select Datasets / Pixels.
    -> Click Add by the search bar at the top of the page.
    -> Enter a name for your pixel.
    -> Optional: Enter your website URL.
    -> Click Continue and note the Pixel ID.
