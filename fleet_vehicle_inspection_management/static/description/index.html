Frequently Asked Questions

How do I create a new inspection request?

Go to Fleet > Inspection Request > Inspection Request and click New. Select the Vehicle Inspection type and the Vehicle, then click Confirm to move the request to the New state.

How does automatic inspection scheduling work?

After confirming a request, an Inspection Line is created on the vehicle. A daily scheduled action checks if today matches the reminder date (Next Inspection Date minus Reminder Days). When it matches, a new inspection request is auto-created, a reminder email is sent, and the Next Inspection Date is advanced by the configured period.

How do I create a service from an inspection?

When the inspection is in the Inspection Started state, click the Create Service button in the header. A wizard opens where you can select the service type, sub-service types, cost, vendor, and date. Saving the wizard creates both a Fleet Service log and a Vehicle Service Log automatically linked to the inspection.

What is the difference between Inspection Manager and Inspection Supervisor?

Inspection Manager has full access and can view and manage all inspection requests across the system. Inspection Supervisor can only view and manage inspection requests that are assigned to them. Roles are configured in Settings > Users & Companies > Users.

Can I print a PDF report for an inspection?

Yes. Once the inspection reaches the Inspection Finished state, a PDF Report button appears in the header. Clicking it generates a detailed PDF containing the vehicle details, inspection result, supervisor name, and all attached images.

Why is the Next Inspection Date not updating when I run the scheduled action manually?

The scheduled action only advances the Next Inspection Date when today exactly equals the reminder date (Next Inspection Date minus Reminder Days). If that date has already passed, the condition will not trigger. Using a less-than-or-equal check instead of an exact match would ensure missed dates are still processed.
