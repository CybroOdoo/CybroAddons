Configuration

Go to Settings -> Users & Companies -> Users, open the user and enable the checkbox "Manage Multiple Journal Entry Cancel" to get the cancel and reset options in the Action menu of journal entries.

Multiple entry cancel

Go to Invoicing -> Account ->Journal Entries -> select the journal entries in the posted state and click Multiple Journal Entry Cancel in the action menu.

Journal entry cancel confirmation

Click Multiple Journal Entry Cancel to open the confirmation wizard, then click Mass Cancel Journal Entry.

Cancelled Journal Entries

The selected journal entries are now cancelled.

Resetting cancelled entries

Select multiple cancelled entries and click Multiple Journal Entry Reset in the Action menu.

Journal entry reset confirmation

Click Multiple Journal Entry Reset to open the confirmation wizard, then click Mass Reset Journal Entry.

Reset Journal Entries

The selected journal entries are now back in draft state.

Frequently Asked Questions

What is the purpose of the Mass Journal Entry Cancel module?

The module allows users to efficiently cancel multiple journal entries at once, streamlining the process and saving time when adjustments or corrections are needed.

How do I select which journal entries to cancel?

Open the list of journal entries, tick the entries you want, and choose the action from the Action menu. Cancel works on posted entries and reset works on cancelled entries.

Is there a confirmation step before canceling journal entries?

Yes, a confirmation wizard appears before the entries are cancelled or reset, which prevents accidental changes.
