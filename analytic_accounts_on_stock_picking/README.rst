Analytic Account on Stock Picking
=====================================

Analytic Account and Analytic Tags Features for Stock Picking


Key Features
------------

* Show the selected analytic account when delivering products in a sale.
* Show the selected analytic account when receiving products in a purchase.
* Specify analytic distribution percentages on order lines.
* Review the selected analytic distribution when invoicing or billing.

Installation
------------
No external dependencies.

Configuration
-------------
Enable Analytic Accounting from configuration settings, so that it is possible to
select the analytic accounts when we need.
