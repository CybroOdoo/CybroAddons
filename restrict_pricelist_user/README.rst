Restrict Pricelists for Users
=============================
This module helps you to restrict pricelists for users.

Key Features
------------

* Ability to restrict pricelists for users.
* Compatible with multi-company setups in Odoo.
* Users can access all pricelists if none are selected.
* Authorize selected pricelists to the respective users.

Installation
------------
* No external dependencies.


Configuration
-------------
* The Restrict Pricelist option in the Settings needs to be enabled.
