How do I add multiple components to an existing BoM?

Simply open your BoM, click the "Select Products" button above the component lines, select all the products you need in the wizard, and click "Select".

Can I create a BoM directly from the product list?

Yes. Select the products you want as components in the list view, then click the "Action" gear icon and choose "Create BOM".
