Edit Sale Order Date
====================

The Edit Sale Order Date module allows authorized users to change the order date of confirmed sale orders. Access to edit the order date can be restricted to a specific user group. Users without access receive a validation error when attempting to modify the order date.

Key Features
------------

* Edit confirmed sale order dates.
* User group-based access control.
* Restrict unauthorized users from modifying the date.
* Error validation warning upon unauthorized changes.

Installation
------------
No external dependencies.

Configuration
-------------
* Navigate to Settings -> Users & Companies -> Users.
* Select the user and locate the Other / Extra Rights section.
* Enable the 'Edit Order Date' checkbox to allow the user to modify order dates on confirmed sale orders.
