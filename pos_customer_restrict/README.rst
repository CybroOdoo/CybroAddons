Restrict Customers In POS
=========================

This module helps to manage and restrict customer visibility in Point of Sale sessions, ensuring only permitted customers can be selected.

Key Features
------------

* Restrict customer visibility in Point of Sale sessions.
* Enable or disable customer availability in POS directly from the partner form view.
* Automatically set newly created customers from the POS UI as available in POS.
* Filter and search only permitted customers in the POS customer screen.

Installation
------------
No external dependencies.

Configuration
-------------
Open a Customer/Partner record in the backend and toggle the "Available In POS" field under the Misc group in the Sales & Purchase tab.
