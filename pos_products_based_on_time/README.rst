POS Happy Hours | POS Time Based Products | POS Breakfast Lunch Dinner
======================================================================

This module lets you show different products in the POS at different times of the day.

Key Features
------------

* Time-Based Product Switching
* Time Ranges That Cross Midnight
* Live Updates, No Session Restart
* Wide Odoo Compatibility

Installation
------------
No external dependencies.

Configuration
-------------
The user must be added to the security group Point of Sale / Administrator in order to access the new
Product Planning menu, found under Point of Sale > Products.
