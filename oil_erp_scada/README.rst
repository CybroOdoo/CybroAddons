Oil & Gas SCADA Integration
===========================
* Oil ERP SCADA Integration is a centralized solution designed to bridge Ignition SCADA and Odoo with real-time tag readings, threshold alerts, and production write-back efficiently within Odoo.
* It is an open-source module developed to extend Odoo with industry-specific SCADA integration functionalities tailored for oil and gas businesses.
* Oil ERP SCADA Integration provides integrated features for managing tag registries, multi-measurement readings, alert thresholds, storage tanks, and daily production reports.
* The SCADA Integration module acts as a unified layer that standardizes all real-time field telemetry operations within the Oil ERP system.
* It follows a specialized approach, allowing businesses to effectively map OPC-UA tags to wells, equipment, pipelines, and storage tanks based on operational requirements.

Configuration
=============
* Enable ``SCADA Integration`` under ``Settings > Oil ERP`` and set the ``SCADA API Key`` that Ignition will send in every payload.
* For the full Ignition setup — project library, tag change handlers, gateway scripts, and test procedure — see ``ignition_scripts/README.md`` in the module.
