Answers Before You Install

Q
Which Odoo editions and deployment environments are supported?
A
The module is fully certified for Odoo 20 Enterprise, running smoothly on both Odoo.sh and On-Premise deployments with zero external server dependencies.
 
Q
How are the 17+ KPIs and 90-Day Cash Flow Forecast computed?
A
All 17 financial KPIs and ratios (including Gross Margin, DSO, DPO, Working Capital, Daily Burn Rate, and Runway Days) are calculated in real time directly from posted journal entries. The 90-day cash forecast daily projection curve is generated from confirmed invoice payment schedules and vendor bill maturities.
 
Q
Can each user customize card visibility and switch themes?
A
Yes. Each user has an independent slide-out drawer to toggle metric visibility, reorder KPI cards, and show or hide individual charts. Users can also switch effortlessly between crisp Light Mode and eye-friendly Dark Mode, with all layout preferences saved per user account.
