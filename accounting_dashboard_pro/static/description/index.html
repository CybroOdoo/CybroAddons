Frequently Asked Questions

Does the dashboard module create new user security groups in Odoo?

No, it inherits Odoo's native accounting group architecture. It checks user privileges against existing groups to dynamically display or hide widgets.

Key Privileges Verified:
  • Invoicing / Billing (account.group_account_invoice)
  • Basic Accounting (account.group_account_basic)
  • Accountant (account.group_account_user)
  • Advisor / CFO (account.group_account_manager)
  • Readonly (account.group_account_readonly)

This ensures users see only the widgets and analytics they have authorization to access, preventing unauthorized sensitive revenue and cost leakage.

Can individual users configure and persist their dashboard layouts?

Yes. The module features user-specific configuration options. Layout structures, collapsed widgets, and default filter periods are serialized in a dedicated configuration model (account.dashboard.config) and saved per user to database records.

Does the dashboard support multi-company operations?

Absolutely. The dashboard is built to operate in Odoo's multi-company environment. Managers and CFOs can select single or multiple companies to consolidate or isolate financial statistics on the fly, adhering fully to company record rules.

How is dashboard performance optimized for large databases?

The dashboard implements a multi-tier optimization strategy:

  • Raw SQL Queries: Executes complex aggregations directly on PostgreSQL bypassing ORM loops.
  • Parallel JSON-RPC: OWL frontend fires independent RPC requests concurrently.
  • Server Caching: Caches KPI results using Python LRU cache, invalidating automatically when moves are posted.
  • Lazy Chart Loading: Renders basic metric elements first, then async-loads heavy Chart.js charts and transaction lists.
