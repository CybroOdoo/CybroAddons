Payable And Receivable Amount
=============================
This module displays the total payable and total receivable amounts directly in the partner form view.

Key Features
------------
* View total receivable amount on customer profiles.
* View total payable amount on vendor profiles.
* Automatically computed based on posted, unreconciled account moves.
* Multi-company aware.

Installation
------------
No external dependencies required.

Configuration
-------------
No additional configuration is required.
