Draggable And Resizable Wizard
==============================

This module makes every backend wizard and dialog in Odoo resizable. Odoo
already lets users move a dialog by dragging its header.

Key Features
------------

* Applies to every backend wizard and dialog, with no setup per model.
* Resize a dialog from the handle in its bottom-right corner.
* Move a dialog by its header (standard Odoo behaviour, shown with a move
  cursor).
* A resized dialog keeps its size while it is moved.
* A minimum size of 300 x 150 pixels keeps dialogs usable.
* Full-screen dialogs (for example on mobile) are not changed.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
