Google Drive Odoo Connector
===========================
* This module connects Google Drive with Odoo 19 and automatically syncs
  attachments to Google Drive.

Configuration
=============
* Create an OAuth client ID in the Google Cloud Console and enable the
  Google Drive API.
* Go to Google Drive Connector > Configuration, create an account with the
  Client ID and Client Secret, and click Connect Google Drive.
