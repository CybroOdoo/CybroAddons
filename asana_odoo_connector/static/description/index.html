Go to the Settings page.

Go to the Asana settings section. You can get a new asana account from here. In the Asana settings section you can provide your Asana Workspace ID and your Personal Access Token (PAT) as App Token.

To get the App Token

To get the App Token first you need to go the settings by clicking on the Settings button of https://app.asana.com/.

Click on Build new Apps option

Then under the Apps section you need to click on Build new Apps option.

Create new app token

From here you can see the existing tokens and also you can create new app token by clicking on the button Create new token.

To get the Workspace ID

To get the Workspace ID you need to go to this link https://app.asana.com/api/1.0/workspaces (The gid will be the workspace id), and then as per the image you need to fill your App Token on AUTHORIZATION section and then click on the button Try It!, as you can see in the Response section you can get the Workspace ID's of the workspaces from here.

Test the connection

If you want to test the connection from Odoo to Asana you can click the TEST button, if the connection is success then it will be shown as in a popup as connection successful.

Import the Projects and Tasks

From the IMPORT PROJECTS AND TASKS button you can import the Projects and Tasks from Asana to Odoo if the Projects are not already imported then the Projects will be get imported also the corresponding Tasks will be imported according to the Project Sections from Asana.

What is the Odoo Asana Connector module?

This module enables two-way synchronization between Odoo and Asana. Projects, tasks, and customers created in Odoo will reflect in Asana—and vice versa.

How do I connect Odoo with Asana?

Create a developer app in Asana to get the Personal Access Token. Enter the token in the connector's configuration within Odoo. Map workspaces and projects between the platforms.

Can I choose which projects or tasks to sync?

Yes, you can configure specific workspaces or projects to sync. You may also set filters based on tags, stages, or assignees.
