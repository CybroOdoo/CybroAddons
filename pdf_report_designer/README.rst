PDF Report Designer
===================
This module enables to create custom PDF Reports for any Odoo model.

Key Features
------------
* Fully Configurable PDF Reports
* Filter Report data based on any Date Field
* Reports Menu under the Action Menu

Installation
------------
No external dependencies.

Configuration
-------------
The user should be added to the security group: Administrator(Settings/Base)
inorder to get access to the new menu.
