Advanced VAT Invoice
====================
This module allows printing VAT invoice reports and simplified tax invoice
reports in Arabic, with QR code generation compliant with ZATCA regulations.

Key Features
------------

* QR Code
* Reports
* QR Scan

External Dependencies
---------------------
* Python library ``qrcode`` (https://pypi.org/project/qrcode/)

Installation
------------
This module requires the external Python library 'qrcode':

.. code-block:: bash

    pip install qrcode

Configuration
-------------
Configure QR code generation (Automatically or Manually) in Accounting -> Configuration -> Settings -> QR Code.
