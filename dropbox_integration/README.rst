Dropbox Integration
===================

This module allows users to integrate Dropbox with Odoo 20 to upload, preview, and manage files seamlessly via direct file links.

Key Features
------------

* Easily synchronize and connect Odoo with Dropbox.
* Dedicated interactive Dropbox Dashboard to preview and manage files.
* Direct file upload from Odoo to your configured Dropbox folder.
* Open and preview files securely via generated direct Dropbox links.
* Secure OAuth2 authentication flow with refresh tokens.
* Search and filter files directly from the dashboard.

Installation
------------
External Python dependency required:
* dropbox (install via `pip install dropbox`)

Configuration
-------------
* Go to Settings > General Settings > Integrations > Dropbox.
* Enter your Dropbox Client ID and Client Secret.
* Specify the target Dropbox Folder ID.
* Click 'Setup Access Token' to authenticate and generate a refresh token.
