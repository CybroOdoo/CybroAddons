Where does the workflow start?
The workflow starts by enabling Employee Management, setting hourly wage on employees, and assigning those employees to an oil and gas well task.
What data is used to create the expense?
The system uses the selected expense category, the chosen date, task timesheet entries, assigned employees, and each employee's hourly wage.
How are created expenses reviewed later?
Users can open the generated HR expense from the task and review the related daily expense lines, total amount, employee, project, and task details.
