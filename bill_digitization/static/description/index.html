Frequently Asked Questions

What file formats are supported?

This module supports scanned documents in .jpg, .jpeg, .png, and .pdf formats for bill creation.

Can I review the extracted data before creating the bill?

Yes, a preview view is available to review and verify all extracted details before confirming the vendor bill.

How does the Digitize Bill feature work?

The feature reads scanned documents using OCR and AI to extract vendor and bill details automatically.
