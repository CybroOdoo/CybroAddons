Minimal Backend Theme
=====================

Calm backend theme: search menus and records, pins, app board, sidebar, dark mode, mobile and RTL.

Key Features
------------

* Global search (top bar, Ctrl+Shift+F): menus of all apps and records, quick create, pinned menus and recently opened records.
* Full-screen app board with pinned shortcuts.
* Menus in the top bar or in a collapsible sidebar (drawer on tablets).
* Dark mode, compact view and full-width forms from quick settings or general settings.
* Fully responsive on phones and tablets, with right-to-left (RTL) language support.

Installation
------------
No external dependencies.

Configuration
-------------
* Navigate to Settings > General Settings > Backend Theme to configure global theme options.
