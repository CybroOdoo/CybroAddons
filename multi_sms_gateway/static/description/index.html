Answers Before You Install

Q
Which SMS gateway providers are supported by this module?
A
The module supports three premier global communication providers: Twilio, Vonage (formerly Nexmo), and TeleSign. You can configure individual credentials for one or multiple gateways simultaneously and choose your preferred gateway dynamically whenever sending messages.
 
Q
Does this module require Odoo In-App Purchase (IAP) credits or an Enterprise license?
A
No. Unlike Odoo's default SMS mechanism, this module communicates directly with your own Twilio, Vonage, or TeleSign accounts using your direct API credentials. No Odoo In-App Purchase (IAP) credits are needed, and it operates seamlessly on both Odoo 20 Community Edition and Odoo 20 Enterprise Edition without extra Odoo fees.
 
Q
Can I send bulk SMS messages to multiple contacts simultaneously?
A
Yes. You can select multiple contacts from the Contacts list view and trigger the "Send SMS via Gateway" action to dispatch broadcast messages in a single operation. Dispatched messages are automatically recorded in the partner's communication chatter and saved in the centralized audit log under SMS Gateway → SMS History.
