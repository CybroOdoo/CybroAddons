Delivery Date Scheduler
=======================
Let your customers set their delivery date.

Configuration
=============
* Go to **Website** > **Configuration** > **Settings**.
* In the **Delivery Scheduler** section under **Delivery Date Restrictions**:
  * Enable **Restrict Date** to set the delivery date range.
  * Configure **Minimum Date Range (Days)** to set the earliest allowed delivery date from today.
  * Configure **Maximum Date Range (Days)** to set the latest allowed delivery date from today.
