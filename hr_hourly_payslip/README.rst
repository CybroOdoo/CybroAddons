Hr Hourly Payslip
=================
Create payslip based on the worked hours for the employees.

Key Features
------------

*  Salary based on the hours worked
*  Hourly cost taken from the employee profile
*  Hours are read from the Attendances app for the payslip period
*  The basic salary rule uses the worked hours for hourly employees only

Usage
-----
Enable *Hourly Payslip* on the employee form, set the *Hourly Cost* and
create a payslip. The total hours and the hour based salary are shown on it.


Installation
------------
Depends on *Attendances* and *Payroll Community* (hr_payroll_community).

Configuration
-------------
No additional configuration is required.
