OpenAI Ecommerce Product Media
==============================
Helps you convert OpenAI-generated sample images into product media for eCommerce use.

Key Features
------------

* "Make as Media Image" button on generated OpenAI image suggestions.
* Creates an eCommerce product media image from the selected image,
  with no download or re-upload.

Installation
------------
* Install the *OpenAI Product Images* module (``openai_product_images``)
  and its dependencies, then install this module.

Configuration
-------------
* Enter your OpenAI API key in the settings.
