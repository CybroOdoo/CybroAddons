Odoo Trello Connector
=====================

Integrate Projects and Tasks between Trello and Odoo

Key Features
------------

* Import open Trello boards, lists and cards into Odoo as projects, stages and tasks.
* Export Odoo projects, stages and tasks to Trello as boards, lists and cards.
* Create stages and Trello lists automatically during import and export.
* Run imports as background jobs using Queue Job.
* Avoid duplicate records by using Trello reference IDs.
* Move Trello cards to the matching list when a task changes stage in Odoo.

Installation
------------
This module requires the OCA ``queue_job`` module to be available in your addons path.

Configuration
-------------
No additional configuration is required.
