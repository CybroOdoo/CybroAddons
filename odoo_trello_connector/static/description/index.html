Odoo Trello Connector

Seamlessly integrate your Odoo Projects and Tasks with Trello. Import all Boards, Lists and Cards from Trello into Odoo as Projects, Stages and Tasks — or export your Odoo Projects and Tasks back to Trello. Stages are created automatically during both import and export operations.

Key Highlights

Two-Way Sync Between Odoo and Trello

Import Trello Boards, Lists and Cards directly into Odoo as Projects, Stages and Tasks. Export Odoo Projects and Tasks back to Trello with a single click.

Automatic Stage Creation

Trello lists are automatically mapped to Odoo project stages during import. New stages are created on the fly during export if they don't already exist in Trello.

Queue Job Powered Background Processing

Large Trello board imports are processed asynchronously in the background using Odoo Queue Jobs, keeping the UI responsive and preventing timeouts.

Secure Per-User API Configuration

Each Odoo user stores their own Trello API Key, Token and Username in their profile. Credentials are validated before any import or export operation is executed.

Duplicate-Safe Import

The module checks Trello reference IDs before creating records, ensuring that re-running an import never creates duplicate Projects, Stages or Tasks in Odoo.

Card Stage Tracking on Export

When exporting, task stage changes in Odoo are detected and the corresponding Trello card is moved to the correct list automatically, keeping both platforms in sync.

Trello Configuration and API

Sign in to your Trello account, then open the Trello Power-Ups Admin page by entering https://trello.com/power-ups/admin in your browser. Click New to create a new app and fill in the required details as shown below. In the Iframe Connector URL field, enter a valid HTTPS URL (for example, https://your-domain.com). This module uses the Trello REST API to communicate with Trello and does not require a Trello Power-Up iframe. The Iframe Connector URL can be updated later if you decide to develop a Trello Power-Up.

How do I get my Trello API Key and Token?

Log in to Trello and visit https://trello.com/power-ups/admin. Create a new Power-Up to generate your API Key. Then click "Token" on that page to generate a Token with the required permissions.

Where do I enter my Trello credentials in Odoo?

Go to Settings → Users & Companies → Users, open your user record, and click the Trello tab. Enter your Trello Username (your @handle without the @), API Key and Token, then click Import or Export.

Will re-running the import create duplicate records?

No. The module checks Trello Reference IDs before creating any record. If a Project or Task already exists with that reference, it is skipped.

Is the Queue Job module required?

Yes. The module requires the OCA queue_job module to be installed before installing this connector. The pre-install hook will raise an error if it is not present.

What Trello objects are imported?

Only open Boards are imported. For each Board, all its Lists (Stages) and Cards (Tasks) are pulled in and linked to the corresponding Odoo Project.
