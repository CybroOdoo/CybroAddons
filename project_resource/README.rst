Project Free Resource
=====================

This module helps retrieve all available resources for a project task based on the task start date and end date, allowing assignment to one of them.


Key Features
------------

* Directly retrieve all resource details.
* Ensure only authorized users are permitted to access projects and tasks.
* View allocated tasks and resource availability list.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
