Frequently Asked Questions

How can I enable Washing Type in POS?

You can enable it by navigating to Settings under Configuration in Point of Sale and enabling Washing Type.

Can I create invoices directly from laundry orders?

Yes, you can generate invoices based on the laundry orders processed in the POS screen.

How do I add Washing Type to an order line?

You can click either the Laundry Service button or the custom button in the order line to add the Washing Type.
