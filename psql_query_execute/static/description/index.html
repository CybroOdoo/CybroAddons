Screenshots Feature Matrix Frequent Questions Release Notes

Go To Settings -> Technical -> PSQL Query

Navigate to Settings > Technical > PSQL Query to access and manage your database queries.

Create New PostgreSQL Query

Click on the 'New' button to create a new query entry and set a descriptive query name.

Write the SQL query you want to execute and click Execute/Refresh the Query

Input your SQL query in the text area and click 'Execute/Refresh' to run it against the PostgreSQL database.

Result of the Query

The query result is displayed directly in the user interface inside a styled, scrollable table.

Print the Result

Click the 'XLSX' button at the bottom of the form to export the query results into an Excel report.

XLSX PSQL Result

View the generated XLSX Excel spreadsheet with report generation date, company name, and organized data columns.

Query Error

In case of syntax mistakes or non-existent tables/columns, the system safely catches the error and displays a clear Validation Error dialog.

Answers Before You Install

Q
Does the feature available to all users?
A
No, the user must have technical settings access to use this feature.
 
Q
Can we reuse the Query?
A
Yes, the query can be saved as a record and it can be reused.
 
Q
Can we export the query result to an Excel sheet?
A
Yes, clicking the XLSX button on the query form generates and downloads an Excel file containing all the fetched data.
