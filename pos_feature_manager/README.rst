POS Feature Manager
===================
This module allows administrators to restrict or enable specific Point of Sale
features for individual users and employees. Restrictions can be configured per
user or employee directly from their profile, giving fine-grained control over
what each cashier is allowed to do during a POS session.

Configuration
=============
1. For employees: Go to **Employees → Employees → [Employee Name] → Point of Sale** tab.
2. For users: Go to **Settings → Users & Companies → Users → [User Name] → Point of Sale** tab.
3. Check or uncheck the desired permission booleans.
4. Save the record.
5. In **Point of Sale → Configuration → Settings**, enable
   **Log in with Employees** to use employee rights tiers and cashier switching.
6. Open a POS session to apply restrictions for the logged-in user or active cashier.
