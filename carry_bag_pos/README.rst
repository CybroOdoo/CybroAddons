Bag Charges in POS
==================

This module allows cashiers to add carry bags to Point of Sale orders.

Key Features
------------

* Quick bag selection in the POS
* Bag charges shown as order lines on the receipt
* Simple, lightweight setup

Installation
------------
No external dependencies.

Configuration
-------------
To use the module, set the bag category first:

#. Go to *Point of Sale > Configuration > Settings*.
#. In the *PoS Interface* section, enable *Bag Charges*.
#. Select the *Bag Category*: the POS category whose products are offered as
   carry bags.
#. Make sure the bag products are available in the POS and assigned to this
   POS category.
