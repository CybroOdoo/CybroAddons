POS Reference for Payment
================
This module will help you to add Reference for payment manually from payment screen.

Key Features
------------
* Easily add Payment reference from pos payment screen.

Installation
------------
No external dependencies.

Configuration
-------------
* Go to **Point of Sale → Configuration → Settings**.
* Enable **Allow Payment Reference from POS Payment Screen** to allow
  adding payment reference from the POS payment screen.
