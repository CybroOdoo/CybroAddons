Frequent questions

What is the role of the Waste Management Base module?
wm_base provides the core models, configurations, digital signature engine, and audit logging framework that serve as the foundation for the entire Waste Management suite.
Can wm_base be installed as a standalone module?
Yes. You can install wm_base independently to manage waste categories, materials, container specifications, compliance codes, digital signatures, and audit logs.
How does the digital signature engine work?
It enables multi-role signature workflows (e.g. Generator, Transporter, Facility Manager). Signers can sign in-app via the Sign Now wizard or externally via a secure token-verified web portal.
Does the audit trail impact system performance?
No, the audit logging mixin is designed for asynchronous recording of tracked field mutations and status transitions with minimal overhead.
