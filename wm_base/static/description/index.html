Is this module compatible with standard Odoo 19 Community Edition?
Yes. Waste Management Base is built for Odoo 19 Community Edition and needs no Enterprise modules. It does require the reportlab and pillow Python packages.
How do digital signatures work on mobile devices and field tablets?
Signers receive a secure, token-protected portal link that opens directly on touchscreens (smartphones, iPad, Android tablets). They sign via finger/stylus canvas. The signature, signing time, IP address, and browser are recorded, and the signed PDF is attached to the linked document.
Can we configure custom waste categories and container sizes?
Yes. You can define unlimited waste categories, materials, and container types, with container volume in litres, maximum payload, tare weights, and approved waste categories.
Are audit logs protected from user modification?
Audit log records cannot be edited or deleted through the application, including by administrators, and are visible only to Compliance Officers and Administrators. They are not cryptographically sealed, so someone with direct database access could still alter them.
