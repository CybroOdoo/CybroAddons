Frequently Asked Questions

Can I restrict multiple users from seeing a menu item at the same time?
Yes. When you hide a menu for a user, the system automatically updates the restricted-user list for that menu. You can hide the same menu for multiple users by selecting it in each user's form, or add them together from the menu's Restrict Access tab.
Does this module also work for admin users?
No. By default, system administrators keep access to all menus. The module detects admin users and always shows them the full menu hierarchy, so the 'Hide Specific Menu' configuration does not apply to them.
Can I hide sub-menus and their parent menus?
Yes. You can hide both parent menus and sub-menus. You can select each one individually, or use the 'Apply to sub-menus' button to cascade a parent menu's restrictions to all of its children at once.
Can I hide a menu for an entire group of users?
Yes. Each menu has a 'Restricted Groups' field — any user belonging to one of those groups will not see the menu, without having to configure each user separately.
Is there a faster way to apply the same restrictions to many users?
Yes. Use the 'Copy Hidden Menus' wizard to copy one user's hidden-menu set onto several other users at once. It adds to their existing restrictions without removing any.
