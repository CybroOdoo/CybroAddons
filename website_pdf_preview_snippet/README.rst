Website PDF Preview Snippet
===========================

This module adds a website snippet that lets visitors upload a PDF file
and preview it directly on the website.

Key Features
------------

* Adds a PDF Preview Snippet to the website builder, in its own PDF
  Preview group.
* Visitors choose a PDF file and preview it in the browser.
* Only PDF files are accepted (up to 20 MB); other files show an error page.
* Nothing is stored: the file is only sent back to the visitor's browser.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required. Drag the PDF Preview Snippet onto
a page in the website editor.
