Answers Before You Install

Q
Can I add a different logo for each POS?
A
Yes, you can configure a unique logo for each POS by setting a different image in the POS configuration. This allows you to tailor the branding for different stores or locations.
  • Store-specific branding with individual logos
  • Improves customer recognition at each outlet
  • Flexibility for multi-location businesses
Q
What are the size requirements for the logo?
A
The recommended size for the logo is 75 pixels in height for the navbar. The system will automatically resize the image, but it's best to use a high-resolution image for clarity.
Q
How do I enable the receipt header logo?
A
You can enable the receipt header logo by selecting an option under Receipt Logo Option in the POS configuration. The available choices are:
  • Show POS Logo Only
  • Show Company Logo Only
  • Show Both POS and Company Logos

Once selected, the chosen logo(s) will appear automatically on the POS receipt.
