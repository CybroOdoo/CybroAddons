All In One Hide Print Button
============================

This module lets the administrator hide print buttons per user. For each
user, the administrator can choose in which applications and documents
the print buttons should be hidden.

Key Features
------------

* Hide print buttons per user from the user form (Access Rights tab).
* Supports Sales, Invoicing, Purchase, Project Tasks and Employees.
* Inventory: Transfers, Operation Types, Packages, Lots/Serial Numbers and
  Locations.
* Manufacturing: Manufacturing Orders and Bills of Materials.
* Removes both the Print menu of the action toolbar and print buttons in
  the views, such as Print Labels.
* Send by email buttons stay visible.

Installation
------------
No external dependencies.

Configuration
-------------
Open Settings > Users, select a user and choose the print buttons to hide
in the Hide Print Button section of the Access Rights tab.
