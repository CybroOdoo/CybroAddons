User Wise Button Restrict In POS
=================================
This module restricts POS buttons based on users, employees, and Point of Sale configurations.

Configuration
=============
* Navigate to **Settings > Users & Companies > Users** (or **Employees** when using POS HR).
* Select a user or employee and open the **Point of Sale** tab.
* Set **Point of Sale** to specify the POS configurations where restrictions apply (leave blank to apply to all).
* Set **POS Buttons** to select which buttons should be restricted.
