Product Removal Authorisation
=============================
User in the group "Product Deletion" can only delete the products. Those who are not in the
group cannot delete the product. Odoo will raise a warning if the user is not in the group.


Key Features
------------

*  Raise Warning Message.
*  Restrict Product Deletion.
*  Only users in the group Product Deletion can delete the product.

Supported Editions & Deployment
-------------------------------
* Deployed on: Odoo.sh, On-Premise
* Supported Editions: Community, Enterprise

Frequently Asked Questions
--------------------------
* Who can delete products?
  Only users assigned to the "Product Deletion" security group.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required. Assign the "Product Deletion" group to authorized users.
