Website Product Customizer
==========================

A comprehensive product customization module that allows customers to design
and personalize products directly from the eCommerce storefront using a
Fabric.js-powered canvas designer.

Configuration
=============

1. Install the module from **Apps**.
2. Go to **Product Designer → Configuration → Settings** and set the
   maximum upload size for customer images.
3. Open any product form, enable the **Is Designable** toggle under
   *Sales*, and configure the **Product Designer** tab (design area,
   fonts, colors, limits).
4. Publish the product on the website — the *Customize & Design* button
   will appear on the product page.
