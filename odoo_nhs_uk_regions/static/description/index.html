Frequently Asked Questions

Does this module replace the existing NHS England and Scotland configuration?

No. This module extends the existing NHS Trust Management configuration without modifying or replacing any England or Scotland data. It adds Wales and Northern Ireland as additional health systems that coexist alongside the existing dual-system hierarchy.

What is a Welsh Local Health Board and how does it differ from an ICB?

Welsh Local Health Boards (LHBs) are the Welsh equivalent of NHS England Integrated Care Boards. Unlike ICBs, LHBs are responsible for planning, commissioning, and delivering healthcare directly within their geographic area. This module stores them as separate records with their own ODS codes while linking them to associated NHS Trust records for Wales.

Is the ODS Sync module required to use the UK Regions Extension?

Yes. The UK Regions Extension depends on both the NHS Trust Management base module and the ODS Sync module. This dependency allows Welsh and Northern Ireland ODS organisation codes to be classified and synced correctly using the extended role mapping provided by this module.
