Storage Dashboard
=================
The Storage Dashboard shows the memory and CPU usage of the server, the Odoo
memory and time limits, the database details and a chart of the models using
the most storage in the current database.

Configuration
=============
No additional configuration is required. The Memory Usage menu in Settings is
visible to the administrators.
