Theme Petzen
============
* Pet Theme for Odoo 18 Website

Overview
========
Theme Petzen provides a complete Odoo website and eCommerce experience tailored for pet-related businesses. Includes pre-designed templates for home, shop, services, reviews, and contact pages.

Configuration
=============
* Install the theme from Website > Configuration > Settings > Choose a Theme.
* Approve the reviews submitted on the website from Website > Configuration > Customer Reviews.
