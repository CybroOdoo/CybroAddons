Interactive Info Icon on Order Lines

An intuitive info icon is seamlessly placed next to each product on quotation and sales order lines for quick, one-touch product inspection.

Instant Product Details Popover

Hovering over or clicking the info icon displays a rich product summary card with the product image, reference, category, unit price, ordered quantity, and real-time on-hand stock. Product cost is securely restricted to Sales Managers.
