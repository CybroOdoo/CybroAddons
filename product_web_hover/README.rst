Product Web Hover
=================
Displays a product details card from the info icon of sale order lines.

Key Features
------------
* Hover (or click) the info icon of a sale order line to open a card with the product image, internal reference, category, unit price, ordered quantity, and on-hand stock.
* The product cost is displayed to Sales Managers only.
* The product data is read from the server each time the card is opened.

Installation
------------
Requires the Sales (``sale_management``) and Inventory (``stock``) apps; there are no external dependencies.

Configuration
-------------
No additional configuration is required.
