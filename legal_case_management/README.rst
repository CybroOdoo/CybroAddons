Legal Case Management
=====================
This module helps to manage all processes of a legal case management firm.
In this way we can register a case and add their evidence, trial, and payment also.
Assign lawyers based on wages and per case.

Key Features
------------

* Different access rights for admin, lawyer and clerk.
* Creation of lawyers and their wages for trial and case.
* Case registration through form.
* Invoicing For trial, case, out of court and full settlement.
* Case registration through portal.


Installation
------------
No external dependencies required


Configuration
-------------
The user should be added to the security group: Admin(Settings/Users/Other/Case Management) in order to get access to the new menu.
