POS Automated Manufacturing
===========================
* This module automates the creation of Manufacturing Orders (MRP) directly from the Point of Sale interface.

Configuration
=============
* Configure "To Create MRP Order" and "Done MRP Order" on the Product Template under the Point of Sale tab.
* Ensure a Bill of Materials (BoM) exists for the product.
