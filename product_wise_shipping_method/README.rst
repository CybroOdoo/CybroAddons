Product Wise Shipping Method
============================

This module allows users to manage product-wise shipping methods.

Key Features
------------

* Auto-Filled Shipping Method
* Community and Enterprise Support

Installation
------------
No external dependencies.

Configuration
-------------
* Enable "Delivery Methods" in Sales > Configuration > Settings.
* Select the shipping method on the product form.
