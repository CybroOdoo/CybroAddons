Database Delete Protection
==========================
This module restricts the deletion of Databases.

Configuration
=============
* Add the ``db_delete_restrict`` parameter to your ``odoo.conf`` file with a comma-separated list of database names to protect from deletion::

    db_delete_restrict = database_name1, database_name2
