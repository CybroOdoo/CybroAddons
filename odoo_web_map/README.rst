Odoo Web Map
====================
* Map View for Odoo Community

Configuration
=============
* Navigate to Settings > Technical > User Interface > Configure Map View to dynamically add map views to any Odoo model.
* Select the model, the relevant actions, and the partner field to enable the map view.
