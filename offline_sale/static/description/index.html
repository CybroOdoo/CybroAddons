Added an Offline Sale systray icon in the Odoo header. Users can click the icon from the top-right systray section to access offline sale features and related operations.

Upon clicking the icon, users are redirected to the Offline Sale Terminal screen, where they can perform offline sales activities and manage orders.

A customer selection field and a contact icon were added to the Offline Sale Terminal. Users can choose an existing customer from the dropdown list or create a new customer by clicking the contact icon

Clicking the Contact icon in the Offline Sale Terminal opens the Customer Creation form, allowing users to enter customer details such as name, address, phone number, and email. After filling in the required information, users can click the Save Customer button to create and store the customer record locally. The newly created customer is then available for selection in the current sales transaction.

Newly created customers are automatically added to the customer selection list in the Offline Sale Terminal. Users can select the customer, add products to the order line, and create a sales order with the selected customer and add products directly from the terminal interface.

Upon clicking Confirm Order, the system redirects users to the Payment Screen. The selected customer, order details, and invoice preview are displayed for review. Users can select a payment term, enter the payment amount, and click Validate Payment to finalize the sale and complete the payment process.

Once a payment is successfully completed, the system automatically routes the user to the dedicated Document View. Print Icon: Sends the receipt directly to the local or thermal hardware printer for a physical copy. Email Icon: Opens a prompt to instantly email a digital copy of the receipt to the customer. PDF Icon : Generates and downloads a portable PDF version of the transaction for local digital filing.

Clicking the Orders button in the left navigation sidebar transitions the interface to the Pending Orders screen as displayed. This dashboard synchronizes and lists active backend sales orders that are not canceled and still carry an outstanding balance due.

Upon clicking the Load Order button, the system opens the specialized payment terminal for the selected backend transaction. This interface allows operators to accept either full or partial amounts to settle outstanding customer balances.

Clicking the Transactions button in the left navigation sidebar transitions the interface to the Transaction History.

Clicking the Exit Terminal button transitions the operator out of the active sales dashboard

When sales transactions are processed or finalized through the offline terminal, they are synchronized into the backend and displayed directly within the Sales.

Frequently Asked Questions

Why should I use this module?

This module helps sales teams remain productive in environments with unreliable or limited internet access, preventing workflow interruptions and reducing the risk of lost sales data.

Can I create sales orders while offline?

Yes. Users can create new sales orders, add products and manage order details without an active internet connection.
