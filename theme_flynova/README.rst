Theme Flynova
==============

Theme Flynova is an Odoo Website theme for travel booking websites. It adds
tour and hotel listing pages, booking flows, traveller photo management, and
reusable website snippets.

Configuration
=============

* No additional configuration is required after installation.
* Configure tour and hotel products from Website > Configuration > Flynova
  Packages.
