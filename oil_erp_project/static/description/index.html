Does the module create projects automatically?
Yes. Its project customization layer supports automatic structure and storage location creation as part of the upstream exploration workflow.
How is production entry controlled?
Production entry is launched from a dedicated task wizard and is only available in well stages configured specifically for production monitoring.
Is this standard Odoo Project only?
No. It is a sector-specific customization of Odoo Project, adding the technical fields and execution logic required for oil and gas well coordination.
