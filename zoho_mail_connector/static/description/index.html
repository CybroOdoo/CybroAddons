Frequently Asked Questions

Can I synchronize Inbox and sent emails?

Yes, this module allows synchronization of Inbox and sent emails from Zoho Mail into Odoo.

Are email attachments synchronized?

Yes, attachments are downloaded from Zoho Mail and stored as native Odoo attachments.

Does the module automatically refresh expired access tokens?

Yes, the module automatically generates new access tokens using the stored refresh token when required.
