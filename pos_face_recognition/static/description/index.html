Answers Before You Install

Q
Does it work with any webcam?
A
Yes, the module is compatible with any standard USB or integrated webcam that can be accessed by the browser.
 
Q
Is facial data stored securely?
A
Employee images are stored securely on their profile in the Odoo database. Face descriptor generation and facial matching are performed entirely client-side in the browser.
 
Q
Does it work in offline mode?
A
Yes, because employee images are loaded with the POS session and face recognition runs locally in the browser, matching works seamlessly even in offline mode.
