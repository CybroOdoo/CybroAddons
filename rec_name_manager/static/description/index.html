Record Display Name Manager

Configure and control the display name of any Odoo model directly from the UI, without writing a single line of code.

Key Highlights

Configure display name for any installed Odoo model.

No code customization required.

Supports char, text, many2one, selection, date and numeric fields.

Updates breadcrumbs, form titles and many2one dropdown values.

Smart search using the configured display field.

Enable or disable configurations anytime.

Record Display Name Manager Menu

Open the Record Display Name Manager app and access the configuration menu to manage model display names.


Rec Name Configuration List

View all configured models, selected fields, field types and active status in one place.


Create a Rec Name Configuration

Select an installed Odoo model and choose the field that should be used as its display name.


Dynamic Field Selection

After choosing a model, the available fields are dynamically listed for easy selection.


Sale Order Display Name Changed

Example showing Sale Order records displayed using the configured field value.


Contact Display Name Changed

Example showing contact records displayed using another selected field instead of the default name.


Product Display Name Changed

Example showing product records displayed based on the configured product field.


Disable Configuration

Disable a configuration anytime to revert the selected model back to its default display name.


  • Configure rec name/display name for any installed Odoo model.
  • Manage display names directly from the UI without developer support.
  • Supports char, text, many2one, selection, integer, float, date and datetime fields.
  • Updates many2one dropdowns, breadcrumbs, form titles and display names.
  • Smart search uses the configured field value.
  • Enable or disable configurations anytime.
  • Compatible with Odoo 17 Community and Enterprise.
