Frequently Asked Questions

Does this work for all installed models?
Yes. The module patches the ORM at the base level and applies to every model in your Odoo instance — both native and custom models.
Do I need to restart Odoo after changing a config?
No. Changes take effect immediately after saving — the in-memory cache is automatically cleared on every save, create, or delete.
Which field types can I use as display name?
You can use char, text, integer, float, selection, date, datetime, many2one, and boolean fields. For many2one, it shows the related record's display name.
Can I revert to the original display name?
Yes. Simply toggle the Active switch off on the configuration record and the model will immediately revert to its default display name.
Is it compatible with Odoo 18 Community and Enterprise?
Yes, it is fully compatible with both Odoo 18 Community and Enterprise editions.
