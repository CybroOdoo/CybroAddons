Record Display Name Manager
===========================

Record Display Name Manager lets you choose which field is used as the display
name (rec_name) of any installed model, directly from the user interface and
without writing code. The chosen value is shown in breadcrumbs, form titles,
many2one fields and dropdowns.

Key Features
------------

* Configure the display name field of any installed model from a simple screen.
* The chosen value is shown in breadcrumbs, form titles and many2one fields.
* Many2one dropdown searches also match the value that is displayed.
* Supports Char, Text, Integer, Float, Monetary, Selection, Date, Datetime
  and Many2one fields, formatted in the user's language, timezone and
  currency.
* Selection fields show their label and many2one fields show the related
  record's name.
* Records whose chosen field is empty keep their default name.
* Archive a configuration to restore the default display name at any time.

Installation
------------
No external dependencies.

Configuration
-------------
Open the Record Display Name Manager app (Settings access required), create a
configuration, select a model and the field to display.
