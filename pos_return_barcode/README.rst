POS Return Barcode
==================
The POS Return Barcode module for Odoo 20 streamlines the product return process by enabling cashiers to return items by scanning barcodes printed on customer receipts.

Configuration
=============
* Navigate to **Point of Sale > Configuration > Settings**.
* Under the **Bills & Receipts** section, enable **Use Barcode on ticket**.
* Save the settings.
