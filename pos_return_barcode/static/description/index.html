Enable Barcode in POS Settings

Navigate to Point of Sale > Configuration > Settings. In the Bills & Receipts section, enable "Use Barcode on ticket" to activate barcode generation on receipts.

Barcode Printed on Customer Receipts

Upon completing any sales order in the Point of Sale session, a scannable 128 barcode is automatically printed at the bottom of the order receipt.

Barcode Number Stored in POS Orders

The generated barcode string is saved directly on the backend POS Order form view, ensuring complete traceability and fast back-office order lookup.

Dedicated "Return Product" Action Button

Cashiers can initiate receipt-based returns at any time by simply clicking the dedicated "Return Product" action button in the Point of Sale screen.

Scan Receipt Barcode in Popup Dialog

A streamlined popup dialog opens for instant scanning. Scan the receipt barcode using your handheld scanner or enter the barcode value manually.

Order Lines Retrieved for Product Return

The matching order is fetched instantly. The cashier can review line items, specify precise return quantities, and click "Refund" to add items to the cart.

Complete & Validate the Refund Transaction

Process the refund payment method, validate the return transaction, and print the return receipt with updated stock levels and financial entries.

Answers Before You Install

Q
Does this module work on both Odoo Community and Enterprise editions?
A
Yes, POS Return Barcode works identically on both Odoo 20 Community and Enterprise editions without requiring extra modules or configurations.
 
Q
What barcode scanners are supported?
A
Any standard USB or Bluetooth handheld scanner operating in keyboard emulation (HID) mode is supported out of the box, as well as native Odoo POS IoT barcode scanners.
 
Q
Can cashiers return partial quantities or selected items from an order?
A
Yes. When the order lines are retrieved, cashiers can specify the exact quantity to return for each item or return only specific products.
 
Q
Does this module work on Odoo.sh and On-Premise installations?
A
Yes, the module is fully compatible with Odoo.sh cloud hosting as well as self-hosted On-Premise environments.
