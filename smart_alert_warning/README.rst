Smart Alerts
============

Show alert banners on the form view of any model, only on the records that
match your conditions and only to the users who need to see them.

Key Features
------------

* Alert banners above the form view of any model
* Six alert styles: Primary, Secondary, Success, Danger, Warning and Info
* Show the alert only on the records matching a filter built with the domain
  editor, combining conditions with AND, OR and NOT
* The alert shows or hides as soon as a field of its filter changes, before
  the record is saved
* Optionally show the alert only to the users of one group
* Apply an alert to add it to the form, cancel or delete it to remove it
* Admin and User access levels
* Works with both Community and Enterprise editions

Installation
------------
No external dependencies. The module depends only on ``base``.

Configuration
-------------
Give the users the Smart Alert Warning: Admin or Smart Alert Warning: User
access in Settings > Users, then create alerts from the Smart Alerts menu.
Alert admins do not need the Settings access.
