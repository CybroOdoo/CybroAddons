Subscription ID Card
====================
Print a subscription ID card for the customer of a subscription sale order.

Key Features
------------

* Subscription ID Card button on confirmed subscription orders
* Card with the customer photo, the subscription dates and the products
* Works with the Odoo Enterprise Subscriptions app


Installation
============
- Install the module from the Apps menu.

Configuration
=============
- No additional configuration is required.
