All in One Dynamic Fields
=========================

The features of the module facilitate the addition of fields to any view within a model,
allowing users to specify attributes and properties at their preferred location.

Key Features
------------

* No-Code Custom Field Creation: Create custom fields across any standard or custom Odoo model without writing Python or XML files.
* Form and Tree View Integration: Effortlessly attach created dynamic fields to both Form and Tree/List views with automated inheritance.
* Precise Field Placement: Specify the exact position of new fields relative to existing fields (before or after) in any view.
* Custom Field Widgets: Select appropriate widgets for custom fields to enhance visualization, data entry, and user experience.
* Comprehensive Field Properties: Configure attributes including Required, Read-Only, Copied on Duplicate, Indexed, and Help tooltips.
* Role-Based Security & Access: Control permission groups to determine which users or administrators can create and manage custom fields.
