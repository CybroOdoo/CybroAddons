Multiple Warehouses in Sale Order Lines
=======================================

This module will help you to set warehouses per sale order line and the pickings will be created for the selected warehouses separately.


Key Features
------------
* **Warehouse Assignment per Order Line**: Choose different warehouses for individual products directly within the sale order lines.
* **Automated Multi-Warehouse Delivery Creation**: Automatically generates separate delivery orders (stock pickings) for each designated warehouse upon confirming the sale order.
* **Accurate Stock Procurement & Reservation**: Runs procurement rules per line according to the assigned warehouse, ensuring stock is reserved and deducted from the correct inventory locations.
* **Single Order Multi-Location Fulfillment**: Fulfill orders from multiple physical warehouses without needing to split or duplicate customer sales orders.
* **Default Warehouse Fallback**: Seamlessly falls back to the sales order's default warehouse if an order line has no specific warehouse set.
