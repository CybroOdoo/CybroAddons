Double Validation for Invoice and Bill
======================================
Invoices and bills need to be approved by the Manager and Finance Manager if the total amount exceeds a defined limit.

Key Features
------------

* Two-level approval for invoice.
* Available in Odoo 20.0 Enterprise and Community.


Installation
------------
* No external dependencies.

Configuration
-------------
After installing the module:

* Go to Accounting → Settings
* Enable Double Validation for Invoice
* Set the first and second approval limits
