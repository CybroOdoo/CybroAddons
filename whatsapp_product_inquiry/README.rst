WhatsApp Product Inquiry In Website
===================================

Let website visitors ask about a product on WhatsApp in one click. An Inquire
button on the product page opens WhatsApp with a message to the company
number, containing the inquiry message and the link to the product.

Key Features
------------

* WhatsApp Inquire button next to Add to Cart on the product pages
* The WhatsApp message contains the configured inquiry message and the
  product link
* WhatsApp number and message configured per company
* The button only shows when the website company has a WhatsApp number
* The WhatsApp number is validated to contain only digits
* Inquiries only work for products published on the website
* Works with both Community and Enterprise editions

Installation
------------
No external dependencies. The module depends only on eCommerce
(``website_sale``).

Configuration
-------------
In Settings, open the company and fill the WhatsApp Number (with the country
code, digits only, e.g. 919876543210) and the Message in the WhatsApp
Configuration tab.
