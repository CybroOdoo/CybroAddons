Customer Success Sentiment Tracker
========================
Customer Success Sentiment Tracker is an AI-powered Odoo module that
analyzes Helpdesk tickets in real time to determine customer sentiment,
calculate churn risk, and generate a dynamic Customer Health Score.

It helps support teams proactively identify at-risk customers and
improve overall customer satisfaction.

Features
========
* AI-powered real-time ticket sentiment analysis using OpenAI GPT models 
* Automatic 0--100 Customer Health Score calculation
* Intelligent 90-day sentiment decay logic for accurate scoring
* Automatic churn-risk detection (Healthy / Attention Needed / Critical)
* Interactive dashboard to monitor customer sentiment trends
* Automatic score recovery based on improved support interactions

Configuration
=============
1.  Go to:

    Customer Sentiment Tracker → Configuration → AI Settings

2.  Enter your OpenAI API Key

3.  Select your preferred GPT model

4.  Save

No additional configuration required.
