Mass Price Update
================
This module allows you to update the price or cost of products by percentage.

Key Features
------------
* Update the cost or price of multiple products in one click.
* View and confirm the current and new cost or price before applying the change.
* Shows a notification when the price update is complete.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
