Schedule Mail to Send
---------------------
* This module allows you to schedule and send emails at a specified future date and time.

Key Features
------------

* Easily schedule emails to be sent at a later time from any chatter record.
* View scheduled emails as planned activities in the chatter.
* Automated sending of scheduled emails through a scheduled cron job.

Installation
------------
* No external dependencies needed (depends on 'mail').

Configuration
-------------
* No additional configurations needed
