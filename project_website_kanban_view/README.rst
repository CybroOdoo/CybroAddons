Website Project Kanban View
============================
This module allows users to view projects and their related tasks in a Kanban view on the website portal. It shows the progress of each task based on its stage and due date.

Key Features
------------
* Website Kanban view for projects and tasks
* Real-time stage tracking
* Due date monitoring
* Configurable tasks per page pagination


Installation
------------
No external dependencies.

Configuration
-------------
To configure the number of tasks per page in the Kanban view:

1. Go to **Project** -> **Configuration** -> **Settings**.
2. Under the **Tasks** section, set the desired value for **Tasks per page in Kanban View** (default is 80).
3. Click **Save**.
