Frequently Asked Questions

Can I sync existing GitHub repositories?

Yes. Once configured, you can import and sync your existing GitHub repositories, issues, and branches seamlessly into Odoo.

Does it support real-time updates?

Yes, by configuring a Webhook Secret, you can receive real-time updates for pushes, pull requests, and issue activities directly in Odoo.

Are GitHub Issues linked to Odoo Project tasks?

Yes, the module syncs GitHub Issues as tasks within your Odoo Projects, enabling seamless project management.
