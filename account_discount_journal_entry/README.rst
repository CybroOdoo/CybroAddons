Account Discount Journal Entry
==============================
This module enables users to generate journal entries for discounts that are
offered on invoices or bills, and these discounts are accounted for after
the invoices or bills have been posted.

Key Features
------------
* Allows users to create journal items for discounts on invoices automatically.
* Allows you to configure discount accounts on product categories for finer control.

Installation
------------
No external dependencies.

Configuration
-------------
1. Navigate to **Invoicing** (or **Accounting**) -> **Configuration** -> **Product Categories**.
2. Select a product category.
3. Under the **Account Journal Properties** section, configure the **Customer Discount Account** and/or **Vendor Discount Account**.
