Custom Receipts For POS
=======================
Option to select the customised Receipts for each POS

Key Features
------------

* Create Custom Receipts for POS from the Backend.
* User can add the receipt designs from the backend in the menu Receipt Designs.
* Empower users to choose customized receipt designs from the POS interface.
* Edit Custom Receipts for POS from the Backend

Installation
------------
No external dependencies.

Configuration
-------------
* Go to Point of Sale -> Configuration -> Settings.
* Enable the 'Custom Receipt' option.
* Select the desired design in the 'Receipt Design' field.
