SignUp With Mobile
==================
* This module allows users to sign up with their mobile number.

Key Features
------------
* Users can sign up with their mobile phone number.
* Sign up with email address is also available.
* Mobile numbers are verified via Twilio SMS OTP for security.

Installation
------------
* Install the Python Twilio library: ``pip install twilio``.

Configuration
-------------
1. Open Settings-> General Settings.
2. Under the Discuss section, enable Custom Call Server and select Custom ICE Server with Twilio.
3. Fill in your Twilio Account SID and Twilio Auth Token.
4. Enter the Twilio From Number associated with your Twilio account.
