POS Manual Weight
=================
This module allows cashiers to enter product weight manually in Point of Sale without requiring a physical weighing scale.

Key Features
------------
* Enter product weight manually in Point of Sale without a weighing scale.
* Seamless integration with Point of Sale Community and Enterprise editions.

Installation
------------
No external dependencies are required.

Configuration
-------------
1. Navigate to Point of Sale -> Configuration -> Settings.
2. In the Connected Devices section, enable "Allow Manual Weight".
3. Save the settings.
