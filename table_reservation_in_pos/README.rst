Table Reservation in POS
========================
Reserve tables from the Point of Sale floor plan editor and keep the
reservation details with the table.

Key Features
------------

* Reserve a table from the floor plan editor and enter the reservation details.
* View the reservation details of a reserved table.
* Unreserve a table after confirmation.
* Reserved tables show a "Reserved" label in the floor plan.
* Enable or disable the feature for each POS from the settings.

Installation
------------
No external dependencies.

Configuration
-------------
Go to *Point of Sale > Configuration > Settings*, enable *Restaurant*, and
tick *Table Reservation*. The reserve, view info and unreserve buttons only
appear in the floor plan editor when this option is enabled.
