IT Hardware Sales & Services
============================
A comprehensive solution for managing IT Hardware Sales and Services in Odoo SaaS edition.
It streamlines operations for IT hardware businesses by managing hardware catalog sales, eCommerce,
serialized inventory tracking, field service installations, repairs, warranty coverage, and helpdesk support efficiently.

Configuration
=============
No complex configuration needed. Install the module and the default hardware categories, and helpdesk configuration will be automatically loaded.
