Send POS Receipt and Invoice via WhatsApp
=========================================
This module helps to share POS Receipt and Invoice to customers through WhatsApp.


Key Features
------------

* Send POS Receipt and Invoice through Whatsapp
* Capability to set separate WhatsApp authentication for individual POS sessions.

Installation
------------
No external dependencies.

Supported Editions & Deployment
--------------------------------
* Community Edition
* Enterprise Edition
* Deployed on: Odoo.sh, On-Premise

Configuration
-------------
Configure WhatsApp API credentials and session authentication via Point of Sale settings.

Frequently Asked Questions
--------------------------
* Can we send both POS receipts and invoices?
  Yes, receipts and invoices can be shared directly via WhatsApp.
