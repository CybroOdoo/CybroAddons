Create an account

Create an account in https://user.ultramsg.com/

Configure Instances

Click on 'Instances' to configure instances.



Add Instance

To create a new instance, click on the "Add Instance" button.

Token Configuration

Copy the Instance and Token to add them to Odoo.




Enable WhatsApp Messaging

Enable WhatsApp Messaging in the Settings. Upon enabling, you will receive a module named Whatsapp Configurator.


Authentication


Add the Instance and Token, then click on the "Authenticate" button.


Scan QR Code


You will receive a QR code for login along with the instance and token. After scanning the QR code from your mobile device, save it.


Connection Status


If you attempt to click on the Authenticate button again, you will receive a message stating 'Already connected'.


POS Configuration Settings


Navigate to Point of Sale -> Configuration -> Settings. Under Bills & Receipts, enable "WhatsApp Enabled". You will have the option to choose "Send Receipt" and "Send Invoice". Here, choose nothing and save.


Active POS Session Screen


During a POS session, create an order and confirm the payment. After confirming the payment, you will see two buttons named "Send Invoice" and "Send Receipt".


Invoice Configuration


Select "Send Invoice" in the Configuration Settings.


Customer Contact Configuration


You need to set a WhatsApp number in the customer profile.


Customer Profile Identification


You can view the WhatsApp number in the customer chosen page within the POS session.


Payment Verification Screen


You can view the WhatsApp number in the Payment Screen within the POS session.


Send Invoice Trigger


You will find a "Send Invoice" button on the Receipt Screen, which you can click to send the invoice to the Partner's WhatsApp number.


Processing Queues


When the Invoice sending is In Progress, you will see a loading indicator on the Button.


Success Confirmation


When the Invoice is successfully sent to the WhatsApp Number, you will receive a Success message on Receipt Screen.


WhatsApp Document Receipt


In WhatsApp, you can see that the Invoice document has been sent to the recipient.



Send Receipt Setting


Select "Send Receipt" in the Configuration Settings.



Send Receipt Execution


You will find a "Send Receipt" button on the Receipt Screen, which you can click to send the receipt to the Partner's WhatsApp number.



WhatsApp Receipt Verification


In WhatsApp, you can see that the Receipt document has been sent to the recipient.



Error Logs Exception Handler


If an error occurs while sending the document to the partner's WhatsApp Number, you will receive a failed message in the POS session.



Manager Logging Audit Track


As a manager, you can view all messages sent through WhatsApp from the POS session.



User Access Workspace


As a user, you can view your own messages sent through WhatsApp from the POS session.
