Theme Aquere

A calm blue website theme for a premium packaged drinking water brand, with a floating glass header, cinematic hero and animated, editable sections.

Key Features

Floating Glass Header

The standard Odoo header restyled as a glass pill with a call to action. It becomes more solid as the page scrolls.

Six Ready Pages

Home, Our Story, Our Water, Our Process, Our Planet and Contact, with menus created automatically.

Editable Sections

Every section is a building block in the Aquere group of the website builder and can be dropped on any page.

Scroll Animations

Fade-up reveals, a scroll-lit statement, parallax backgrounds, a sticky process tracker and a testimonial slider.

Enquiry Form

The contact page uses the standard website form and saves each enquiry as a CRM lead.

Bundled Fonts and Icons

Fonts, icons and photos are shipped with the theme, so the website works without external services.
