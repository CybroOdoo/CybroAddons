Frequently Asked Questions

Can dashboards be created for any Odoo model?

Yes, the module allows dashboards to be created for any Odoo model, enabling real-time visualization of key metrics and data in one place.

Can charts and reports be exported from the dashboard?

Absolutely. The module allows exporting charts and dashboard data into Image, PDF, XLSX, and CSV formats for easy sharing, reporting, and analysis.

Can charts and tiles on the dashboard be customized?

Yes, the module allows editing and configuring charts and tiles, choosing data sources, visualization types, and display settings to build fully personalized dashboards.
