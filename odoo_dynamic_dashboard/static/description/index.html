How it works

From an empty page to a dashboard in its own menu, in four steps.

1
Create a dashboard
Open Dynamic Dashboard Studio › Create Dashboard and give it a name.
2
Drag blocks, choose their data
Drop a block, then pick the model, the measure and the grouping in the side panel.
3
Arrange
Drag blocks to reorder them, resize them, or click Auto Arrange for tidy rows.
4
Save and add to a menu
Choose the menu item and its parent menu: the dashboard opens from there, for everyone allowed.

The builder

Everything happens on one screen, and every change is previewed with your real data.

Start from an empty page

Drag your first block, or let the AI generate the whole dashboard.

Drag and drop

A placeholder shows where the block lands. Click a block in the palette to add it at the end.

Choose the data

Search a model (Sales Order, Contact…), then the measure, how to group it, a second split, a filter. Sensible options are preselected and the title is suggested.

A menu for each dashboard

After saving, name the menu item and choose its parent menu, for example Sales / Reporting, or make it a new app.

The dashboard now opens from Sales › Reporting › Sales Overview. Click Edit to change it at any time.

17 building blocks

Each block shows one view of your data. Click any figure, bar or row to open the records behind it.

Key figures

KPI Tile
One key figure: a count, a total, an average, a minimum or a maximum, with an icon.
Progress Bar
A figure against its target, with the percentage reached.
Gauge
The same, as a speedometer towards the target.

Charts

Bar Chart
Compare categories. Optionally split into several series.
Horizontal Bars
Rankings, even with long labels: top customers, products…
Stacked Bars
Totals split by a second field, like orders per quarter by status.
Line Chart
Follow a trend by day, week, month, quarter or year.
Area Chart
A trend with its volume.
Pie Chart
Share of a total, for a few values.
Doughnut Chart
Share of a total, lighter look.
Polar Area
Compare a few categories by size.
Radar Chart
Compare profiles across several values.

Tables & views

Ranking Table
Top values as a numbered ranking.
Pivot Table
Cross two fields, with totals.
Record List
The latest or top records, with the columns and sort order you choose.
Odoo View
Embed a standard list, kanban, graph or pivot view of any model.

Layout

Text
A section title or a note, to structure long dashboards.

AI built in

Uses Odoo's own AI service (the same one as the AI of Odoo's editor): no account or API key to set up.

1. Describe the dashboard

Write what you want to follow, or start from an example, and choose how many blocks you want, or let the AI decide.

2. Review what the AI designed

It picks the right data and the right blocks. Every block is checked, then shown live in the builder: adjust anything before saving.

Analyze any block

Click the AI button on a block for a short analysis of what it shows: key facts with their numbers, trends, outliers, and one recommendation. In the language of the user, on the data they see, filters included.

Only the figures displayed by the block are sent to the AI service, when the user asks for it.

Filters on every block

Each viewer narrows any block for themselves, with options taken from the data of that block:

  • Period on a date of the model: today, this week, month, quarter or year, the last 7 or 30 days, the last 12 months, or a custom range.
  • Show only some of the values the block is grouped by.
  • Conditions on other fields: a status, a salesperson, a customer, yes / no, a text…

The block shows a summary of its filters. Filters are personal: they never change what others see, and are kept for the next visit.

From a figure to the records

Click a tile, a bar, a slice or a table row: the matching records open in a list, filters included.

Present it, export it

Slides

Present turns the dashboard into full screen slides: a title, the key figures together, then one slide per chart or table. Arrow keys to move, F for full screen, and an automatic mode for wall screens.

PDF

Export PDF lays the dashboard out on A4 landscape pages, with its name, the company and the date, and opens the print dialog: choose Save as PDF. Charts are kept exactly as displayed, in any language.

Multi-language

Fully translatable, with Spanish and Arabic included. Right-to-left languages are supported: the whole builder and the dashboards are mirrored. AI answers are written in the language of the user.

Getting started

Install
  1. Copy the module to your addons path.
  2. Update the apps list and install Dynamic Dashboard.
  3. Give your users the User or Administrator access.
  4. Open Dynamic Dashboard Studio › Create Dashboard.
Good to know
  • Depends only on web and iap, installed with every Odoo.
  • The AI features use Odoo's AI service, within its request limits.
  • No PDF engine to install on the server: PDFs are made by the browser.
  • Covered by automated tests, roles and permissions included.
