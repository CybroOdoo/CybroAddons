Beauty Shop Theme
=================
Beauty Shop Theme is an advanced eCommerce theme crafted for beauty and wellness stores. It transforms your online shop into a sophisticated, modern platform with a sleek design and premium UI/UX.

Installation
============
- Install the module from the Apps menu.

Configuration
=============
- No additional configuration is required.
