Theme Converza

A modern, fully responsive website theme for digital marketing agencies, built for Odoo 17.

Highlights

Ready-made pages

Home, Services, Results, Case Studies, Pricing, About Us, Contact Us and Blog pages that you can edit in the website builder.

Eleven snippets

Drag-and-drop building blocks for services, analytics, case studies, process, testimonials, pricing, team, insights and contact sections.

Custom header and footer

A sticky header with a responsive mobile menu, and a multi-column footer with a newsletter sign-up.

Interactive sections

Animated counters, a monthly and annual pricing switch, and filters for case studies and blog posts.

Self-contained

All scripts are bundled with the theme. No external script or stylesheet is loaded from a CDN.

Blog redesign

A featured article, category filters and a newsletter call to action, all powered by your real blog posts.

Installation

  • Install Theme Converza from the Apps menu.
  • Open the website builder and choose Theme Converza as your theme.
  • Edit the pages and add the Converza snippets from the builder panel.
