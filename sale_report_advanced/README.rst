Advanced Sales Reports
======================

Adds six wizards under Sales > Reporting > Sale Advanced Reports to print sales reports in PDF and XLSX format.

Key Features
------------

* Product Profit report by customer, product or both
* Invoice Analysis report by invoice status
* Sales Category report
* Product Sales Indent report
* Sales Analysis report by sale order or product
* Hourly Sales report in the time zone of the user

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
