Advanced Dashboard

Advanced Dashboard of Veterinary Clinic Management. It includes overall statics, today statics, and graph of monthly appointments, top 5 medicines, and grooming products.

Animal Form View

The form view allows users to enter all details of animals coming for veterinary services and provides a PDF report of animal details for reference. It also includes an option to create appointments for procedures, grooming, and training directly from the animal details window.

Create Appointments

The form view allows users to create appointments, add details of the disease, and confirm the appointment for further procedures.

Consultation Stage

At the consultation stage, we can add procedure details such as treatment, admission details, and vaccinations by simply enabling checkboxes.

Medical Test Tab

In the Medical Test tab, add the medical tests taken by the patient. Click on the 'Create Medical Test' button to create a record in the Medical Test model.

Medical Bill Tab

In the Medical Bill tab, you have the option to add the amounts for consultancy, surgery, admission, treatment, and vaccines to the invoice.

Grooming Appointments

Form View to Create Grooming appointment and Create Invoice for them.

Training Appointments

Form View to Create Training Appointments, Choose different Training Packages for pets and Create Invoice for them.

Surgery Appointments

Form View to Create Surgery Appointments.

Prescription Orders

Form view to create Prescription orders and Download the pdf report of Prescription.

Create Medicine

Form view to Create Medicine.

Medical Tests

Form view to Create Medical Tests and Invoice for them.

Maintenance Setup

Form view to Create Maintenance and Invoice for them.

PDF Reports Wizard

At the Report Menu, a wizard to select data for pdf Report.

Configuration Tab

At the Configuration Tab we can configure Animal Type, Breed Type, Disease Type, Medical tests, Surgery Details, Vaccine type, Training Packages, Grooming Products, Employees, Inclusion, Exclusion, Room Details.

Medical Test Product

Form view to Create Medical Test Product.

Staff Details

Form view to Store Staff Details.

Training Packages

Configure Training Packages for Training.

Grooming Products

Form view to Create Grooming Products.
