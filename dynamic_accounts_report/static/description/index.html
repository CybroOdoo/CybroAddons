Answers Before You Install

Q
In what formats can I export the financial reports?
A
You can easily print and export your financial reports in both PDF and XLSX (Excel) formats, allowing for easy sharing and further data analysis.
 
Q
Is it possible to see the detailed transactions behind the summary figures in the reports?
A
Yes, the module features a Drill-down Approach, which allows you to click on summary figures in the reports to dive deeper and directly access the underlying Journal Entries.
 
Q
Does this module require any special configuration or external dependencies to work?
A
No, the module is designed for ease of use. It requires no external dependencies and no additional configuration to start generating dynamic financial reports in Odoo 20 Community Edition.

DETAILED FEATURES

01
Drill-Down Approach
The reports are highly interactive. You can click on summary figures (like account balances or categories) to expand them and view the detailed transactions underneath.
 
02
Direct Journal Entry Access
While drilling down, you can directly access and view the underlying Journal Entries that make up a specific balance without leaving the report interface.
 
03
Flexible Export Options
Every report can be exported and printed in PDF format for static records, or XLSX (Excel) format for further data manipulation and analysis.
 
04
Advanced Filtering
It provides various filters (such as by date, period, journals, or accounts) allowing you to compare financial data dynamically.
