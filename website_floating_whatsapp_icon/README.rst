WhatsApp Floating Icon in Website
=================================
This module helps you to access your WhatsApp Web using an icon in the website.


Key Features
------------

* Floating WhatsApp Icon
* One-Click Direct Chat
* Configurable Mobile Number

Installation
------------
No external dependencies.

Configuration
=============
To configure your WhatsApp mobile number:

* Navigate to **Website** > **Configuration** > **Websites**.
* Select your website and enter the phone number in the **Mobile Number** field.
