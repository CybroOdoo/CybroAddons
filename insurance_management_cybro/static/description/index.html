FREQUENT QUESTIONS

Q
Which Odoo version does this module support?
A
This module is built for Odoo 20 and tested on the Community edition.
 
Q
Do I need any additional configuration after installation?
A
Assign users to the Insurance User or Insurance Manager group, then set up the policy types, payment types, policies and agents. See the README for details.
 
Q
Can I get support if something doesn't work as expected?
A
Yes. Contact Cybrosys Technologies at odoo@cybrosys.com or via WhatsApp for dedicated support within the warranty window.
