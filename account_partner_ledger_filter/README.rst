Partner Ledger with Partner Filter
==================================

Generate partner ledgers from selected contacts in Odoo 17.

Features
--------

* Open the report wizard from the Contacts Action menu.
* Select partners and use date, journal and customer/supplier filters.
* Display opening, running and closing balances for a selected period.
* Use the inherited posted-entry, reconciliation and currency options.

Installation and usage
----------------------

Install Odoo 17, base_accounting_kit and its base_account_budget dependency.
Install this addon, select contacts and choose Action > Partner Ledger.
Set Included Partners and the date range, enable Include Initial & Closing
Balance when needed, and print. Set Date From for opening balances.
Accounting report access is required. No additional configuration is needed.
