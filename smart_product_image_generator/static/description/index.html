Configure AI Providers in Settings

Go to Settings › AI Image Generator to enter your API keys for OpenAI, Stability AI, or Google Gemini. Define a Brand DNA style guide that is automatically appended to every prompt for catalogue-wide visual consistency.

Generate Image Button on the Product Form

A ✦ Generate Image with AI button appears at the top of every product form. Click it to open the AI image wizard for that product — works from both product.template and product.product (variant) views.

Review and Customise the AI Prompt

The wizard auto-builds an optimised prompt from the product's name, category, description, and price tier. You can review and edit it before generating. Choose the AI provider, image size, style, and number of variants (up to 4).

Preview Generated Variants and Apply

After generation, all image variants are shown in a preview grid with the provider and style used. Click ✓ Use This Image on the best variant to apply it directly to the product — the page reloads instantly showing the new image.

AI Image Generation Log

Every generation request is tracked in the AI Image Generation Log — accessible from the Products menu. The log records the product, provider, style, prompt, status, timestamp, and whether the image was applied, giving managers a full audit trail.

Frequently Asked Questions

Which AI providers are supported?

The module supports OpenAI DALL-E 3, Stability AI (stable-image/generate/core), and Google Gemini Imagen. You only need an API key for the provider(s) you plan to use. Keys are entered once in Settings and stored as encrypted system parameters.

Do I need to write the AI prompt myself?

No. The wizard automatically generates an optimised prompt from your product's name, category, description, and price range. The prompt is fully editable before generation, so you can fine-tune it if needed. The optional Brand DNA setting in Configuration also appends your visual style guide to every prompt automatically.

Can I generate images for multiple products at once?

Yes. Select multiple products from the product list view and use the Generate AI Images action. The bulk wizard lets you choose the provider, style, and image size for all selected products at once. You can also enable Skip products with existing images to avoid overwriting already-set photos.

Does applying an image overwrite the existing product photo permanently?

Clicking Use This Image writes the selected variant to product.template.image_1920. The previous image is replaced in the product record. If you need to revert, you can re-upload the original image manually or generate a new one. The Generation Log also stores a reference to every image that was applied, making it easy to track changes over time.
