Answers Before You Install

Q
What is the purpose of this module?
A
The systray panel lists internal users. Select a user to open their chat in the installed Viber app using their phone number.
 
Q
How does the Viber integration improve communication?
A
It provides a quick way to open a Viber chat from Odoo. Messages are handled in the Viber app, not in Odoo.

Download Viber

Download Viber from the official Viber website.

Viber systray icon

The Viber icon appears in the Odoo systray.

Choose the User

Click the icon to open a form where you can choose the user to chat with.

Viber Chat

The Viber chat opens with the selected user's phone number.
