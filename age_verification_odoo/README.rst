Age Verification in Website Login
=================================

Keeps the website signup form locked behind an age verification popup. Visitors confirm their date of birth, and only those aged 18 or over can sign up.

Key Features
------------

* Age verification popup on the website signup page
* Signup form locked until the age is confirmed
* Access denied message for visitors under 18
* Invalid date message for an empty or future date
* Invitation links skip the popup

Installation
------------
No external dependencies.

Configuration
-------------
Open Website > Configuration > Settings and set Customer Account to Free sign up.
