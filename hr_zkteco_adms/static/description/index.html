Frequently Asked Questions

Does the device need a static IP address?

No, not in ADMS mode. The terminal pushes to Odoo over HTTP, so only outbound access to the Odoo server is required - it works through NAT and on Odoo.sh. Direct IP mode does require a static, reachable IP.

My terminal has no Cloud Server Setting menu - what now?

Use Direct IP mode instead. Install pyzk on the Odoo server, set the device's Connection Mode to Direct IP and give it a reachable IP - Odoo then polls the terminal directly.
