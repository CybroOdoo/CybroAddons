Pharmaceutical ERP — Traceability, CoA & Audit Trail
====================================================
Certificate of Analysis, batch genealogy and audit trail for the Pharmaceutical ERP suite.

Key Features
------------
* Certificate of Analysis (CoA) generated per batch, carrying the QC result lines for that lot.
* Printable CoA PDF report with its own dedicated paper format.
* QA release queue consolidating the checks required before final batch disposition.
* Batch genealogy view tracing a lot upstream to its components and downstream to its products.
* Audit trail of tracked field changes, built on Odoo's mail tracking values.
* Deviation and CAPA relations surfaced directly on the CoA and genealogy records.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
