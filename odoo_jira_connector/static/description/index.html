Odoo Jira Connector

Seamlessly integrate your Odoo Projects and Tasks with Jira. Bi-directionally synchronise Projects, Tasks and Users between Odoo and Jira — export Odoo records to Jira or import Jira issues into Odoo with a single click. Automate project creation and keep both platforms in sync in real time.

Key Highlights

Bi-Directional Sync Between Odoo and Jira

Export Odoo Projects and Tasks to Jira or import Jira Projects and Issues back into Odoo. Both directions are supported with a single click from the Settings panel.

Centralised Configuration in Settings

Configure your Jira URL, username and API token in Odoo's Project Settings. Test the connection, then trigger export or import operations from one place.

User Import and Export

Sync users between Odoo and Jira in both directions. Each Odoo user stores their Jira User Key, keeping user assignments accurate across both platforms.

Automatic Mode for Real-Time Sync

Enable the Automatic toggle to have Projects and Users created in Odoo pushed to Jira automatically, eliminating the need for manual export operations.

Sprint Management

Import Jira Sprints into Odoo and link Tasks to their corresponding Sprint. View all sprints per project directly from the Project form via a smart button.

Queue Job Powered Background Processing

All import and export operations are processed asynchronously using Odoo Queue Jobs, keeping the UI responsive and preventing timeouts on large datasets.

Jira Profile

Login to the Jira account and click the icon → Profile.

Jira API Key Generation

Security → Create API token.

Token Label

Provide a label and click on the Create button.

Copy API Token

Copy the generated API token and store it securely. This token will be used to authenticate the Odoo Jira Connector.

Finding Your Jira URL & Username

URL: Go to id.atlassian.com/manage-profile/products while logged into your Atlassian account. Under "Jira settings" you'll see every Jira site linked to your account (e.g. yoursite.atlassian.net). Copy the exact domain shown there and prefix it with https:// when entering it in the URL field — this avoids typos or truncated site IDs from copying the address bar manually.

User Name: Despite the label, this field expects the email address linked to your Atlassian account, found under "Profile and visibility" → "Email" on the same account page — not your Jira display name.

Both values must exactly match the account that generated the API Token, or the connection test will fail.

Authenticate Connection

Go to Project → Settings, enter the URL, User Name (email) and API Token as described above, then click Test Connection to verify.

Import/Export Data

After that you can export/import or sync all the projects, tasks and users. It also syncs the comments and attachments. You can import projects while creating them in your Jira account using the "Automatic" feature.

WebHook Setup

Go to Jira → Settings → System Settings → WebHooks.

Webhook Configuration

Create a webhook. After adding details like 'name' and 'status', add the URL "/jira_webhook" with your app's URL.

Webhook Events

Only allowed protocol is HTTPS. Then enable events to trigger that webhook. After that save the webhook.

Jira View — Projects

You can add a sprint in that project from Jira.

Does this module work with both Odoo Community and Enterprise?

Yes, the module is fully compatible with Odoo 19 Community and Enterprise editions.

Is the synchronization between Odoo and Jira real-time?

The synchronization is near real-time, based on scheduled jobs or webhooks, depending on your configuration.

What happens if I delete a task in Jira or Odoo?

The task will be automatically removed from the other system to maintain consistency.

Can I sync attachments between Odoo and Jira?

Yes, attachments are automatically exported from Odoo to Jira and vice versa.

Is the Queue Job module required?

Yes. The module requires the OCA queue_job and queue_job_cron_jobrunner modules to be installed before installing this connector. The pre-install hook will raise an error if they are not present.
