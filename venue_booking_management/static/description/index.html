Answers Before You Install

Q
Can I configure both daily and hourly booking rates for venues?
A
Yes, you can configure distinct Day-wise and Hour-wise charges for each venue. When creating or requesting a booking, selecting the booking type automatically calculates the rental fee based on the specified duration and rate rules.
 
Q
How does the system prevent double bookings for the same venue?
A
The module features built-in overlap constraint validation that prevents scheduling conflicts for the same venue across overlapping time intervals. Staff can also use the 'Check Availability' wizard before confirming reservations.
 
Q
Can customers book venues directly from the website?
A
Yes. The module provides a frontend website booking page where visitors can select venues, check availability for specific dates, select required amenities, and submit booking requests with automatic partner registration.
