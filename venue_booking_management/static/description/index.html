Key Highlights

Venue Booking : Easily create and manage new venue booking orders.

Venue Types & Amenities : Configure multiple venue types and add custom amenities to enhance each venue.

Integrated with Accounting Module : Can create and view invoices based on the Venue Booking.

Dashboard & Analytics : Interactive Kanban and graphical dashboard showing booking counts, customer info, and venue insights.

Manage Venue Types & Amenities : Add, edit, or delete venue types and amenities directly from the dashboard.

Advanced Reporting : Generate detailed booking analysis with downloadable PDF and XLSX reports.

Extra Charges Management : Handle additional costs and service charges for venues with ease.

Website Booking : Enable customers to book venues online quickly and conveniently.

Portal Access : Users can view their booking records through a dedicated portal interface.
