Theme Arqora
============
An architectural lighting studio theme for Odoo 20: a dimmable hero room,
drawing-sheet sections, collections that switch on, a mosaic of signature
products, light levels by space, services, projects, materials, resources,
about and contact pages. The shop, product page, cart and checkout stay the
standard eCommerce of Odoo.

Configuration
=============
* Install the module and apply the theme "Theme Arqora" on the website
  (Website > Configuration > Settings > Choose a theme, or Themes).
* With demo data enabled, the six lighting categories and eighteen products are
  created and shown by the Collections and Objects of Light blocks.
