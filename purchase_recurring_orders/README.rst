Purchase Recurring Orders
=========================

This module allows you to create recurring orders for purchases.

Key Features
------------

* Recurring Purchase Agreements
* Line-wise Ordering Intervals
* Initial Order in One Click
* Next Year Orders in One Click
* Fixed, Renewable and Unlimited Terms
* Scheduled Action

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
