Volunteers and Donors Management
================================
This app allows you to manage your volunteers and donors in Odoo and allows you to create projects and tasks with volunteers. It also allows you to select volunteer and donor details on CRM leads and pipelines.

Key Features
------------

* Allow you to create and manage Volunteers and Donors in Odoo.
* Allow you to add Volunteer Types, Volunteer Skills.
* The project will allow you to select Volunteers specifically for that particular project.
* Project PDF report with Volunteers details.
* Allow you to share tasks to Volunteer on the portal of your website.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
