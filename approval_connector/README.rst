Sale Approval Connector
=======================
Helps to set up an approval system for sale orders.

Key Features
------------

* Additional approval stage controlling sale orders.
* Grant permission for order confirmation.

Installation
------------
No external dependencies.

Configuration
-------------
No configuration is needed initially. Sale orders follow the normal
process until an approver is added to the Create Sale Request
approval category, after which all sale orders require approval.
