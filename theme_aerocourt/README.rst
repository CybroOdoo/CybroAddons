Theme AeroCourt
===============

A dark, lime accented website theme for an indoor badminton club. It gives the
club a complete website: a fixed glass header with a light and dark switch, a
full height hero with the live open status, a court booking calendar, coaching
sessions, membership plans, a journal, a contact page and an oversized
wordmark footer. Every page is made of sections that are edited in the website
builder.

Key Features
------------

* Full height hero with the live open or closed status and animated counters.
* Court booking calendar: free courts are counted from the existing bookings,
  so a court cannot be booked twice.
* Coaching sessions as plain HTML cards: duplicate, delete, change the photo,
  the texts and the time slots in the website builder. Filters, search,
  sorting and a registration form read the cards themselves.
* Membership plans that open a join form.
* Testimonials carousel with editable slides.
* Journal built on the standard Odoo blog, with nine sample articles.
* Contact page with a message form, opening hours and contact cards.
* Court bookings, session requests, memberships and contact messages are saved
  as tagged CRM leads (Court, Session, Membership, Contact) with a reference
  such as BK-00001.
* Footer newsletter form that subscribes to the default mailing list.
* 18 building blocks in the AeroCourt group of the website builder.

Installation
------------
No external dependencies.

Configuration
-------------
* Install the theme from Website > Configuration > Settings > Choose a Theme.
  The menu, the header, the footer, the logo and the pages are set up
  automatically.
* Set the opening hours, the number of courts, the court price, the racket
  rental fee and the booking window in Website > Configuration > Settings >
  AeroCourt Club.
