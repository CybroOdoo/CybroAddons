Direct Access to Product Variants

Navigate directly to Purchase > Products > Product Variants to view and manage all product variants with purchasing cost and stock availability.

Bulk Product Selection & Create RFQ Action

Select one or multiple products from the list view and choose Create RFQ from the Actions menu to launch the quick quotation wizard.

Configure RFQ Details & Product Lines

Specify Vendor, Order Deadline, and Salesperson in the wizard dialog. Selected products are pre-loaded with standard cost prices and default quantities ready for inline adjustment.

Flexible Creation: Create or Create & View

Choose Create RFQ to save the quotation in the background and continue browsing, or Create and View RFQ to immediately open the generated purchase order.

Generated Request for Quotation (RFQ)

The generated RFQ appears in draft status with vendor details, deadline, and populated order lines with computed totals, ready for sending or confirmation.

Answers Before You Install

Q
How can I create an RFQ from product variants?
A
Select one or more product variants from the list view and use the Action → Create RFQ option to open the RFQ wizard.
 
Q
Can I edit details before creating the RFQ?
A
Yes, the wizard allows you to set vendor, quantities, pricing, and order deadline before creating the RFQ.
 
Q
Can I view the RFQ after creating it?
A
Yes, you can choose the Create and View RFQ option to immediately open the generated RFQ form.
