Quick RFQ from Products
================

This module helps to generate rfq for multiple products from Products list.

Key Features
------------

* **Bulk RFQ Generation from Products List**: Select multiple products or product variants from the list view and generate a Request for Quotation (RFQ) instantly.
* **Interactive RFQ Wizard**: Pre-populates selected products into a wizard with default quantities and unit cost prices for quick verification.
* **Vendor & Order Customization**: Choose vendor, salesperson, and order deadline while adjusting product line quantities and unit prices prior to creation.
* **Flexible RFQ Creation**: Option to create the RFQ in the background or create and directly open the generated Purchase Order form.
* **Dedicated Product Variants Menu**: Quick access menu under **Purchase > Products > Product Variants** to browse variants and execute bulk RFQ generation.

Installation
------------
No external dependencies.
