POS Lot Expiry Warning
======================

Displays expiry warnings for product lots in POS.

Key Features
------------

* Expiry date warning.
* Real-time synchronization.
* Integration with the Lot System.
* Warning for non-existent lots.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
