Sale Order Line Views
=====================
* Sale Order Line Views is a module which helps in viewing quotation/sale order lines with custom views. Users can easily analyze order lines directly with the help of list view, form view, kanban view, search view, pivot view, graph view and calendar view.

Key Features
------------

* Sale Order Line View.
* Quotation Line View.
* Quick Access to Sales Data.
* Improved Sales Management.

Installation
------------
No external dependencies.

Configuration
-------------
* No additional configurations needed.
