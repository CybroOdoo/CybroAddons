Hide Price, Add to Cart and Quantity Selector in Website
========================================================
* A module that hides product prices, the Add to Cart button, and the quantity
  selector from guest users on the website.

Key Features
------------

* Hide product prices from guest users.
* Hide the Add to Cart button from guest users.
* Hide the quantity selector from guest users.
* Show full product details to logged-in users.
* Control price and cart visibility from the website settings.

Installation
------------
No external dependencies.

Configuration
-------------
* In the website settings, enable *Hide Product Prices for Guests* and/or
  *Hide Cart from Guests*. Hiding prices also hides the cart.
