Theme Velora
============
Luxury fragrances and signature perfumes eCommerce theme with rich snippets and editorial design.

Features
========
- Transparent hero header and fixed navigation with search overlay.
- Side-panel cart drawer and wishlist integration.
- Restyled shop, product cards, login and order confirmation pages.
- Ready-made pages: Our Story, Collections and Best Sellers.
- Nine drag-and-drop snippets: Hero, Collections, Bestsellers, Categories,
  About Story, Why Us, Testimonials, FAQ and Newsletter.
- Fragrance categories (Men, Women, Unisex, Floral, Woody and more) created on install.
- Newsletter sign-ups are stored as mailing contacts.

Installation
============
- Install the module from the Apps menu (it also installs Website, eCommerce
  and Email Marketing).
- In Website → Configuration → Settings, or via Website → Themes, click
  "Use this theme".

Configuration
=============
- No additional configuration is required.
- Add products and publish them on the website so they appear in the
  Best Sellers section.
