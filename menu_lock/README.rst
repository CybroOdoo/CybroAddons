Menu Lock in Odoo
=================
Require a password when a user opens selected menus in Odoo.

Key Features
------------
* Lock Models and Menus
* Single and Multi Password Options

Installation
------------
Install Menu Lock from the Apps menu.

Configuration
-------------
* In Settings, open Users & Companies → Users and select a user. Choose a
  password mode, set the lock password, and select the menus or models.
  Menu prompts apply to navbar navigation. Configure model permissions
  and record rules to control access to the underlying records.
