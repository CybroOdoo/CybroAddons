Twilio SMS Gateway
==================

Send individual and group SMS through the Twilio gateway.

Key Features
------------

* Send SMS from sale orders, purchase orders and contacts.
* Create reusable message templates.
* Send SMS to groups of contacts, immediately or on a scheduled date.

Installation
------------

External Python dependency required:
* twilio (``pip install twilio``)

Configuration
-------------

* Create an account in Twilio (https://www.twilio.com).
* Configure Account SID and Auth Token in Twilio Account settings.
