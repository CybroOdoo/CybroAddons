FREQUENTLY ASKED QUESTIONS

Where does the file upload button appear on the website?

The 'Choose File' button appears on the eCommerce payment checkout page, allowing customers to add documents prior to completing their order.

Can sales managers access uploaded files from the backend?

Yes! A dedicated 'Attachments' smart button is displayed on the sale order form view in Odoo backend, allowing staff to view and download all customer files.

Can customers delete uploaded files before submitting the order?

Yes. Each uploaded file has a Delete button, so customers can remove a wrong file and upload the right one before paying.
