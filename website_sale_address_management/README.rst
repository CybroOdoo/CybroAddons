Website Sale Address Management
=================================
This module helps you filter fields in the address form and show or hide them with on/off toggles.

Configuration
=============

* To customize which fields appear or are mandatory, go to
  **Website → Configuration → Settings → eCommerce Address**.
  There you can toggle field visibility and required status individually for
  Billing and Shipping addresses, and set a default country for each.
