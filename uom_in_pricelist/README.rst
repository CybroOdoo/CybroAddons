UOM In PriceList
================
This module allows to apply the condition with UoM in the advanced price rule in Odoo.

Key Features
------------

* Add a dedicated Unit of Measure condition to product pricelist items to tailor pricing rules per unit type.
* Enforce both minimum purchase volume and target UoM criteria simultaneously before applying discounts or rates.
* Dynamic Sales Line Recalculation

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
