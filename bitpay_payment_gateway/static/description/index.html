Frequently Asked Questions

How can customers pay using BitPay on the website?

Customers select BitPay during website checkout, connect their crypto wallet (Coinbase, MetaMask, Trust Wallet, etc.), select their preferred coin (BTC, ETH, etc.), and complete the payment.

Are testnet sandbox environments supported for testing?

Yes, the module supports both Test/Sandbox (test.bitpay.com) and Live production (bitpay.com) environments using POS API tokens.
