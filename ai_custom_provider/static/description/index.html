Enable Custom AI Provider.

Go to Settings → General Settings → AI Provider section. Enable "Use Custom AI Provider".

Select Provider & Enter API Key.

Choose a pre-configured provider (e.g. OpenAI, Anthropic, Gemini) and enter your API key.

Choose Chat & Embedding Models.

Pick a Chat Model, an optional Reasoning Model, and an Embedding Model from the provider's model list.

Manage Providers & Models.

Click "Manage Providers & Models" to view all pre-seeded providers with their chat and embedding model counts.

Provider Form View.

Open any provider to view its API Base URL, API Key, and the full list of chat and embedding models.

AI Agent Responding via Custom Provider.

AI chat agent replying through your configured provider — no IAP credits consumed.

DETAILED FEATURES

01
Configurable API Endpoint
Set any OpenAI-compatible base URL (e.g. https://api.openai.com/v1) directly in General Settings.
 
02
Pre-Seeded Providers
Ships with ready-to-use providers: OpenAI, Anthropic, Google Gemini, Groq, DeepSeek, Mistral, OpenRouter, and Ollama.
 
03
Chat & Reasoning Models
Select a standard chat model and optionally a separate reasoning model for "Think Longer" AI actions.
 
04
Embedding Model Routing
Route AI agent document embedding requests to a 1536-dimensional embedding model of your choice.
 
05
Async AI Agent Support
AI chat agents run requests in a background thread after DB commit — no blocking, no webhook required.
 
06
IAP Fallback
Disable the custom provider at any time and Odoo automatically falls back to its default IAP service.

Answers Before You Install

Q
Do I still need Odoo IAP credits after installing this module?
A
No. Once the module is enabled and a provider is configured, all AI requests are routed to your own API endpoint. Odoo IAP credits are not consumed.
 
Q
Which embedding models are compatible?
A
The model must produce 1536-dimensional vectors. OpenAI's text-embedding-3-small and Google's gemini-embedding-001 are supported. Mistral's mistral-embed (1024 dimensions) is not compatible.
 
Q
Can I add my own custom provider or model?
A
Yes. Go to Technical → AI Providers and click New. Enter any OpenAI-compatible base URL, an optional API key, and add as many chat or embedding model IDs as needed.
