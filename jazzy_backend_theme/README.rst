Jazzy Backend Theme
===================
* Jazzy Backend Theme module for Odoo 20 community editions. This is a Minimalist and Elegant Backend Theme for Odoo 20. This theme will change your Old Experience to a New Experience with Odoo.


Key Features
------------

* Customising theme.
* Smooth navigation.
* Highly responsive.
* Customising theme.
* Fully modified and colorful form,kanban and tree view.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
