Key Highlights

Emission Records

Central fact table for all Scope 1, 2 and 3 emission-generating activities with full lifecycle management.

Fleet Carbon Capture

Auto-sync odometer readings and commuting wizard to generate Scope 1 fleet emissions from vehicle CO₂ specs.

Executive Dashboard

Interactive ESG dashboard — scope breakdown, monthly trends, and target progress in one view.

Targets & Initiatives

Set annual reduction targets and track initiative progress against expected and actual savings.

Invoice Auto-Capture

Assignment rules automatically match vendor bill lines to emission factors and create records on posting.

Reporting Periods

Named time windows with open/closed/locked states — locked periods block retroactive changes for audit integrity.

Screenshots

1

Invoice Auto-Capture Flow

Set up an assignment rule, post a matching vendor bill, and watch emission records be created automatically.

Step 1 — Emission Factor Configuration

Emission factor list showing scope, category, and kg CO2e/unit. The factor used by the assignment rule is configured here first.

Step 2 — Assignment Rule

A factor assignment rule matching by product, partner, or account — any posted vendor bill line that matches automatically gets an emission record.

Step 3 — Vendor Bill with Smart Button

Posted vendor bill showing the Enviro Records smart button — records were created automatically when the bill was confirmed.

Step 4 — Generated Emission Records

The emission records list opened from the bill's smart button, showing the auto-created logged records with scope and CO2e.

2

Fleet Commuting Flow

Calculate and generate Scope 1 commuting emissions for all assigned drivers over a selected period.

Step 1 — Wizard: Set Period

Open the Fleet Commuting wizard, set the period start and end date, and click Preview.

Step 2 — Wizard: Preview

Preview tab showing calculated overlap days, round-trip km, office ratio, and CO2e per driver/vehicle assignment.

Step 3 — Generated Commuting Records

Emission records created by the wizard, one per driver assignment, showing vehicle, distance, and CO2e calculated from vehicle spec.

3

Dashboard Filtering Flow

Drill into emissions by period and scope directly from the dashboard — filters persist when you navigate away and return.

Step 1 — Dashboard Default View

Dashboard loaded with default year filter and all scopes active — scope donut, monthly trend, and target gauge all visible.

Step 2 — Period Filter Open

Calendar picker open showing Month / Quarter / Year rows with inline navigation arrows to move between periods.

Step 3 — Scope Filter Open

Scope dropdown open with Direct / Indirect / Other checkable rows — only selected scopes are included in all dashboard totals.

Step 4 — Dashboard Filtered

Dashboard refreshed after applying a month + single scope filter — all panels update to reflect the narrowed selection.
