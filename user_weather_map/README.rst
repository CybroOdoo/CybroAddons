User Weather Notification
=========================
The User Weather Notification app shows each user the current weather for
their location in the Odoo systray, using data from OpenWeatherMap.

Key Features
------------

* Shows the current weather in the systray
* Per-user OpenWeatherMap API key
* Manual (city) or automatic location

Installation
============
- Install the Python package ``geocoder`` (``pip install geocoder``).

Configuration
=============
- Create an account on OpenWeatherMap and copy your API key from "My API Keys".
- Go to Settings > Users, open a user and fill in the Weather Settings page:
  the API key and the location (manual city or automatic).
