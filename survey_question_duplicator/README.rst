Survey Question Duplicator
============================
This module lets users copy questions from one survey into one or more other surveys.

Key Features
------------
* Select and copy multiple questions at once.
* Copy question settings, suggested answers, and matrix rows.
* Preserve conditional display rules when their triggering question is also copied or exists in the destination survey.
* Prevent duplicate question titles in destination surveys.

Installation
------------
The module depends on the Odoo Survey application.

Configuration
-------------
No additional configuration is required.
