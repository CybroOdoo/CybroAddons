Frequently Asked Questions

What does the POS Discount Manager Approval module do?

This module allows businesses to set employee-specific discount limits in Odoo POS. If a discount exceeds the assigned limit, it requires a manager's approval through a secure PIN system.

How do I assign discount limits to employees?

You can set individual discount limits for each employee directly from the POS configuration settings. Once set, any discount exceeding this limit will prompt a manager approval.

What happens if an employee applies a discount above their limit?

When a discount exceeds the limit: The system will request the manager’s PIN. If the correct PIN is entered, the discount is approved, and payment can proceed. If the wrong PIN is entered, an error notification appears and the discount is denied.

Is the approval process secure?

Yes, only users with the correct manager PIN can authorize high-value discounts, ensuring that unauthorized discounting is prevented.
