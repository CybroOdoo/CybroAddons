POS Multi Currency Payment
==========================

This module allows POS payments in multiple currencies with real-time currency conversion.

Key Features
------------

* Administrators can set allowed currencies separately for each POS shop.
* See the converted amount using Odoo currency rates as soon as a currency is selected.
* Administrators control which currencies are available at each POS shop.
* Apply Payment adds a payment line with the converted amount, ready for validation.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
