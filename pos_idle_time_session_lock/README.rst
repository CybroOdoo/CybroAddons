POS Idle Session Lock
=====================
* This module allows a POS user to lock the POS screen when the terminal remains idle.

Key Features
------------
* Provides reliable protection for your POS session.
* When the screen is idle, the session is automatically locked.
* The user can enable and configure the lock in the Point of Sale shop configuration.

Installation
------------
No external dependencies.

Configuration
-------------
* Open Point of Sale -> Configuration -> Point of Sale (or click the three dots on the shop card in the POS Dashboard).
* Select your Point of Sale shop and open the "Configuration" tab.
* Enable "POS Idle Screen Lock" and specify the timeout limit in minutes.
