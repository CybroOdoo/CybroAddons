Answers Before You Install

Q
Which Odoo versions and editions are supported?
A
This module is built for Odoo 20. It depends only on the Inventory and Expiration Dates apps, which are part of Odoo Community.
 
Q
Is any configuration needed in settings before running the report?
A
Yes. In Inventory > Configuration > Settings, enable Lots & Serial Numbers. The Expiration Dates option then appears under Traceability. Enable it so that expiration dates are tracked on lots.
 
Q
Can I filter the expiry report for specific products?
A
Yes. When you choose Product Wise tracking in the wizard, a Product selection field becomes visible allowing you to add one or multiple products to filter.
 
Q
Does the report include lots with zero quantity on hand?
A
No. Only lots whose On Hand Quantity is greater than zero are listed, so empty lots are left out of the report.
