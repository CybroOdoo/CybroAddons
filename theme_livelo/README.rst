Theme Livelo
==========
* Design Web Pages with Theme Livelo

Configuration
=============
Product configuration-
go to product -> property details -> enable is Property -> avaliable in property list (shop)
Create a property as a product by by giving a sales person and enable is_property so that
product will be appearing in the property list.

Lead Creation-
product -> property details -> set sales person -> under property details -> fill contact seller -> lead generation
After adding sales person in the property, in the property details page , we can see contact seller form,
after filling the form, a specified lead will be generated in the crm module

NOTE: This theme implements a custom shop page, making it incompatible with the default odoo’s shop page.

Installation
============
   - www.odoo.com/documentation/18.0/setup/install.html
