POS Direct Kitchen Print
========================
POS Direct Kitchen Print facilitates instant printing of order tickets to kitchen printers via PrintNode upon order submission from Point of Sale.

Configuration
-------------
1. Install the ``printnodeapi`` Python package.
2. Install and launch the PrintNode Client application:
   * Visit https://www.printnode.com/en/download
   * Download and install the client for your operating system.
   * Sign in to your PrintNode account and connect your printers.
3. Generate an API Key in your PrintNode account profile.
4. In Odoo, navigate to **Settings -> POS Direct Kitchen Print**.
5. Enter your PrintNode API Key and click **Check available printers** to synchronize printers.
6. Under **Point of Sale -> Configuration -> Kitchen Printers**, configure your kitchen printers, assign them to your POS configurations, and specify the routed product categories.
