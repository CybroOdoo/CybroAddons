Cookie Consent Manager
======================
Manage and customize website cookie consent templates

Key Features
------------
* Helps to customize your own template for cookie.

Installation
------------
No external dependencies.

Configuration
-------------
1. Navigate to **Website** -> **Configuration** -> **Cookie Settings** to create and customize cookie templates.
2. In **Website** -> **Configuration** -> **Settings**, under the **Website Info** section, enable **Cookies Bar** and select your desired **Cookie Template**.
