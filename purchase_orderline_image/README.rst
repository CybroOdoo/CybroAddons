Purchase Order Line Images
==========================

The Purchase Order Line Images module allows users to view product images directly in purchase order lines and printed purchase reports. It enhances visual clarity during order creation, review, and supplier correspondence for both Requests for Quotation (RFQ) and confirmed Purchase Orders (PO).

Key Features
------------

* Displays product thumbnail images directly in Purchase Order and RFQ line items.
* Full compatibility with Odoo 20's purchase order list view layout.
* Shows product images in printed PDF reports for Requests for Quotation and Purchase Orders.
* Central configuration setting to easily toggle image visibility in lines and reports.

Installation
------------
No external dependencies.

Configuration
-------------
To enable or disable product images in purchase order lines and reports:

1. Navigate to **Purchase > Configuration > Settings**.
2. Under the **Orders** section, locate the **Show Product Image** option.
3. Enable or disable the checkbox as needed.
4. Click **Save**.
