OpenAI API Key Configuration

Configure the OpenAI API key securely in General Settings > Integrations (provided by the OpenAI Odoo Base foundation module).

Quick Action Menu

Open the Actions menu directly on any product template and select "Generate Image Using OpenAI" to initiate image creation.

Product Image Generation Wizard

Specify your prompt description, choose the number of images to generate (1 to 4), select resolution (1024x1024, 1024x1536, or 1536x1024), and set Low, Medium, or High quality.

Frequently Asked Questions

Q
Is this module compatible with Odoo 20 Community and Enterprise?
A
Yes. It is fully built and tested for Odoo 20 Community Edition and also operates flawlessly on Odoo 20 Enterprise, Odoo.sh, and On-Premise installations.
 
Q
What dependencies or configurations are required?
A
The module depends on openai_odoo_base and requires the official openai Python library (installable with pip install openai). Set your API key in General Settings under the Integrations section.
 
Q
Who can generate images and update products?
A
Only authorized users with the Product / Administrator access group can trigger image generation and assign the suggested visual as the main product image.
