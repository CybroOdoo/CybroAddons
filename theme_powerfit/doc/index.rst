=================
Theme PowerFit
=================

Premium Fitness & Gym Odoo Theme with modern animations, responsive layouts, customizable sections, and drag-and-drop snippets perfectly tailored for fitness centers, gyms, and personal trainers.
Personal trainers  can be managed via Employee module in odoo.

Installation
============

To install this module, you need to:

Download the module and add it to your Odoo addons folder. Afterward, log on to
your Odoo server and go to the Apps menu. Trigger the debug mode and update the
list by clicking on the "Update Apps List" link. Now install the module by
clicking on the install button.

Upgrade
============

To upgrade this module, you need to:

Download the module and add it to your Odoo addons folder. Restart the server
and log on to your Odoo server. Select the Apps menu and upgrade the module by
clicking on the upgrade button.

Configuration
=============

To further customize the theme, several settings are available directly in your Odoo backend:

1. **Gym Trainers**:
    Go to the **Employees** app.
    Check the "Gym Trainer" box on any employee's profile to automatically display them on the website.
    You can also configure their bio, experience, client count, star rating, and social media links from here.
2. **Membership Plans**:
    Go to your **Products** (via Sales or Website app).
    Check the "Gym Plan" box on a product to turn it into a membership plan on the website.
    You will see a new "Membership Details" tab where you can select its category (Basic, Standard, or Premium) to control its styling, and list the plan's features to display on the pricing card.
