Simplified POS
==============
This module provides all aspects of POS on a single page in Odoo.

Key Features
------------
* Choosing products, confirming an order, and making a payment all on the same page.
* Streamlined single-screen workflow for fast retail checkout.
* Interactive receipt printing and order confirmation popups.

Architecture & Security
-----------------------
* Built using Odoo 20 OWL components and Point of Sale extension architecture.
* Declares standard Point of Sale user access rights in security/ir.access.csv.
* Operates seamlessly with standard Odoo Point of Sale models.

Installation
------------
No external dependencies.

Configuration
-------------
* No additional configuration is needed.
