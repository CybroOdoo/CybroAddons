Odoo Icecat Connector for Odoo 20

This module helps to retrieve rich product information and high-resolution images from Icecat and display them seamlessly on your Odoo eCommerce website shop.

KEY HIGHLIGHTS

Product Details Retrieval

The core feature of the module is the ability to fetch detailed product information from Icecat using the product code and brand specified in Odoo. This includes specifications, images, descriptions, and other relevant details.

 

Efficient Data Retrieval

Optimized for streamlined product data retrieval directly from Icecat's open database, delivering accurate product specifications, technical details, and images smoothly on demand.

 

User-Friendly Configuration

A user-friendly configuration interface within Odoo that allows administrators to easily set up and manage the connection to Icecat by simply entering their Icecat User ID in Website Settings.

 

Community & Enterprise

Fully compatible with both Community and Enterprise Editions of Odoo 20, as well as deployment on Odoo.sh and On-Premise environments.

 

On-Demand Image Fetching

Fetch high-resolution product images on demand via the product form view, and stream rich live datasheets directly to your webshop.

 

No Database Load

Minimizes database overhead in Odoo by leveraging Icecat Live client-side rendering for rich media, manuals, 3D tours, and datasheets on demand without storing redundant data.

Screenshots Feature Matrix Frequent Questions Release Notes

Set User Name on Odoo

First, configure your Icecat User ID in Website Settings. Go to Settings --> Website --> Website Info --> Icecat User ID. Ensure that you have entered the correct Icecat username; otherwise, no product information will be available on the website shop.

Copy Content from Icecat

Please visit the Icecat website and navigate to the desired product. Subsequently, retrieve the Product Code and Brand information by copying the relevant details from the product page.

Add Details on Product

Create or import the product in Odoo, specifying the Internal Reference as the Product code from Icecat, and associating the Brand of the product with the corresponding Brand information in Icecat. Click the "Fetch Icecat Image" button to immediately pull the official product image.

Open Product from Website

You can view the comprehensive details of the product on the website shop. All specifications, high-res images, interactive galleries, user manuals, and multimedia displayed originate directly from the Icecat database.

Answers Before You Install

Q
Can we import and export products?
A
No, this module does not export products back to Icecat. It retrieves and dynamically displays complete specifications, high-resolution images, and interactive datasheets for products on your website shop.
 
Q
Is this only available on Odoo 20?
A
This module is certified for Odoo 20 Community, Enterprise, and Odoo.sh. Compatible versions are also available for earlier Odoo releases from version 16 onwards.
 
Q
What is required to fetch product information from Icecat?
A
You need an active Icecat User ID entered in Website Settings, along with the Brand and Internal Reference (matching the Icecat manufacturer part code) specified on the Odoo product template.
