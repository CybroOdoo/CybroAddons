Product Brand In Invoicing
==========================

* This module allows you to manage product brands and analyze invoice reports by brand.

Key Features
------------

* Manage product brands with custom logos.
* Assign product brands directly on product templates.
* Search and group products by brand.
* Group and filter invoice analysis reports by brand in pivot and graph views.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
