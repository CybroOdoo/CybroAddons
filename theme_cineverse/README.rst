Theme Cordage
=============
* Theme CineVerse Theme for Odoo 19 Website

Overview
========
CineVerse is a premium Odoo 19 theme designed specifically for cinemas, luxury theaters, and entertainment venues. It transforms the standard Odoo website into a highly immersive, cinematic experience featuring interactive 3D elements, dynamic animations, and a rich, dark-mode visual identity.
