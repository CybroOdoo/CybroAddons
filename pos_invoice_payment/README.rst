POS Invoice Register Payment
============================

Create payments for customers and register payments for their invoices directly
from the Point of Sale.


Key Features
------------

* Register invoice payments from the POS.
* Create customer payments from the POS.
* Community & Enterprise Support.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
