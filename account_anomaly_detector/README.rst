AI Anomaly Detection
====================
AI-driven anomaly detection for accounting: real-time GL scanning, duplicate detection, and spending pattern analysis


Key Features
------------

* AI-powered analysis of journal entries to detect duplicate records and spending anomalies.
* Complete internal auditor dashboard with real-time alerts
* Powerful investigation escalation workflow seamlessly routing high-risk anomalies to Audit Managers.
* Distinct user access roles designed for Auditors including Viewer, Investigator, and Manager profiles.

Installation
------------
* No external Python dependencies required.

Configuration
-------------
* Navigate to Invoicing / Accounting -> Settings -> Anomaly Detection to configure detection parameters, automated scan frequency, notifications, and excluded accounts/partners.
