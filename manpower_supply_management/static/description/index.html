Key Highlights

Labour Supply Contract Creation

Create and manage manpower supply contracts by defining skills required, number of workers, contract period, and worker rates — with automatic amount calculation.

Worker Profiles & Skill Management

Maintain detailed worker records, including skills, availability, and assignment history, making it easy to allocate the right workers to each contract.

Smart Contract Dashboard

Access an interactive dashboard displaying active contracts, invoiced and expected amounts, worker availability, and contract statistics through charts and tables.

Skill-Based Worker Search

Easily locate suitable workers using skill-based filtering, ensuring the best match for each manpower requirement.

Automated Invoice Creation

Generate customer invoices directly from manpower contracts with a single click — and track them via smart buttons.

Contract Lifecycle Tracking

Contracts automatically update their status to Expired based on the end date, ensuring accurate lifecycle management.

PDF Contract & Report Generation

Generate professional PDF reports filtered by customer or contract state for documentation and business review.

Website Application Form

Customers can submit manpower requests online, automatically creating backend records for processing.

User Authorization Setup

From the Users form view, enable the option “Manage Manpower Supply Management” to grant access to manpower contract and worker management features.

Dashboard Overview

The Dashboard provides a complete business overview, including: • Currently active contracts • Total invoiced & expected revenue • Worker availability Data is displayed using bar charts, tables, and pallet views for easy monitoring.

Contract Status Trend Chart

A line chart displays manpower contracts categorized by status (such as Active, Completed, or Expired), helping you analyze contract movement over time.

Create Labour Supply Contract

Under the Labour Supply menu, create a new contract by defining: • Required skill • Number of workers • Contract duration • Worker rate This allows structured manpower planning per client requirement.

Fetch Available Workers by Skill

Once skills are selected, the system automatically fetches workers matching the required skillset and lists them for assignment to the contract.

Automatic Contract Amount Calculation

The total contract value is automatically calculated based on: • Worker rate • Number of workers • From & To dates Ensuring accurate billing and time-based costing.

Create Invoice from Contract

Click CREATE INVOICE to generate a customer invoice directly from the manpower contract. A smart button allows quick access to the created invoice record.

Automatic Contract Expiry

When the contract reaches its end date, the system automatically updates its status to Expired, ensuring accurate lifecycle tracking.n.

PDF Report Wizard — Customer Filter

Generate manpower reports in PDF format using a wizard that allows filtering based on specific customers, making reporting more targeted.

PDF Report Wizard — State Filter

Reports can also be generated based on contract state, helping management review active, completed, or expired contracts separately.

Online Application Form (Website)

Customers can submit manpower requirements via an online website form, which automatically creates a backend manpower request.

Customer Portal View

Clients can log into the Customer Portal to view their manpower contracts and related details securely.

Frequently Asked Questions

Can I create manpower supply contracts directly in Odoo?

Yes. You can create labour supply contracts by defining skills, required workers, duration, and worker rates — and the system will automatically calculate the total contract amount.

Key Features:
  • Contract-based manpower planning
  • Auto-calculated contract value
  • Structured contract management

Is it possible to search and assign workers based on their skills?

Yes. Workers can be easily filtered and assigned based on skill categories, ensuring the right workforce is allocated to the right contract.

Key Features:
  • Skill-based worker search
  • Worker availability management
  • Accurate resource allocation

Can I generate invoices from manpower contracts?

Absolutely. You can create customer invoices directly from the contract using the Create Invoice button, and track them via a smart button.

Key Features:
  • One-click invoice creation
  • Linked invoice tracking
  • Smooth billing workflow
