Manpower Supply Management
==========================

A module that helps manpower supply companies manage contracts, workers and invoicing.

Key Features
------------

* Community & Enterprise Support
* Labour Supply Contracts
* Automatic Invoice Creation
* Skill-Based Worker Allocation
* Worker Profile & Availability
* Smart Dashboard
* Contract Value Auto-Calculation
* Automatic Contract Expiry
* PDF Reports with Filters
* Website Request Form
* Customer Portal Contract View

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
