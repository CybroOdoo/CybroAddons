Odoo Module Health Report
=========================
This module allows you to display Odoo app module details and print them as a PDF report.

Key Features
------------

* Effortless Module Quality Evaluation
* Author-Based Code Statistics
* Detailed Code Quality Checks

Installation
------------
Install the required Python dependencies:

.. code-block:: bash

    pip install -r requirements.txt

The following code quality and analysis tools are required:

* ``isort``
* ``black``
* ``bandit``
* ``radon``
* ``pylint``
* ``pylint-odoo``
* ``flake8``

Configuration
-------------
No additional configuration is required.
