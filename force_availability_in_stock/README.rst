Force Availability Button in Delivery
=====================================

Add a **Force Availability** button to stock pickings. The button sets each
stock move's quantity to its demand and marks the picking as ready for the next
step in the delivery workflow.


Key Features
------------

* Force Availability in Delivery
* Update Done Quantities
* Update stock move quantities with one click

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
