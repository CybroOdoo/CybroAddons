Multi Barcode for Products
==========================

Multi Barcode for Products module allows users to configure multiple alternate barcodes for a single product or product variant in Odoo 20. It streamlines barcode scanning across Sales, Purchase, Inventory, and Invoicing operations.

Key Features
------------

* Configure multiple alternate barcodes for products and variants.
* Barcode uniqueness validation preventing duplicates.
* Scan alternate barcodes directly in Sale Order lines.
* Scan alternate barcodes directly in Purchase Order lines.
* Scan alternate barcodes in Customer Invoices and Vendor Bills.
* Scan alternate barcodes in Stock Picking and Delivery Orders.
* Seamless barcode search in product search view.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
