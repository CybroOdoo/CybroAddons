Oil & Gas Custody Transfer
==========================
* Introduces a workflow-centric custody transfer engine that sits above inventory movement.
* It separates legal ownership from physical custody and operational responsibility.
* Supports a configurable approval workflow and links into the existing transfer, gate pass and pipeline modules.
* Provides planned vs actual quantities with loss/gain tracking.

Configuration
=============
No configuration required after install. Default transfer types are loaded.
