Sale Order Custom Fields
========================

This module enables users to generate custom fields in Sale Order without coding.

Key Features
------------

* Generate Customized Fields in Sale Order Without the Need for Coding.
* You Can Select Widgets Based on Field Types.
* Can Easily Adjust the Position of Fields.
* Effortlessly Apply Filters to the Dynamically Generated Fields via the Settings.

Installation
------------
No external dependencies.

Configuration
-------------
- After installation, go to Settings - Users & Companies.
- Select any user and enable the checkbox Create Custom Fields in Sale.
