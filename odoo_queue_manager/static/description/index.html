Frequently Asked Questions

Can customers book tokens in advance?

Yes. The Token Booking feature allows customers to generate tokens for the required department, helping reduce waiting time and improve customer flow.

Can multiple departments manage their queues independently?

Yes. Each department can have its own queue, token sequence, counters, and operators, allowing multiple departments to serve customers simultaneously.
