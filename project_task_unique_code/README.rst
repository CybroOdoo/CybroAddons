Project Task Unique Code
========================

This module helps you to track each task with a unique code that is
generated automatically from a short code set on its project.

Key Features
------------

* Set a Short Code on each project, unique per company.
* Creates a sequence for every project automatically.
* Each new task gets a unique code such as ``PRJ-001``.
* Shows the unique code on the task form, list and kanban views.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required. Enter a Short Code when creating
a project.
