Product Restriction Users
=========================

This module restricts product and product category access for specific users, ensuring users only view and handle allowed items.

Key Features
------------

* Restrict product visibility per user or user group.
* Configure restriction types based on allowed products or allowed product categories.
* Prevent unauthorized users from viewing or selling restricted items.

Installation
------------
No external dependencies.

Configuration
-------------
Set a Restriction Type and choose allowed products/categories under Settings -> Users.
