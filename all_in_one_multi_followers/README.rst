All in One Multi Followers
==========================
The module is used to add or remove multiple followers across all Odoo models
by dynamic actions. If you want to set multiple followers in your model,
it helps you select multiple followers directly when clicking the action.
After adding or removing the followers, it immediately updates the target records.
In this way, you can add or remove multiple followers across all Odoo models quickly.

Key Features
------------

* Multi-Model Compatibility
* Bulk Follower Actions
* Automated Email Notifications
* Dynamic State Management

Installation
------------
No external dependencies.

Configuration
=============
* Navigate to Settings -> General Settings -> Dynamic Followers and click 'Go to Model' to create a dynamic action for any desired model.
