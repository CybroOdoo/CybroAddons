Answers Before You Install

Q
Does this module support Odoo 20 Community Edition?
A
Yes, it is fully certified for Odoo 20 Community Edition and also works with Odoo 20 Enterprise deployments on Odoo.sh or on-premise installations.
 
Q
How do I give a user access to front office operations?
A
Assign the user to the Front Office / Receptionist role from the user access rights.
 
Q
Can the module print visitor and property records?
A
Yes. Print visitor passes, visitor activity reports, and property labels from their corresponding records.
