ZPL Label Designer
====================
Design professional ZPL labels directly in Odoo with a powerful click and add interface, dynamic field mapping, and real-time preview.

Key Features
------------

* Click & Add Editor
* Dynamic Field Mapping
* Properties Sidebar
* Text, barcode, QR code, line, rectangle and image elements
* Labels sized in millimetres or inches at 203, 300 or 600 DPI


Installation
------------
The Fabric.js library used by the designer is bundled with the module, so no external dependencies or internet access are required.

Configuration
-------------
No additional configuration is required.

Usage
-----
Open the **ZPL Designer** app and create a template. Choose the Odoo model, the label size and the DPI. Add elements in the Designer tab and save the design. To print, open the print labels wizard on a product, select the ZPL Label Designer format and choose the template.
