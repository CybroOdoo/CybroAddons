Ecommerce Sequential Variant Selector
================
This module enables customers to select product attribute values from the
website in an ordered manner. It allows customers to choose attribute values one
by one.

Key Features
------------
* **Sequential Attribute Selection**: Enforces choosing product attributes in an ordered, step-by-step sequence (e.g., Color -> Size -> Material) on the eCommerce product page.
* **Dynamic Option Unlocking**: Automatically unlocks downstream attributes one at a time as preceding attributes are selected, preventing premature or invalid choices.
* **Full Re-selection on Completion**: Unlocks all attribute lines once a complete variant combination is configured, allowing shoppers to review and readjust any option.
* **Multi-Display Type Support**: Fully compatible with all native Odoo variant display types, including radio buttons, color swatches, visual pills, and dropdown lists.
* **Real-time Price & Image Sync**: Preserves native Odoo combination recalculations, ensuring live price updates, extra price badges, and variant image switching work smoothly.
* **Modern Odoo 20 Interaction Architecture**: Built on the native Odoo 20 Interaction framework for reactive, lightweight client-side execution.
* **Zero Configuration Setup**: Works out of the box with your existing product templates, attribute sequences, and eCommerce themes.
