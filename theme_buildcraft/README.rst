Theme BuildCraft
================
A construction company theme for the Odoo 17 website, with home, about,
services, projects, team, blog and contact pages, and building blocks for the
website editor.

Configuration
=============
Choose the BuildCraft theme in the Website app. The projects shown on the
Projects page are managed in the BuildCraft Projects menu by the website
designers.
