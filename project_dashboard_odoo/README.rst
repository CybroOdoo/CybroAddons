Project Dashboard
================
In this dashboard, users can get a comprehensive, real-time performance view of projects, tasks, timesheets, margins, and sales.

Key Features
------------
* **Comprehensive Project KPI Cards**: Real-time metrics for Total Projects, Total Tasks, Top Employees, Hours Recorded, Total Sale Orders, Total Margin, and Billed Hours.
* **One-Click Drill-Down Navigation**: Direct navigation from KPI tiles to underlying records (Projects, Tasks, Sales Orders, Timesheets, and Employees).
* **Rich Project Kanban & List Views**: Total Projects drill-down opens the standard rich Kanban view with milestone progress, task counts, avatars, and Kanban/List view toggles.
* **Financial Margin & Profitability Tracking**: Real-time margin calculation from timesheet revenues and labor costs, with drill-down access to List, Pivot, and Graph views.
* **Dynamic Multi-Level Filtering**: Filter dashboard metrics and charts by Project, Employee, and custom Date Ranges (Start Date to End Date).
* **Interactive Visual Charts**: Donut chart displaying Project Task Analysis by stage and bar chart showcasing Top Employees by recorded timesheet hours.
* **Real-Time Task Overview Table**: Tabular view displaying task name, project, and stage with direct click-to-open row navigation to task forms.
* **Multi-Company Compatibility**: Seamless data isolation respecting active company selections in multi-company setups.
* **Modern Neumorphic UI**: Clean, responsive aesthetic built with Owl framework and native Odoo 20 Oi icons.
