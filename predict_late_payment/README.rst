Predict Late Payments
=====================
This module helps you analyze customer invoice and payment history to forecast the likelihood of delayed payments.

Configuration
=============

Step 1 — Get a Gemini API key
-----------------------------
1. Go to https://aistudio.google.com/apikey
2. Sign in with your Google account
3. Click **Create API key** → Copy it

Step 2 — Configure in Odoo
--------------------------
Settings → General Settings → Payment Risk AI
→ Paste API key → Select model → Save → Test Connection

Step 3 — Run scoring
--------------------
Accounting → Payment Risk → Compute All Scores
