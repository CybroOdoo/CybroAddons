Create OpenAI API key

To generate an OpenAI API key, start by creating a free account at https://beta.openai.com/signup. Once signed up, go to the 'API keys' section in the menu and click on 'Create new secret key'.

Configure the API

Now go to General Settings of odoo and fill your API key in settings.

Generate Product Internal Notes From Tags

Click 'Generate Internal Note from Tags Using OpenAI' from actions in product form. Make sure tags are added.

Internal Notes Created Based On Tags

Internal notes of product will be generated in the internal notes of product form based on assigned tags.

Generate Product Tags From Internal Notes

Click 'Generate Tags from Internal Note Using OpenAI'. Make sure product internal notes is not empty.

Tags Generated Based On Internal Notes

Tags will be generated based on internal notes of the product.

Generate Tags And Internal Notes From Product List View.

You can also generate tags and internal notes for multiple products at once from the product list view.

Frequently Asked Questions

Can I generate only tags or only descriptions?

Yes. The module allows you to generate only product tags or only product descriptions. You can also generate both tags and descriptions together, based on your configuration requirements.

Is the generated content editable?

Yes. All generated tags and descriptions remain fully editable after generation.

Does this module require an internet connection?

Yes. You must provide a valid OpenAI API key in the module configuration to enable content generation.
