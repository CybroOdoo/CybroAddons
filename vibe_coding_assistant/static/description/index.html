KEY HIGHLIGHTS

Discuss-Style Chat Flow

Users describe the module they want in natural language and receive generated Odoo addon output directly in a conversation thread.

Revision and Refinement Support

Existing generated modules can be refined in the same conversation. Each refinement is stored as a new revision linked to the previous output.

Static Validation Before Download

The generated addon is checked for manifest structure, Python syntax, XML well-formedness, model init imports, and access file presence.

Inline File Editing

Generated files can be reviewed and edited from the preview panel, with module validation re-run after each save.

Downloadable Addon Packaging

All generated files are packaged into a module ZIP under the technical module name, ready for deployment to an addons path.

Per-User Provider Settings

Each user keeps their own API keys and active model selection. Record rules isolate provider configs and generated artifacts per user.

Usage and Token Tracking

Token usage is tracked per assistant message, aggregated by conversation, and exposed in user forms and the admin dashboard.

Admin Analytics Dashboard

System administrators can review conversation volume, provider usage, validation quality, downloads, and top users.
