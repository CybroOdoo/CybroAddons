Odoo Vibe Coding Assistant
==========================

Chat with AI to generate downloadable Odoo 20 modules.

Key Features
------------

* Multiple AI Provider Adapters
* Discuss-Style Chat Flow
* Ready-to-Extract Addon Package
* Static Validation Before Download
* Inline File Editing
* Revision & Refinement Support

Installation
------------
The Python package ``requests`` is required (bundled with a standard Odoo installation).

Configuration
-------------
Configure the API key of your desired AI provider.
