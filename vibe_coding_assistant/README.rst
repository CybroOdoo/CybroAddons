Odoo Vibe Coding Assistant
==========================
* Chat with AI to generate downloadable Odoo modules

Installation
============
* Download the module and add it to your Odoo addons folder.
* Restart the Odoo server.
* Enable Developer Mode, go to Apps and click **Update Apps List**.
* Search for the module and click **Install**.

Configuration
=============
* No additional configuration is required.

Usage
=====
* Install the module and open the related menu to start using it.
* See the HTML description for screenshots and a step-by-step walkthrough.
