Scroll Button In Website
========================

Adds dynamic scrolling buttons to website pages, enabling visitors to easily scroll from bottom to top and vice versa.

Key Features
------------

* Floating scroll-to-top and scroll-to-bottom buttons on website pages.
* Smooth scrolling animation for enhanced user experience.
* Automatically appears when scrolling down past a threshold.
* Mobile-responsive and customizable styling.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
