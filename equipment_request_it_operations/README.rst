Equipment Request & IT Operation
================================
Employees can request equipment and claim equipment damage expenses. Each
request is approved by the Department Manager and then the HR Officer, after
which the Stock Manager creates the internal transfer for the equipment.

Configuration
=============
* Go to Settings --> Users and assign the Equipment access levels (Department
  Manager, HR Officer, Stock Manager or Manager) to the relevant users.
