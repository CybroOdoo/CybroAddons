Sign In to Google Contacts

Sign in with your Google Account. To generate Google Contact API credentials, navigate to the Google Cloud Platform Console and click Enable APIs and Services.

Search for Google People API

In the API Library search box, search for the Google People API to enable contacts management.

Enable Google People API

Select the Google People API from the search results and click the Enable button to activate it for your project.

Create Credentials

Click on the Create Credentials button to start the OAuth credential generation process.

Select API & User Data

Choose Google People API and select the User Data option to allow access to user contacts, then click Next.

Configure OAuth Consent Screen

Enter your application name, support email address, and developer contact information, then click Save and Continue.

Configure OAuth Scopes

Verify OAuth scopes for Google Contacts integration, then click Save and Continue to proceed to client setup.

Set Application Type to Web Application

Under Application type, select Web application and provide a descriptive name for your OAuth client.

Configure Authorized URIs

In Authorized JavaScript Origins, enter your Odoo company URL. In Authorized redirect URIs, enter your Odoo URL followed by /google_contact_authentication.

Generate API Credentials

Upon successful generation of the Google People API credentials, your OAuth Client ID and Client Secret are created.

Client ID and Secret Key

View and copy your Client ID and Secret Key to use in your Odoo Company settings.

Grant Access to Authorized Users

Add test user email addresses who will authenticate and synchronize contacts with the Google app.

Configure Credentials in Odoo

In Odoo, navigate to Settings > Users & Companies > Companies. Open your company, select the Google Contact tab, enter the Client ID, Client Secret, and Redirect URL, then click Authenticate.

Sync with Google Contacts

After successful authentication, you can now synchronize Google Contacts seamlessly with Odoo.

View Contacts in Google Contacts

View your full contacts list directly inside Google Contacts with organized details.

Import Contacts into Odoo

Go to Settings > Companies > Google Contact tab and click the Import Contacts button to fetch all Google contacts into Odoo.

Contacts Imported into Odoo

Imported contacts now populate your Odoo Contacts address book with complete profile information.

Export Menu in Odoo

Select contacts in Odoo that need to be exported, open the Action menu, and click on the 'Export to Google' button.

Exported Contacts in Google Contacts

Verify that exported contacts from Odoo appear instantly in your Google Contacts account.

Unified Delete Menu

Select contacts to remove from both platforms and click 'Delete G-Contact'. If a partner is referenced by another Odoo record, it safely deletes only from Google.

Contact Removed from Google Contacts

Verify that deleted contact records are cleanly removed from Google Contacts.

Filter by G-contacts

Click the Filter by 'G-contacts' option in the search bar to filter synchronized contacts effortlessly.

Filtered Synced Contacts List

View all partners currently synchronized between Google Contacts and Odoo in one organized list view.

Answers Before You Install

Q
Does this module support both Odoo Community and Enterprise?
A
Yes, it is fully certified for Odoo 20 Community Edition and also operates flawlessly on Odoo 20 Enterprise and Odoo.sh. No proprietary Enterprise license is required because it only depends on the core Contacts application.
 
Q
Can I import Google Contacts into Odoo and export Odoo contacts back to Google?
A
Yes, the module supports robust two-way synchronization. You can import contacts from Google into Odoo with a single button click, and export selected Odoo partners back into your Google Contacts directory.
 
Q
What setup is required before I can sync contacts with Google?
A
Before syncing, you enable the Google People API in the Google Cloud Console, generate your OAuth Client ID and Client Secret, configure the Redirect URI, enter them in Odoo Company settings, and authenticate your Google account.
