=======================================
Waste Management Collection & Inventory
=======================================
Comprehensive collection operations, route optimization, and waste inventory management for Odoo 19.

* End-to-end collection order lifecycle from draft to scheduled, in-progress, completed, or missed.
* Route optimization and interactive Leaflet map views with real-time waypoint rendering.
* Pre-trip and Post-trip vehicle inspection checklists integrated with Odoo Survey module.
* Automated vehicle breakdown failover and standby vehicle reassignment.
* Waste batch inventory management, container tracking, sorting lines, and valuation reporting.
* Automated recurring collection schedules and missed collection handling workflows.

Configuration
=============
* Configure Service Zones, Collection Points, and Routes under ``Waste Management > Collection``.
* Set up Inspection Checklist templates under ``Waste Management > Configuration > Checklists``.
* Enable automated cron jobs for route generation and missed collection notifications in ``Settings > Technical > Scheduled Actions``.
* Configure sorting and valuation rules under ``Waste Management > Configuration > Settings``.
