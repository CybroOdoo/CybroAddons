Frequent questions

Does this module work on mobile devices and tablets for field drivers?
Yes - the collection order logging interface, signature capture, and safety checklist wizards are fully responsive and optimized for mobile browser use on driver phones and tablets.
How does the interactive route map work in Odoo 19?
The module embeds a custom Leaflet-powered OWL map component showing all collection points as interactive pins, connected by sequenced route polyline segments with 1-click optimization algorithms.
What happens when a customer bin cannot be collected?
Drivers trigger the "Mark Missed" action, record the reason (e.g. Blocked Access, Contaminated Waste, Gate Locked), log internal notes, and the system automatically flags the SLA and schedules a follow-up.
Can we configure custom safety checklists for different vehicle types?
Yes, the inspection framework allows you to define distinct pre-trip and post-trip survey questions, mandatory photo uploads, and pass/fail thresholds tailored per vehicle category (e.g., compactor trucks, roll-off haulers).
How and when are waste batches created in the system?
Waste batches are generated automatically: when an entire route is marked complete, Odoo groups all completed orders by waste category and consolidates them into route-level waste batches. For standalone orders, completing the collection immediately creates or aggregates into an open category draft batch at the destination warehouse.
How are collection orders generated for daily operations?
Collection orders can be generated in three ways: (1) automatically via the contract recurrence cron based on customer frequencies, (2) automatically when adding stops to a route on the Leaflet map, or (3) manually created by dispatchers.
