Pivot AI Summary
====================
This module allows users to generate instant summaries of complex pivot tables and interact with
their data using natural language queries.

Configuration
=============
* Enable the “Enable Summary” option from Configuration Settings, select the desired AI model, and enter the API key to activate the feature.
