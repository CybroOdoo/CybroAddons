What happens when a purchase order exceeds the budget?

If a purchase order amount goes beyond the defined budget, the system checks the alert type you set on the budget line.

Do I need anything else enabled for this module to work?

Yes. Users must have Analytic Accounting enabled and the budget must be configured under Accounting → Budgets. Alerts are triggered based on the budget’s analytic distribution and the alert type configured for each budget line.
