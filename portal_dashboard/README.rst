Portal Dashboard for Odoo 19
============================
Portal Dashboard for Odoo 19 replaces the default customer portal view with an interactive, modern dashboard displaying key business metrics and recent records.

Installation
============
- https://www.odoo.com/documentation/19.0/setup/install.html
- Install our custom addon in your Odoo environment.
