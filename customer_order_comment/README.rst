Customer Order Comment
======================
This module helps you to add customer rating and comments through website.

Key Features
------------
*  Add customer rating and comments through website.
*  Review customer comment in the sale order form view.

Installation
------------
* Depends on the ``website_sale`` module.

Configuration
-------------
* Navigate to Website -> Configuration -> Settings.
* Under the "Customer Order Comment" section, enable "Customer Comment & Rating".
