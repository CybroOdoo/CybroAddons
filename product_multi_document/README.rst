Product Multi Document
======================

This module helps to attach multiple documents in product.


Key Features
------------

* Easily upload and manage multiple documents associated with a product.
* View attached documents directly in Purchase Order lines for better transparency and information flow.
* Product documents are automatically attached to emails sent during the Purchase Order process.
* Store and access all product-related documents centrally.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
