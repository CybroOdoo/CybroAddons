Time Off LOP
============

Deduct Loss of Pay Amount from the Payslip


Key Features
------------

* Configure Loss of Pay rules for leave taken before, after, or between public holidays.
* The module supports Odoo Enterprise and Odoo.sh.
* HR managers can configure multiple Loss of Pay structures.
* The configured percentage of daily wage is deducted from salary according to the matching leave rule.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
