Delivery Date on eCommerce
==========================

This module displays the expected delivery time of the products on the eCommerce shop page, product page and cart.

Key Features
------------

* Shop Page Display
* Product Page Display
* Cart Display

Installation
------------
No external dependencies.

Configuration
-------------
Go to *Website > Configuration > Settings* and enable *Show delivery date* under the eCommerce section. Then set the *Customer Lead Time* on each product, because the delivery time is shown only for products that have one.
