Pharmaceutical ERP
==================
Core pharmaceutical manufacturing and quality management: batch records, in-process checks, QC specifications and out-of-specification handling.

Key Features
------------
* Batch Manufacturing Record (BMR) with sequenced execution steps and operator/supervisor e-signatures.
* In-Process Quality Check (IPQC) results captured against each BMR step with expected min/max ranges.
* QC Specifications holding versioned parameter lines per product and production stage.
* QC Test Orders with result lines, automatic pass/fail evaluation and out-of-specification flagging.
* Out-of-Specification (OOS) investigation workflow covering the Phase I lab-error check and Phase II batch review.
* Yield reconciliation on the BMR, raising a QA sign-off when actual yield falls below the configured threshold.
* Role-based workflow permissions (QA, QC, Production) provided by a reusable workflow mixin.
* Pharmaceutical extensions to products, lots, quants, moves, pickings, purchase orders and manufacturing orders.
* Dedicated Pharmaceutical dashboard with custom side-bar navigation.
