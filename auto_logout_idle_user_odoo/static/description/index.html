KEY HIGHLIGHTS

Automated Idle Logout

Automatically log out inactive users after a configured duration of browser inactivity.

 

Easy Configuration

Quick to configure directly in user profiles with no technical expertise required.

 

Per-User Timeout

Each user has their own idle duration, enabled or disabled in the user profile.

 

Cross-Tab Activity

Activity in any open browser tab resets the countdown.

 

Enhanced Session Security

Helps protect unattended workstations by logging out the browser session after inactivity.

  

Idle Timer Setup

Configure session idle timeout duration directly in the user preferences.

Systray Countdown

The systray shows the time remaining before the idle logout; activity in any open tab resets it.

Automated Session Logout

After the idle time elapses the user is logged out and must sign in again.

DETAILED FEATURES

01
Automated Idle Logout
Logs out idle users once the configured inactivity time elapses. The timeout is enforced in the browser, not as a server-side session expiry.
 
02
Systray Countdown
The remaining time is always visible in the systray.
 
03
No Extra Dependencies
Relies only on standard Odoo modules — no third-party libraries required.
 
04
Version Compatibility
Built for Odoo 20.0.
 
05
Per-User Settings
Administrators can configure idle timeout durations directly within each user's profile preferences.
 
06
Configurable Duration
Set the idle time in minutes, from a minimum of 1 minute.

FREQUENT QUESTIONS

Q
Which Odoo version does this module support?
A
This module is built for Odoo 20 and tested on the Community edition.
 
Q
Do I need any additional configuration after installation?
A
Minimal configuration is required. Simply navigate to Settings > Users & Companies > Users, open a user, enable the idle timeout, and set the duration in minutes (default 15, minimum 1).
