Answers Before You Install

Q
Can users with Readonly Access create, edit, or delete records?
A
No. Users with Readonly Access are restricted from creating, editing, or deleting records in Odoo.
 
Q
Is the Readonly Access feature easy to configure?
A
Yes. The module provides an easy-to-configure setup for enabling Readonly Access for selected users.
 

Enable Readonly Access for Users.

Navigate to Settings -> Choose Users -> Enable Readonly Access.

Restrictions for Users with Readonly Access.

Users with Readonly Access enabled cannot create, edit, or delete records.

Clicking any button will trigger an access error in the system.
