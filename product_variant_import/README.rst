Import Product variant
======================
This module provides a wizard to import products and product variants using XLSX or CSV files by redirecting the uploaded file into Odoo's standard import interface. Users can create new products or update existing products and product variants using standard fields (such as char, many2one, and many2many fields).

Key Features
------------
* Convenient wizard for importing products and product variants.
* Supports both CSV and Excel (.xlsx) file formats.
* Directly redirects to Odoo's standard base import interface with automated preview.
* Seamless creation and updating of product templates and variants.

Installation
------------
* stock
* base_import

Configuration
-------------
* Assign the 'Variant Manager' group under Users & Companies to grant access to the import wizard.
