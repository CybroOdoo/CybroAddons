Quotation Customer Follow-up
============================

Automated follow-up emails for quotations and expiry notifications to customers.


Key Features
------------

* Expiry date is automatically calculated based on the user's expected days.
* Automatically email customers if the quotation has expired or the follow-up date has been reached.

Installation
------------
No external dependencies.

Configuration
-------------
* Go to Sales -> Configuration -> Settings, enable quotation follow-up and expiry emails, and select the email templates and timing in days.
* Optionally specify quotation expiry days on individual customer forms.
