Frequently Asked Questions

What does this module do?

This module allows users to view previous sale and purchase prices of a selected product for a specific customer. It helps manage pricing decisions based on historical rates.

Where can I view the previous sale/purchase rates?

A button is added to the Sale Order and Purchase Order form that, when clicked, displays a list of past sale/purchase transactions for the selected product.

Does this module change pricing automatically?

No, this module only provides historical price data. However, users can manually adjust new orders based on past rates.
