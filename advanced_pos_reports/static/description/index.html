Answers Before You Install

Q
Does this module support Odoo 20 Community Edition?
A
Yes, it is fully certified for Odoo 20 Community Edition and also operates flawlessly on Odoo 20 Enterprise and Odoo.sh. No proprietary Enterprise license is required for POS reporting operations.
 
Q
Is any configuration required to make the reports visible?
A
No configuration is required. Simply install the module, and the report actions will be automatically available on the POS screen and under Point of Sale → Reporting.
 
Q
Can I print the on-screen summaries using a POS receipt printer?
A
Yes, each summary popup includes a dedicated print button configured for standard thermal receipt printers via POS ticket printing utilities, as well as browser print dialogs.
