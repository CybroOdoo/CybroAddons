Advanced POS Reports
====================

The Advanced POS Reports module generates various reports from the Point of Sale screen and reporting menu. It allows users to view and print real-time category, order, payment, and location summaries with thermal receipt printing directly from the active POS screen, as well as generate comprehensive analytical PDF reports for ongoing sessions and top-selling products, categories, and customers.

Key Features
------------

* Ongoing Session Report gives a summary and PDF report of active Point of Sale sessions.
* Top selling Products, Categories, and Customers reports with custom date filtering.
* Payment Summary from POS Screen to get payment details of current session or across all sessions within a period.
* Order Summary from POS Screen to get all order details of current session or across all sessions within a period.
* Category Summary from POS Screen to get category-wise sales details of current session or across all sessions within a period.
* Location Summary from POS Screen to get location-wise stock details with thermal receipt printing.

Installation
------------
No external dependencies.

-------------
