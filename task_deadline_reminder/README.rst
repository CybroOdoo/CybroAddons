Task Deadline Reminder
======================

This module extends the functionality of project module to allow sending deadline reminder emails on task deadline day.

Key Features
------------

* Automated Daily Task Deadline Notifications
* Configurable Task Reminders
* Comprehensive Task Context in Reminder Mail

Installation
------------
No external dependencies.

Configuration
-------------
By default, a cron job named "Task Deadline Reminder" will be created while installing this module.
This cron job can be found in:

**Settings > Technical > Automation > Scheduled Actions**

This job runs daily by default.
