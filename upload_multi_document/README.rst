Upload Multiple Attachments From List View
==========================================

Select records in any list view and upload one or more files to all of them at once. The files are created as standard attachments linked to each selected record.

Key Features
------------

* Upload multiple documents at once from the list view.
* Attach files across multiple selected records at once.
* A paperclip button is displayed in the control panel when records are selected.
* The user needs write access on the selected records.
* Automatically creates and links standard `ir.attachment` records.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.

Usage
-----
1. Open any list view and select one or more records.
2. Click the paperclip button next to the list buttons.
3. Choose one or more files in the file dialog.

Each file is attached to every selected record. The attachments are listed in the attachments of each record.
