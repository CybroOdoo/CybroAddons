Advanced HR-LinkedIn Integration
================================

* Advanced HR-LinkedIn Integration module for Odoo 20.

Key Features
------------

* Share recruitment post to LinkedIn from Odoo.
* Retrieve count of likes and comments.
* Retrieve comments and view shared post directly.

Installation
------------
* No additional external Python packages are required.

Configuration
-------------
* Mention the LinkedIn username and password in the section
  LinkedIn Credentials under the recruitment configurations.
