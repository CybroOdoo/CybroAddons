Frequently Asked Questions

What does the Export X2Many module do?

The Export X2Many module extends Odoo's native Excel export mechanism with two powerful features: automatic child subfield selection for relational fields (One2many, Many2many, Many2one) and multi-sheet workbook generation where records can be partitioned across custom worksheet tabs using domain filters.

How does multi-sheet grouping work?

When 'Enable data grouping' is activated and XLSX format is selected, clicking Export launches the 'Apply Filters' popup. You can create multiple sheets, label them with custom tab names, and apply specific domain filters to each sheet. The backend then generates a single Excel workbook containing all filtered sheets.

What happens if 'Enable data grouping' is left unchecked?

The export proceeds as a standard Odoo export. It downloads a single-sheet Excel or CSV file without modifying standard Odoo export workflows.

Are there limitations on sheet names?

In accordance with Microsoft Excel standards, sheet tab names are capped at 31 characters. The module automatically sanitizes prohibited Excel characters ([ ] : * ? / \) and resolves duplicate sheet names to ensure generated workbooks open without errors.
