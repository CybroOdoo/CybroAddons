Duplicate Contact Details Alert
===============================
Duplicate Contact Details Alert module for Odoo 20.

Configuration
-------------
* Navigate to **Settings -> General Settings -> Contacts**.
* Enable the **Unique Contacts** option.
* Select the contact fields (e.g., Email, Phone, Mobile, VAT) to enforce uniqueness.
