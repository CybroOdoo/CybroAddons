POS Restaurant Dine-In/Take Away
================================
* This module adds the Dine-In and Take Away options in Odoo POS.
* A separate token is generated for every Take Away order.

Configuration
=============
* Open Point of Sale > Configuration > Settings for a restaurant POS and enable POS Take Away.
* Enable Generate Token to give every Take Away order a token number.
