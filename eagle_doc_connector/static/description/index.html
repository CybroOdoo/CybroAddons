Frequently Asked Questions

What file formats can I upload for OCR processing?

You can upload PDF and common image formats. Multiple files can be uploaded together as a batch, and their processing status can be tracked from the batch monitor.

What happens if the extracted total doesn't match Odoo's computed total?

A warning banner is displayed on the invoice comparing Eagle Doc's extracted total against Odoo's computed total, and the discrepancy is logged in the chatter for audit purposes. The check is re-run when the invoice is posted.

Who can upload and sync documents?

Upload and sync actions are restricted to users with the Accounting/Invoicing access group. Automated cron and batch sync jobs run independently of individual user permissions.
