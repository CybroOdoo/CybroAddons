Advanced Cash Flow Statements
=============================

The Advanced Cash Flow Statements module for Odoo provides comprehensive cash flow reporting across four hierarchical levels. It enables organizations to monitor cash inflows and outflows effectively, analyze specific date periods, filter by posted or draft journal entries, and generate reports in both PDF and Excel (XLSX) formats.

Key Features
------------

* Four levels of Cash Flow Statements: Summary, Consolidated, Detailed, and Very Detailed.
* Dual format reporting: Print and download reports in both PDF and XLSX formats.
* Intuitive report wizard with configurable date ranges and target move filters.
* Filter reports by 'All Posted Entries' or 'All Entries' (excluding cancelled).
* Clear breakdown of Operating, Investing, and Financing cash flow activities.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
