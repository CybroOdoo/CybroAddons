Customized Barcode Generator
============================
This module enables the user to print customized product labels.

Key Features
------------

* Print the product cost on product labels as an encoded code.
* Define a substitute character for each digit from 0 to 9.
* Keep only one code rule active at a time.
* Optionally print the product reference next to the cost code.
* Works with the 2 x 7, 4 x 7, 4 x 12 and Dymo label formats.

Installation
------------
No external dependencies.

Configuration
-------------
* Go to Invoicing > Configuration > Settings > Product Labels.
* Enable 'Standard Price as a Code' and, if needed, 'Show Product Reference'.
* Click 'Barcode Code', set a character for each digit and mark the rule
  as Active.
