Infinito Plus Backend Theme
===========================
Infinito Plus extends the Infinito Backend Theme for Odoo 19 with
additional customization options, including font selection, animations,
chatbox positioning, view refreshing, and language switching.

Installation
============
- Install the module from the Apps menu.
