Task Overdue Email Notification
================================

Send email notifications to assigned users when their project tasks become overdue.

Key Features
------------

* Overdue task notifications by email.
* Filter overdue tasks directly from the task search bar.


Installation
------------
No external dependencies.

Configuration
-------------
Open Project settings and enable **Overdue Notification**. Set the number of overdue days
after which an email should be sent.
