User Log Details
================

Record user login details, including login date, time and IP address.

Key Features
------------

* Track user login details.
* Capture login date and time.
* Record IP address.
* View user login history.
* User and Manager access roles.

Installation
------------
No external dependencies.

Configuration
-------------
* Assign a Login Details role to users from Settings > Users:

  * User: Own Login History - sees only their own logins.
  * Manager: All Login History - sees the logins of all users.
* The administrator gets the Manager role on installation.
