Configuration

First, access the project settings and activate the 'Is Progress Bar' option. This enables you to monitor the progress of your project from multiple perspectives.

Progress Bar in Task Stages

Subsequently, navigate to the task stages section (Configuration -> Task Stages) and activate the 'Is Progress Bar' option for each stage. Define the progress percentage for each specific stage by entering the desired value in the 'Progress (%)' field.

Verify the Stage Priority

During the configuration of the 'Progress (%)', ensure to verify the stage priority. It's important to note that you cannot assign a higher percentage to a stage if it has a higher priority compared to another stage with lower priority and a lower percentage . Attempting to do so will result in a user error.

Stage With Low Priority
It is essential to note that you cannot assign a lower percentage to a stage if its priority is low, and there exists another stage with a higher priority and a higher percentage . Any attempt to do so will result in a user error.

Frequently Asked Questions

What is the primary purpose of the Odoo Project and Task Progress Status app?

The primary purpose of the app is to help teams manage projects and track the progress of tasks efficiently, allowing for better organization, accountability, and project visibility.

Key Features:
  • Visual Progress Tracking
  • Task Management

How can I visualize the progress of my tasks and projects?

The app features visual tools such as Kanban boards and progress bars that provide a clear overview of task status, making it easy to see what has been completed and what remains.
