No Automatic Subscription

To stop the automatic subscription for records in the specified model.

Key Highlights

We can enable or disable the stop subscription feature and configure the models in which you want to prevent the subscription feature.

This module helps prevent updates to the followers list for records in the model specified in General Settings. The followers list remains unchanged even after communication with different users.

This feature helps preserve data privacy by limiting the followers.
