Create Telegram Bot & Get API Token

Search for @BotFather on Telegram, send /newbot to create your bot, and obtain the HTTP API token required to connect your Telegram bot with Odoo.

Configure Telegram Bot & Webhook Setup

Navigate to Telegram > Configuration > Telegram Bots, enter your Bot API Token, and set the Webhook URL (format: https://YOUR_DOMAIN/telegram/webhook) to receive incoming messages. For local or testing environments, use a public tunneling tool like ngrok to forward webhook requests to your instance, whereas production servers require a public HTTPS domain. Click Set Webhook to activate the bot.

Automated Contact Matching & Telegram Sync

When a customer starts or messages the bot on Telegram, Odoo automatically identifies them by matching their Telegram Chat ID, Username, or Profile Name—and creates a new contact if none exists. You can also manually connect existing Odoo contacts by filling their Telegram Chat ID and Username under the Telegram tab on the Contact form to enable real-time messaging and chatter synchronization.

Dispatch Quotations & Orders via Telegram

Select a customer configured with Telegram and click Send via Telegram directly from the order screen. If the state is Quotation, it automatically generates and sends the Quotation PDF report to Telegram; once confirmed in the Sales Order stage, it attaches and delivers the official Sales Order confirmation document.

Interactive Message Wizard & Template Selection

Clicking Send via Telegram opens an interactive wizard allowing you to select a message template (e.g., Sales Order RFQ or Confirmation), preview dynamic variable values, and verify attached documents. Simply click Send to dispatch the message along with its PDF attachment directly to the recipient on Telegram.

Instant Delivery & Telegram Message View

The recipient instantly receives the personalized message along with the attached PDF document directly in their Telegram chat. Customers can easily view order information, download official documents, and reply in real time.

Dispatch Delivery Slips via Telegram

Notify customers regarding shipment status with a single click. From any Delivery Order (Stock Picking), click Send via Telegram to automatically generate and send the official Delivery Slip PDF directly to the customer.

Delivery Notification & PDF Slip on Telegram

Customers receive real-time shipment updates directly on Telegram, complete with a personalized confirmation message and the official Delivery Slip PDF ready for instant download and review.

Dispatch RFQs & Purchase Orders via Telegram

Streamline vendor communication with a single click. From any Request for Quotation (RFQ) or confirmed Purchase Order, click Send via Telegram to automatically generate and deliver the official PDF report directly to the vendor on Telegram.

Vendor PO Notification & PDF Receipt on Telegram

Vendors receive real-time purchase order notifications directly on Telegram, complete with a personalized confirmation message and the official Purchase Order PDF ready for immediate download and review.

Dispatch Goods Receipts via Telegram

Confirm incoming shipments with suppliers in real time. From any Incoming Receipt (Stock Picking), click Send via Telegram to generate and dispatch the official goods receipt slip PDF directly to the vendor on Telegram.

Dispatch Invoices & Notifications

Accelerate payment collections by sharing official invoices directly via Telegram. Click Send via Telegram from any Customer Invoice to automatically generate and attach the invoice PDF.

Instant Billing Notification & Invoice PDF on Telegram

Customers receive instant billing notifications directly on Telegram with total amounts due, reference numbers, and the official PDF invoice attached for prompt review and payment clearance.

Centralized Message Logs & Communication History

Monitor all incoming and outgoing Telegram interactions from a single centralized dashboard. Filter messages effortlessly by status (Draft, Received, Sent, Failed), direction (Incoming / Outgoing), contact, or bot for complete traceability.

Pre-Configured & Customizable Templates

Create and manage customizable Telegram message templates for Sales Orders, Invoices, Purchase Orders, and Delivery Slips. Use dynamic placeholders to automatically inject customer names, order numbers, and transaction amounts.
