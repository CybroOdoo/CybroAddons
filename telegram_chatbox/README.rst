Odoo Telegram Integration
=========================
* Send and receive Telegram messages directly from Odoo business records.
* Seamlessly communicate from Sales Orders, Purchase Orders, Invoices, Delivery Orders, and Contacts.
* Automatically receive incoming messages and customer replies in the document chatter.

Key Features
------------
* Send Telegram messages directly from Sales Orders, Purchase Orders, Invoices, Deliveries, and Contacts.
* Automatic generation and attachment of official PDF reports (Quotations, Invoices, Purchase Orders, Delivery Slips).
* Configurable Telegram message templates with dynamic variable placeholders.
* Real-time incoming webhook processing logging customer replies, photos, documents, and media into Odoo chatter.

Installation
------------
No external dependencies.

Configuration
=============
- Configure Telegram Bot API token under Telegram -> Configuration -> Bots.
- Register the Webhook URL with Telegram to receive real-time incoming messages.
