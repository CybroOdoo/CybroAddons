Before Installation

This module uses a few external Python packages. Install the ones you need for your chosen destinations first, then install the module.

Required packages: dropbox, pyncclient, boto3, nextcloud-api-wrapper, paramiko, azure-storage-blob, google-cloud-storage and webdavclient3. Install these before installing the module using the commands below.
Install the Python packages
pip3 install dropbox
pip3 install pyncclient
pip3 install boto3
pip3 install nextcloud-api-wrapper
pip3 install paramiko
pip3 install azure-storage-blob
pip3 install google-cloud-storage
pip3 install webdavclient3

Answers Before You Install

Q
Which storage destinations are supported?
A
Twelve: Local storage, FTP, SFTP, Google Drive, Dropbox, OneDrive, Nextcloud, Amazon S3 (and S3-compatible providers such as Backblaze B2, Wasabi, Cloudflare R2, MinIO), Azure Blob Storage, Google Cloud Storage and WebDAV.
 
Q
How often are backups taken?
A
On a schedule you choose — daily, weekly or monthly — using Odoo scheduled actions. You can also run a backup at any time with the "Backup Now" button.
 
Q
Are old backups removed automatically?
A
Yes. Enable "Remove Old Backups" and set the number of days — backups older than that are deleted from the destination automatically.
 
Q
Is my database master password stored?
A
No. The master password is only used to authorize the configuration when you save it, and it is never stored on the record. Scheduled backups do not need it.
 
Q
Can I back up more than one database at once?
A
Yes. A single configuration can back up one database, every database on the server, or a selected list — each database gets its own history entry.
 
Q
Where can I see whether a backup succeeded?
A
In the Backup History log (one row per run, with status, duration and any error) and on each configuration's last-run status. You can also enable email notifications.
