Reports and Attachments Preview in Browser
==========================================

Open PDF reports and attachments in a new browser tab instead of downloading
them, so documents can be previewed without leaving your current screen.

Key Features
------------

* Printing a PDF report opens it in a new browser tab
* Downloading an attachment from the chatter also opens it in a new tab when
  the browser can show it (PDF, image, text or video)
* Files in attachment fields open in a new browser tab when clicked
* Files are served inline so the browser displays them, keeping their original
  file name for saving
* If the PDF engine is not available, Odoo's standard warning and HTML report
  are used
* Works with both Community and Enterprise editions

Installation
------------
No external dependencies. The module depends on Web (``web``) and Discuss
(``mail``).

Configuration
-------------
No additional configuration is required.
