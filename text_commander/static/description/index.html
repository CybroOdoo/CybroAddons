Frequently Asked Questions

How do I activate the command palette?

Press Ctrl + K from anywhere in the Odoo backend to open the command palette, then type ! to switch to the Text Commander namespace. You'll see suggestions as you type your command.

What command syntax should I use?

Here are the supported command formats:

  • ! Open Sale Order — opens the model list view
  • ! Open Sale Order/S00001 — opens a specific record
  • ! Open Sale Order of Customer Azure — filters by a field value
  • ! Create Sale Order — opens a new record form

How does condition-based filtering work?

Use the keywords of or in to filter by a field and value. For example, Open Sale Order of Customer Azure will open the list of sale orders filtered by the customer named Azure. The module supports Many2one, Selection, and text-based fields.

Does this work with custom models?

Yes. Text Commander works with any model registered in Odoo, including custom modules. As long as the model has a menu action associated with it, you can open, filter, or create records for it through the command palette.

Is the model name matching case-sensitive?

No. The model name matching is fully case-insensitive. Whether you type sale order, Sale Order, or SALE ORDER, the module will correctly identify and navigate to the right model.
