Key Highlights

2D Interactive Canvas Designer

Design warehouse layouts on an interactive 2D grid canvas. Drag and drop racks, shelves, bins, zones, docks, and more with grid snapping for precise placement.

3D WebGL Warehouse Walkthrough

Switch to a fully rendered 3D view powered by Three.js. Navigate with orbit, pan, and zoom camera controls to explore racks with shelf details, shadows, and labels.

Stock Density Heatmap

Toggle a real-time colour heatmap (green to red) showing stock fill percentages for each location, helping you instantly spot overcrowded or under-utilized areas.

Multi-Floor / Zone Support

Manage multi-storey warehouses by creating separate layout canvases per floor level. Link floors via staircase or elevator map objects for seamless navigation.

Location Detail Sidebar

Click any placed location on the canvas to open a sidebar showing product summaries, quantity, weight, and fill percentage without leaving the designer.

Background Floor Plan Upload

Upload an existing floor plan image as a background layer on the canvas and overlay your digital rack/shelf placements on top of it for accurate mapping.

Product Location Search

Search for products by name or internal reference across all placed locations on the current floor, or expand the search cross-floor across the entire warehouse.

Location Shape & Colour Customisation

Assign industry-standard shapes (Rack, Shelf, Bin, Zone, Dock, Packing, Refrigerator, QC Area) and custom hex colours to every stock location for clear visual distinction.

Multi-Company Compatible

Fully multi-company aware — each layout, map object, and location is scoped to its company, making the module safe for multi-tenant Odoo deployments.

Warehouse Layout List View

The main Warehouse Layouts list shows all configured floor layouts with their warehouse, floor level, canvas size, and location count at a glance.

Creating a New Warehouse Layout

Create a new layout by setting the warehouse, floor level, canvas dimensions (width × height in grid cells), grid size, measurement unit, and an optional floor plan background image.

Stock Location Configuration

Each stock location can be assigned a visual shape (Rack, Shelf, Bin, Zone, Dock, Packing, Refrigerator, QC Area), a hex color, rotation, and shelf row count directly on the location form.

2D Canvas Designer — Placing Locations

Open the designer to see the 2D grid canvas. Drag unplaced locations from the sidebar onto the canvas. Grid snapping keeps every placement perfectly aligned.

Location Detail Sidebar

Click any placed location to open the detail sidebar. It shows the location's complete name, shape, weight and height, number of rows and color.

3D WebGL Warehouse View

Switch to the 3D view to see a fully rendered Three.js scene. Racks appear as 3D objects with shelf rows, drop shadows, and floating name labels above each location.

3D View — Camera Navigation

Use orbit (left-click drag), pan (right-click drag), and zoom (scroll wheel) camera controls in the 3D view to inspect any corner of the warehouse from any angle.

Product Search Across Locations

Use the product search panel to find any product by name or internal reference. Results list the matching location.

Background Floor Plan Image

When a floor plan image is uploaded to the layout, it renders as a semi-transparent background layer beneath the grid, allowing you to trace real-world positions accurately.

Does this module work with Odoo Community edition?

Yes. The Warehouse 3D Map & Designer is fully compatible with both Odoo 18 Community and Enterprise editions. All designer, heatmap, and 3D features are available in Community.

How does the stock density heatmap work?

The heatmap queries live stock quants for all locations placed on the canvas and calculates a fill percentage based on the location's storage category capacity. Colors range from green (0% full) to red (100% full).

Can I manage a warehouse with multiple floors?

Yes. Create a separate Warehouse Layout for each floor and assign a floor level number (0 = ground, positive = upper floors, negative = basement). The designer's floor switcher lets you navigate between them instantly

Can I upload an existing floor plan image?

Yes. On the Warehouse Layout form, upload any image (PNG, JPG) in the Floor Plan Image field. It will render as a semi-transparent background on the 2D canvas so you can precisely overlay digital rack placements on your real floor plan.
