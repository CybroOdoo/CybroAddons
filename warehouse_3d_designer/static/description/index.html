Answers Before You Install

Q
Does this module work with Odoo 20 Community Edition?
A
Yes. It works on Odoo 20 Community and Enterprise, and on Odoo.sh. It depends only on the core Inventory (stock) module, and all designer, heatmap and 3D features are available in Community.
 
Q
How does the stock density heatmap work?
A
It reads live stock quantities for every location placed on the canvas, and their child locations, in a single aggregated query. The fill percentage uses the location's storage category capacity, falling back to 100 units when no category is set. Colours run from green (empty) to red (full).
 
Q
Can I manage a warehouse with multiple floors?
A
Yes. Create a Warehouse Layout for each floor and give it a floor level (0 = ground, positive = upper floors, negative = basement). The floor switcher in the designer toolbar moves between them, and the 3D view can show all floors stacked together.
 
Q
Can I upload an existing floor plan image?
A
Yes. Upload a PNG or JPG in the Floor Plan Image field on the Warehouse Layout form. It is drawn behind the grid as a reference layer so you can overlay your racks accurately, and it does not affect location placement.
