Minimum Purchase Limit In Website
=================================
This module helps you to set a minimum amount for purchasing.

Key Features
------------
* Set a Minimum Purchase Amount for Website.
* Displays an error popup if the amount is less than the limit.


Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
