POS Direct Login
================

This module allows users to directly log in to their configured Point of Sale shop upon authentication.

Key Features
------------

* Direct User Login to POS
* Time-saving Workflow
* User-Friendly POS Access

Installation
------------
No external dependencies.

Configuration
-------------
1. Navigate to **Settings > Users & Companies > Users**.
2. Select a user who has Point of Sale user access rights.
3. Open the **Point of Sale** tab and select the desired **POS Configuration**.
4. Save the user record.
