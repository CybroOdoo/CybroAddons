Odoo Zendesk Connector for Odoo 20

Seamlessly integrate Odoo Helpdesk with Zendesk. Bi-directionally synchronize support tickets, manage tickets directly from Odoo, and import or export tickets between platforms with secure OAuth 2.0.

KEY HIGHLIGHTS

OAuth 2.0 Authentication

Modern, secure OAuth 2.0 client credentials grant. Access tokens are cached in Odoo and automatically refreshed prior to expiration.

 

Create Tickets to Zendesk

Create support tickets in Zendesk with a single click. The requester is automatically resolved or registered in Zendesk using customer contact email.

 

Two-Way Synchronization

Keep subject lines, ticket descriptions, and priorities fully in sync. Push updates from Odoo to Zendesk with the dedicated Update button.

 

Smart Customer Matching

Requesters are looked up and mapped by email address. Dedicated contacts are created in both Odoo and Zendesk when missing, ensuring accurate history.

 

Safe Deletion & Unlink

Delete tickets directly from Zendesk API. Once confirmed or already removed, the connector cleanly clears the Zendesk Ticket ID on the Odoo ticket.

 

Date-Range Import & Export

Powerful wizard with pagination support imports historical tickets into Odoo or exports new tickets to Zendesk between selected dates.

Screenshots Feature Matrix Frequent Questions Release Notes

Create an Account in Zendesk

Sign up or log in to your Zendesk account. An active account is required to access the Admin Center and generate OAuth client credentials.

Navigate to Zendesk Admin Center

From your Zendesk instance, open the product tray and select Admin Center to manage system settings, APIs, and integrations.

Navigate to OAuth Clients

In the Admin Center left navigation menu, go to Apps and integrations > APIs > Zendesk API > OAuth clients.

Add OAuth Client

On the OAuth Clients management interface, click the "Add OAuth client" button to create an authentication client for Odoo.

Configure Client Credentials & Secret

Enter client details and save. Zendesk generates your Client Secret key. Copy and store this secret securely, as it is displayed only once.

Configure Zendesk in Odoo Settings

In Odoo Settings > Helpdesk, enable "Connect Zendesk" and provide your Company Domain, OAuth Client Identifier, Client Secret, and Scope.

Verify Connection with Test Connection

Click "Test Connection" to immediately test authorization with Zendesk. A success notification verifies everything is configured properly.

Create Support Ticket in Odoo Helpdesk

Open any ticket in Odoo and click "Create to Zendesk" in the header to dispatch the ticket directly to your Zendesk instance.

View Created Ticket in Zendesk

The ticket is instantly registered in your Zendesk agent view with full subject, description, priority, and matched requester profile.

Zendesk Ticket ID Linked in Odoo

Once created, the ticket form in Odoo Helpdesk displays the associated Zendesk Ticket ID, establishing a bi-directional reference.

Update Ticket Details from Odoo

Modify ticket fields such as subject, description, or priority in Odoo and click the "Update" button to synchronize changes to Zendesk.

Synchronized Updates in Zendesk

Zendesk reflects the updated ticket details immediately without needing to manually copy changes across tools.

Delete Ticket from Zendesk

Click "Delete From Zendesk" in the Odoo ticket header to send a deletion request to the Zendesk API.

Confirm Deletion in Zendesk

Verify ticket removal in the Zendesk Deleted Tickets view. Odoo automatically unlinks the Zendesk ticket reference on the record.

Import / Export Tickets Wizard

Access the Import/Export wizard under Helpdesk > Configuration > Import/Export Tickets to perform date-range synchronization.

Import Tickets by Date Range

Select start and end dates and click "Import" to fetch Zendesk tickets created within the period, with automatic multi-page pagination.

Imported Tickets in Odoo Helpdesk

All imported tickets populate directly in Odoo Helpdesk with customer contacts, descriptions, priorities, and linked Zendesk Ticket IDs.

Answers Before You Install

Q
What authentication method is used to connect with Zendesk?
A
The module uses Zendesk's official OAuth 2.0 with the Client Credentials grant type. Odoo securely manages and caches the short-lived access tokens, renewing them automatically before expiry without requiring recurring logins.
 
Q
How are customers and requesters matched between Odoo and Zendesk?
A
Matching is based on contact email addresses. If a customer already exists with that email in Odoo or Zendesk, they are linked immediately. If not found, a dedicated contact is created automatically.
 
Q
Can I update an existing Zendesk ticket directly from Odoo?
A
Yes. Modifying the ticket's subject, description, or priority in Odoo and clicking the "Update" button in the form header immediately synchronizes the changes to the linked Zendesk ticket.
 
Q
How does date-range ticket import and export work?
A
Under Helpdesk > Configuration > Import/Export Tickets, select your start and end dates. "Import" queries the Zendesk Search API with pagination to create or update local tickets. "Export" batches local tickets created within the range and pushes them to Zendesk.
 
Q
What happens when a ticket is deleted in Zendesk?
A
When you click "Delete From Zendesk", the connector issues a DELETE request. If successful or already deleted in Zendesk (404), Odoo unlinks the Zendesk Ticket ID and resets the Zendesk origin flag safely.
