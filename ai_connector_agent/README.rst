AI Agent Connector
==================
* Connect to different AI providers and chat with selected models

Key Features
------------

* Multi-Provider Integration
* Flexible Model Selection
* Interactive Chat Interface
* Secure API Key Management
* Real-Time Responses

Installation
------------
No external dependencies.

Configuration
=============
    - Generate API key from https://aistudio.google.com/app/api-keys for Google Gemini
    - Generate API key from https://platform.openai.com/api-keys for ChatGPT
    - Generate API key from https://platform.claude.com/create/api-key for Claude
