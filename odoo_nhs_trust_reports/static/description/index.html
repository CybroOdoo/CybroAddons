Frequently Asked Questions

Who can access the Excel Directory Export feature?

Both NHS Trust Users and NHS Trust Managers can access the Excel Directory Export wizard. Users can apply filters, generate reports, and download NHS Trust directory data directly from the Reports menu.

What information is included in the NHS Trust Excel export?

The Excel export includes important NHS Trust details such as ODS Code, Trust Name, Health System, Trust Type, Region, ICB/Health Board, CQC details, Trust Status, Chair, and CEO information.

Can users filter reports before exporting?

Yes. Users can filter reports by Health System, NHS Region, and Trust Status before generating and downloading the Excel report..
