Odoo Quickbooks Online Connector
================================
* A module to import/export data between Odoo and Quickbooks.

Configuration
=============
* Create a Developer account in Quickbooks.
* Copy the Client ID, Client Secret and Realm ID and add it in the Quickbooks
record in Odoo to connect Odoo with Quickbooks.
