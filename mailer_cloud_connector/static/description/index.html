Create and Access Your Mailercloud Account

Create an account in Mailercloud and navigate to the Account section to begin configuring the integration with Odoo.

Access API Keys from Integration Settings

Under the Integrations menu in Mailercloud, locate the API Keys option to manage authentication credentials.

Create a New API Key

Generate a new API key from the API Keys section. This key will be used to securely connect Odoo with your Mailercloud account.

Test API Connection

Paste the generated API key into Odoo and click Test Connection to validate successful communication with Mailercloud.

Mailercloud Property Configuration

Once the connection is successfully tested, you can create Mailercloud properties directly from Odoo for better contact segmentation.

Sync Odoo Contacts with Mailercloud

Connect Odoo contacts with Mailercloud to ensure real-time synchronization of customer data for email marketing campaigns.

Access Synced Contacts in Mailercloud

Frequently Asked Questions

Does this module support automatic contact updates?

Yes. Once connected, any creation or modification of contacts in Odoo is automatically synchronized with Mailercloud.

Can I use multiple Mailercloud accounts with this module?

Yes. The module supports syncing contacts using multiple API keys, enabling integration with more than one Mailercloud account.
