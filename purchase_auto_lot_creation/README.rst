Purchase Auto Lot Creation
==========================
This module helps to automatically generate product lots during the purchase process.

Key Features
------------

* Integrated with inventory traceability
* Automatic lot creation from PO lines
* No manual lot assignment required

Installation
------------
No additional dependency required.

Configuration
-------------
* Enable the **Lots & Serial Numbers** option in Inventory Settings.
* Set product tracking to **By Lots** or **By Unique Serial Number** to enable automatic lot generation.
