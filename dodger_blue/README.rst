Dodger Blue Backend Theme
=========================
The Dodger Blue Backend Theme in Odoo 20 offers a sleek and modern visual
experience for users interacting with the platform's backend.

Key Features
------------

* A minimal, colorful login screen.
* Kanban, list, and form views with a clean layout and modified font.
* Styling for the Discuss page when Discuss is installed.
* A responsive application sidebar.
* Customized date picker.
* Searchable application menus.

Installation
------------
Install this module from Apps on Odoo 20. It depends on the core web module.
There are no additional Python dependencies for normal use.

Configuration
-------------
No additional configuration is required.
