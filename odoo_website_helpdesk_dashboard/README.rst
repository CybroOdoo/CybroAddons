Website HelpDesk Dashboard
==========================

Adds a dashboard to the Website HelpDesk app. The app opens on the dashboard,
which shows the number of new, in progress and done tickets and of helpdesk
teams, the customer reviews received, the share of the tickets of each
priority, a chart of the ticket status, a chart of the tickets per team and
the latest tickets.

Key Features
------------

* Cards with the number of new, in progress and done tickets and of helpdesk teams.
* Click a card to open its tickets or the helpdesk teams.
* Number of customer reviews received.
* Share of the tickets of each priority.
* Doughnut chart of the ticket status.
* Bar chart of the tickets per helpdesk team.
* List of the latest tickets; click a ticket to open it.
* Every user only sees the tickets their access rights allow.

Installation
------------
No external dependencies. Requires the Website HelpDesk module
(odoo_website_helpdesk).

Configuration
-------------
No additional configuration is required. The dashboard is available to
HelpDesk users and administrators.
