Frequently Asked Questions

Is it possible to download multiple orders without any loading spinner?

Yes, the module supports background generation of multiple orders or reports simultaneously. Users can download multiple PDFs without any loading spinner or interface blocking, ensuring a smooth and uninterrupted workflow.

Does this module generate all PDF reports in the background without loading?

Yes, the module processes all PDF reports asynchronously in the background. Users can continue working without any loading spinner or page blocking, and the PDF is automatically downloaded once generation is complete.

Does this module handle PDF generation efficiently for orders with a large number of lines?

Yes, this module is designed to efficiently handle PDF generation even when orders contain a large number of lines. The reports are generated in the background using a non-blocking process, ensuring that the user interface remains fully responsive. Even for heavy documents with extensive order lines, the system avoids loading spinners and prevents browser freezing, providing a smooth and reliable downloading experience.
