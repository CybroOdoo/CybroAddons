Delivery Slot
=============
This module helps you choose a different delivery slot for each product.

Key Features
------------

* Enable/Disable Delivery Slots
* Customizable Delivery Date and Slot

Installation
------------
No external dependencies.

Configuration
-------------
Enable **Delivery Slot** in Website > Configuration > Settings, then add
the available time slots in Sales > Configuration > Slot Timing.
