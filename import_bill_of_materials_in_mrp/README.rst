Import Bill Of Materials
========================
Import Bill Of Materials using CSV or Excel files

Key Features
------------

* Bulk BoM Import via Excel/CSV
* Supports Multi-level BoMs
* Error Validation & Summary Report

Installation
------------
External Python dependencies "openpyxl" and "xlrd" are required for the module to work.

Configuration
=============
* Check the Import BOM field in users
