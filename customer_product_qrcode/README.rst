Customer and Product QR Code Generator
======================================
Generate unique QR codes for customers and products in Odoo.

Key Features
------------

* Unique QR code generation
* Configurable customer and product sequence prefixes
* PDF badge printing for customers and products
* Community and Enterprise editions support

Installation
------------
This module requires the Python library 'qrcode' (pip install qrcode).

Configuration
-------------
Go to General Settings -> Setup QR Code to configure customer and product QR prefixes.
