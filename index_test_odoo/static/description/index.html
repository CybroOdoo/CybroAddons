Configuration

1.Choose the github user access rights from the user settings.

2.Open the github configuration settings to setup the API tokens and webhooks

3.Set up API tokens and webhooks easily inside Odoo.

Repositories

1.Enter the repository name and owner in the form view, then click the Setup Webhook button to configure the webhook in the GitHub repository.

2.If the webhook is created successfully, a success message will appear in the chatter, and the webhook URL will be generated.

3.Click on the Sync Repository button to synchronize all GitHub repository data into the Odoo repository.

4. After the repository is successfully synced, the state will change to Success, and all other details will be fetched.

Branches

1.By clicking on the Branches, you can view all the corresponding branches linked to each repository.

2.From the Branch form view, you can see all the details related to the corresponding branch.

3.Click on the Sync Branch button to synchronise the branch details from the github.

4.From the repository record, you can create a new branch in GitHub directly from Odoo.

Commits

Track commits per branch and auto-link with tasks.

Pull Requests

Monitor open, closed, and merged pull requests.

Issues

Track issues per repositories and auto-link with tasks.
