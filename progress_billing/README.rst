Customer Progress Billing
=========================

This module enables your accounting users to generate progress billing,
which can be exported as a PDF document. They can then share this billing with
customers for project-related invoicing.


Key Features
------------

* Create progress billing invoices and PDF reports for projects.
* Export project progress billing details as a PDF report.
* Add a progress billing title and project details to customer invoices.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
