Legal Case Management Dashboard
===============================
This module provides an overview dashboard to track and manage legal cases.


Key Features
------------
* Visual overview of legal cases, evidence, trials, and invoices.
* Dynamic charts for case categories, monthly income, and case stages.
* Top 10 revenue-generating cases.
* Multi-filter support by stage, lawyer, and month ranges.

Installation
------------
No external dependencies required.


Configuration
-------------
* Ensure the dependent module `legal_case_management` is installed.
* Access the dashboard from the Legal Case Management menu.
