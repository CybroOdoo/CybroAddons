Calendar Meeting Checklist
==========================

This module helps to enhance your meeting preparation and management
process. It lets you list the required items, things to be done or points
to be considered for a meeting, and track them as a reminder directly in
the calendar event form view.

Key Features
------------

* Create reusable meeting checklist items with a name and description.
* Group checklist items into Checklist Templates.
* Add one or more templates to a calendar event from the new Checklist tab,
  which automatically fills in the checklist lines.
* Mark each checklist line as Completed or Canceled, and reorder lines
  by drag and drop.
* Shows the completion percentage of the checklist on the event form and
  as a progress bar in the event list view.
* Filter events by Completed Checklist or Incomplete Checklist.
* Import checklist items from CSV or XLSX files; existing items with the
  same name are updated instead of duplicated.

Installation
------------
Requires the ``openpyxl`` Python library for importing XLSX files.
Install it with ``pip install openpyxl`` if it is not already available.

Configuration
-------------
No additional configuration is required. Checklists, Checklist Templates
and Import Meeting Checklist are available under Calendar > Configuration.
