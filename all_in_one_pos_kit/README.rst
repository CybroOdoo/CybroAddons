All in One POS Kit
==================
* This module combines a variety of POS features: a dashboard, a dynamic
  report maker, age restricted products, an advanced receipt, multiple
  barcodes, service charges, tips, time based products, manufacturing
  orders from the POS and greeting messages.

Configuration
=============
* Most features are enabled in Point of Sale > Configuration > Settings.
* To send greeting messages, enable POS Greetings and enter your Twilio
  account SID, auth token and number.
* To create manufacturing orders from the POS, tick "To Create MRP Order"
  on a product that has a bill of materials.
