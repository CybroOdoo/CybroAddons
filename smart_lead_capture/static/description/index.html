Does this module require Zapier?

No. This module uses Google Apps Script as the bridge between Google Forms and Odoo. It is completely free and does not require any paid third-party services.

Is WhatsApp notification mandatory?

No. WhatsApp notification via Twilio is optional. If Twilio credentials are not configured in Settings, the module simply skips WhatsApp and still creates the lead and sends the email notification.

What happens if the same person fills the form twice?

The module detects the duplicate by matching the email or phone number. Instead of creating a new lead, it updates the existing lead with the new message appended to the description. No duplicate leads are created.

Can I use my own Google Form field names?

Yes. The Google Apps Script acts as the bridge, and you can map any Google Sheet column name to the required JSON keys. The form field names are completely flexible.
