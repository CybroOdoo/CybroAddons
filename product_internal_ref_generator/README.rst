Product Internal Reference Generator
====================================
This module generates the internal reference of products and product variants
automatically from the product type, name, category and attribute values.

Key Features
------------

* Automatically generate the internal reference of new products and variants
* Generate the internal reference of existing products and product variants
  from the Action menu
* Full product type (Goods:, Service: or Combo:) at the start of every reference
* Configurable number of characters and separator for the product name,
  product category and the attribute values of each variant
* One sequence number shared by all products and variants, so a number is
  never used twice
* References entered manually are never overwritten

Installation
------------
No external dependencies.

Configuration
-------------
Go to Settings > General Settings > Product Internal Reference Generator and
enable the parts to include in the internal reference.
