Automatic Invoice And Post
==========================

This module generates and posts invoices when the delivery is validated,
and can send them to the customer by email.

Key Features
------------

* Automatic Invoice Generation.
* Automatic Invoice Posting.
* Automatic Invoice Sending.


Installation
------------
No external dependencies.

Configuration
=============
* Go to Invoicing > Configuration > Settings and enable "Auto Post Invoice"
  and/or "Auto Send Invoice".
