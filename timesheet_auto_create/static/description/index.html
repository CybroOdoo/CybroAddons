Status field in the Tree View

New Status field in the Tree View of Timesheet to Mark weather Task is 'Ongoing' or 'Completed'.

Configure Incoming Mail Servers

Go to Settings - Technical - Email - Incoming Mail Servers.Create a new one for Timesheet. Select 'Analytic Line' as 'Create a New Record'

Configure Work email for an employee.

Set Work email for an employee.

Send work report, from the employee's Work email

Send work report, from the employee's Work email, as in the same format to the mail for which Incoming Mail Server for Timesheet is created

Work Report Email Template (HTML Format)

Send the work report from the employee's work email using the following HTML template format. The Incoming Mail Server will read this email content and automatically create the corresponding Timesheet entries.
