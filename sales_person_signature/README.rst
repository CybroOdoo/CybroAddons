Sales Person Signature
======================

This module allows salespersons to add their signatures to sale documents. Only after signing can the user confirm the quotation.

Key Features
------------

* **Configurable Sale Approval**: Option to enable or disable salesperson signature requirement under Sales settings.
* **Digital Signature Capture**: Interactive signature widget on Quotations and Sale Orders for salespersons.
* **Confirmation Access Control**: Prevents confirmation of draft/sent quotations if required salesperson signature is missing.
* **Salesperson-Specific Display**: Seamlessly displays signature fields to assigned salespersons on relevant order documents.

Installation
------------
No external dependencies.

Configuration
-------------

1. Go to **Sales -> Configuration -> Settings**.
2. Locate the **Sale Approval** section.
3. Enable **Sale Document Approve** to enforce salesperson signatures before order confirmation.
