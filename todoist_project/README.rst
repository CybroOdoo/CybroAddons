Todoist Integration
===================
Sync Todoist projects, sections, tasks, sub-tasks, labels and due dates into
the Odoo Project app.

Configuration
=============
- The user needs Project access rights.
- Copy the API token from Todoist (Settings > Integrations > Developer),
  paste it in the Todoist Token field of My Preferences and click
  Sync with Todoist.

Installation
============
- No external Python library is needed. The module connects to the
  Todoist API v1 with the ``requests`` library shipped with Odoo.
