3D Image Viewer Widget
======================

Adds a 3D Model Viewer page to the product form. Upload a GLB file and rotate
or zoom the model directly in the backend.

Key Features
------------

* View an interactive 3D model on the product form
* Upload a GLB file for each product
* Rotate the model with the mouse and zoom in or out
* A sample model is shown until a file is uploaded

Installation
------------
* Install the module. It only depends on the Product module.
* The View3D library (MIT) is included in the module, so no internet access is
  needed to display a model.

Configuration
-------------
* No configuration is needed. Only GLB files are supported.
