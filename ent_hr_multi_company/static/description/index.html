Key Highlights

Handle Multi-Company

Enables HR multi-company support so HR managers can handle each company's HR processes separately, activated via General Settings as usual.

Company Field on HR Records

Automatically adds a Company field across all HR-related records — attendance, payslips, expenses, leaves, salary categories and more.

Data Isolation per Company

Security rules ensure each user only sees records belonging to their own company, preventing cross-company data leakage.

Payroll & Expense Filtering

Payslips and expense records are automatically filtered by company, so payroll managers only see data relevant to their own company.

Salary Rule Category Scoping

Salary rule categories can be scoped per company, allowing different payroll structures and rule categories for each company independently.

Attendance Company Tracking

Each attendance record is tagged with the employee's company, enabling accurate attendance reporting and filtering in multi-company environments.

Frequently Asked Questions

How do I activate multi-company in Odoo?

Go to Settings → General Settings and enable the Multi-Company option. Once enabled, you can create and manage multiple companies. This module then automatically enforces company-level data isolation across all HR records.

Will users from Company A see records from Company B?

No. This module adds security rules (ir.rule) that restrict attendance, leave, expense, payslip, department, and salary category records to the user's own company. Users will only see records that belong to their company or have no company set.

Does the Company field need to be filled in manually?

No. The Company field defaults automatically to the currently logged-in user's company when creating new records. It is also set as read-only to prevent accidental changes.

Which HR modules are covered by this module?

This module covers HR Attendance, HR Departments, HR Expenses, Time Off (Holidays), Payslips, and Salary Rule Categories. Security rules are applied to all of these models to enforce company-level data separation.
