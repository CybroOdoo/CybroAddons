Advanced Product Pack
===================
Product Bundle Pack allows users to create product bundle packs with auto-calculated prices and costs. This is a great way to raise average sales price per product, to serve customers with products that make their lives easier, and to leverage current products into new and different ones.

Features
========
- Auto calculate product bundle pack price and cost.
- Add multiple product items to a bundle pack.
- Prevent variants for product bundle packs.
- Filter products by 'Product Pack'.
- Point of Sale (PoS) integration with bundle ribbons and component details.
- Real-time and 'Ship Later' bundle explosion in PoS warehouse operations.
- Sales Order integration with shadow lines for service components.
- Automatic Project/Task creation for service components in bundles.
- Milestone-based invoicing support for bundle components.

Configuration
=============
- Additional configuration not required

Installation
============
- Install our custom addon
