Partner Related User and User Filters
=====================================
This module will help you to add related user in the corresponding partner, if there is any.
You can filter by users in Contacts. And also there is an option to filter by different module users in Users.

Key Features
------------

* Related User in Contacts
* Filter Contacts by User
* Filter Users by Module Type

Installation
------------
* No external dependencies.

Configuration
=============
* No additional configurations needed
