Hide Chatter
============
This module helps you hide the chatter on selected models.

Key Features
------------
* Hide Chatter for Selected Models
* Easy Configuration
* Flexible Customization
* Seamless Integration

Installation
------------
No external dependencies.

Configuration
-------------
* Select the models whose chatter should be hidden.
