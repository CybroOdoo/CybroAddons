ESG Data Sources

Base framework for plugging external emission factor providers into the Enviro suite. Providers extend this module via selection_add.

Key Highlights

Provider Framework

Base enviro.data.source model with abstract interface. Providers extend the provider selection via selection_add.

Source Traceability

source_id on emission factors links each factor back to the data source that created or last updated it.

Extensible Design

Any number of providers can coexist. Each adds its own selection value, fields, and views without modifying the base.
