Answers Before You Install

Q
Does this module support Odoo 20 Community Edition?
A
Yes, this module is fully compatible with Odoo 20 Community Edition and integrates seamlessly with all core Discuss, Chat, and Chatter functionalities.
 
Q
Can I preview and edit documents directly inside Odoo without downloading?
A
Yes, the module provides a built-in document preview and editor powered by the TUI Image Editor, allowing you to view, edit, and save attachments without ever leaving Odoo.
 
Q
Can I generate a QR code for an attachment?
A
Yes, the module supports QR code generation for attachments. You can generate a scannable QR code directly from the attachment context menu, making it easy to share or access files from mobile devices.
