Website Signup Approval
=======================

This module allows administrators to approve or reject signup requests of users from the website.


Key Features
------------

* Control Website Signups
* Secure Portal Registration
* Approve New Users


Installation
------------
No external dependencies.

Configuration
-------------
1. Navigate to **Website** > **Configuration** > **Settings**.
2. Under the **Customer Account** section, enable **Signup Approval**.
3. Select the document types required for user registration under **Documents**.
4. Assign the **Signup Approval User** security group to internal users who manage approval requests.
