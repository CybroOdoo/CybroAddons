AI Hub Dashboard — Your Central Control Panel

Navigate to MCP Gateway → Dashboard to view the MCP server status, active providers, tool statistics, and quick-access buttons for generating API keys and testing tools — all from a single screen.


AI Tools — Define & Manage Callable Actions for AI Assistants

Manage all AI-callable actions from MCP Gateway → Configuration → AI Tools. Each tool supports built-in ORM operations, decorated Odoo methods, or custom Python snippets, with configurable provider, model, and consent settings per tool.


MCP Exposed Resources

Define which Odoo models are visible to AI clients (e.g. Claude). Each registered model becomes a readable data source accessible via the odoo:// URI scheme.


AI Providers

Connect external AI services (OpenAI, Anthropic, Google Gemini, Ollama) by storing their API credentials and models. The system picks the highest-priority active provider automatically, with fallback chains if one fails.


Fetch Available Models

Automatically discover and import the AI models offered by the provider. Click Fetch Models to pull the current model list directly from the provider's API — each model is classified as Chat, Embedding, or Multimodal and added to this provider ready to use. For providers that don't support model listing (e.g. Anthropic), models must be added manually using their official IDs.


Generate an MCP API Key for Your AI Client

In the AI Hub Dashboard, click New MCP Key. Select the target platform (Claude Desktop, Claude Code CLI, claude.ai, or OpenAI Codex CLI). The wizard generates a secure API key and renders the exact configuration snippet to paste into your AI client. The key is shown only once — copy it immediately.


Connect Claude Code CLI to Your Odoo Instance

Generate an MCP key and select Claude Code CLI as the platform. The wizard renders a ready-to-run shell command. Open a terminal, paste the command, and the MCP server is registered automatically: claude mcp add-json odoo-ai-hub '{...}' Run claude mcp list to verify registration, then restart Claude Code and type /mcp in a session to confirm the odoo-ai-hub server is connected with all Odoo tools available — no file editing required.


Connect claude.ai (Cloud) to Your Odoo Instance

Generate an MCP key and select Claude Cloud (claude.ai) as the platform. The wizard produces a single URL with the API key embedded: https://your-odoo-domain.com/mcp_gateway?api_key=YOUR_KEY In claude.ai go to Settings → Integrations → Add custom integration, paste the URL, and click Save. Start a new conversation — Odoo tools such as search_records, create_record, analyze_records and ask_ai will be available immediately. Your Odoo server must be reachable over public HTTPS.


Connect Antigravity to Your Odoo MCP Gateway

Connect Antigravity to your Odoo MCP Gateway by generating an MCP key and importing the provided configuration. Once connected, Antigravity can securely access Odoo tools and business data, enabling record management, data analysis, and AI-powered operations directly within the development environment.


AI Tools Consent Granting

Select which AI tool requires user consent ,then when a user add a prompt which requires that AI tool will ask for a consent from mcp consent manager. The result will generate only when consent is granted.


Browse & Test MCP Tools

Go to MCP Gateway → Tools to see all registered AI tools. Each tool shows its name, description, and auto-generated JSON schema. Click Test Tool on any entry to send live parameters and inspect the real output — useful for verifying your provider and model are correctly configured before connecting an external AI client.


Set Up Bot Channels — Telegram, WhatsApp, Discord

Navigate to MCP Gateway → Bot Channels → New. Select a platform, paste your bot token (from @BotFather for Telegram, Meta Developer Console for WhatsApp, or Discord Developer Portal for Discord), then click Connect. Odoo registers the webhook automatically and shows a direct link to your live bot.


Monitor All AI Tool Invocations with Detailed Logs

Go to MCP Gateway → Tool Logs to audit every AI tool call made through the gateway. Each log entry records the tool name, input parameters, provider used, model used, execution duration, and the result. Use this view to debug unexpected outputs, track usage costs, and verify that tools are calling the correct AI model.

Frequently Asked Questions

Who is the Odoo MCP Manager?

It is a gateway that connects your Odoo ERP to the AI world. Using the Model Context Protocol (MCP), it allows AI tools like Claude Desktop, Claude Code, and various chat bots to securely read from and write to your Odoo database in natural language.

How do I connect Odoo to Claude Desktop?

Simply go to the MCP Gateway Dashboard in Odoo, generate a new MCP Key, and copy the provided JSON configuration. Paste this into your Claude Desktop configuration file, and Claude will immediately be able to see and interact with your Odoo tools.

Can I use this for customer support?

Absolutely. The built-in Bot Gateway allows you to connect your AI-powered Odoo logic to WhatsApp, Telegram, Discord, or a custom Web Chat widget. This lets your customers or team interact with Odoo data through their favorite messaging apps.

Is my data secure when using AI?

Yes. The module uses a secure API key system for all connections. Furthermore, it features a unique Human-in-the-Loop Consent system; you can configure sensitive tools (like deleting records) to require manual approval from an Odoo administrator before the AI is allowed to execute them.
