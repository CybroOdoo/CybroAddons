Sale Delivery by Date
=====================
This module allows setting delivery dates per sale order line and generating separate delivery orders in Odoo 20.0.


Key Features
------------

*  Allows users to add expected delivery dates for each sale order line.
*  Generates multiple delivery orders based on delivery dates set on sale order lines.
*  Displays the delivery date on stock pickings and delivery orders.

Installation
------------
- Install the module from the Apps menu.

Configuration
-------------
- No additional configuration is required.
