ASP Configuration

Select your Accredited Service Provider and enter its credentials directly from Settings > Invoicing > Oman E-Invoicing (Fawtara).

Submit to Oman E-Invoicing

One click on a posted invoice generates the PINT OM XML and starts the submission to your configured ASP.

Submission Tracking

A dedicated smart button and a "Submitting" ribbon show the live submission status right on the invoice.

Acknowledged Document + QR Code

Every submission is tracked with its UUID, ASP reference, the QR code, and downloadable Invoice/Tax Data Document XML.

Our Core Features

PINT OM XML Generation

Produces compliant PINT OM Invoice/CreditNote XML (Peppol International Model, Oman specialization, Corners 1-4) directly from posted invoices and credit notes.

ASP Submission Tracking

A dedicated Oman E-Invoicing Document records every submission attempt, the generated XML, the Tax Data Document, and the ASP's acknowledgement.

QR Code

Automatically prints a supplier-generated QR code (seller name, VATIN, timestamp, total, VAT amount, UUID) on invoices.

Official ASP List

The ASP Provider dropdown is exactly the Oman Tax Authority's own published Accredited Service Provider list - no invented or unverified vendors.

Pluggable Connector Architecture

Each ASP is a small, isolated Python connector behind one common interface - wiring in a new provider never touches the rest of the module.

Oman-Specific Fields

Adds CR Number and a third address line to companies/partners, plus Oman VAT format validation and the Oman VAT Peppol e-address scheme.

Tax Data Document (TDD)

Generates the separate Corner-5 report sent to the Oman Tax Authority, distinct from the invoice XML itself.

Retry & Status Sync

A clear Retry action for failed submissions, and a scheduled action that polls the ASP for status updates.

Downloadable Invoice & TDD XML

Both generated XML files are kept as attachments on every submission document, ready for the 10-year self-archival requirement.

Frequent Questions

Do all 12 ASP providers in the dropdown actually work?

No - only Flick Network currently has a real, working connector (authentication, submission, and status polling). The other 11 are genuinely on the Oman Tax Authority's own accredited-provider list and remain selectable, but clearly state they aren't integrated yet rather than pretending to work.

Can I generate the XML without contracting an ASP first?

Yes. PINT OM XML generation works standalone with no network calls of its own, so you can produce compliant invoice XML and submit it to your ASP manually while you finalize which provider to contract.
