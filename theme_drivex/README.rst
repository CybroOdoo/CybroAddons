Theme DriveX
============
A premium car rental website theme with online booking.

Overview
========
Premium car rental website theme. It features a modern design with smooth animations, responsive layouts, dynamic availability date pickers, insurance calculation and customizable sections.

Configuration
=============
Install the theme from the Website > Themes menu. The Fleet and Website CRM
modules are installed automatically as dependencies.

Backend Fleet Configuration:
1. **Vehicles**: Go to Fleet > Vehicles. Enable "Published on Website" on the vehicles to show on the website.
2. **Pricing**: Configure the daily rental rate for each vehicle.
3. **Categories**: Create and assign Fleet Categories to your vehicles so users can filter them on the website.
4. **Locations**: Setup your pickup and return locations.
5. **Add-ons & Insurance**: Configure any rental add-ons or insurance packages required for booking.
