Cancel Landed Cost
==================

This module helps to cancel Landed Costs and allows you to cancel multiple Landed Costs from the tree view. There are three ways in which you can cancel the Landed Costs.

Key Features
------------

* Multiple Cancellation
* Delete or Reset to Draft
* Three Cancellation Methods
* Accurate Cost Tracking

Installation
------------
No external dependencies.

Configuration
-------------
Enable the "Landed Cost Cancel Features" group for the users who are allowed
to cancel landed costs. Then choose the cancellation method (Operation Type)
under "Landed Cost Cancel Configuration" in Inventory > Configuration >
Settings.
