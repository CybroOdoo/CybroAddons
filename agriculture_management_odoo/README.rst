Agriculture Management
======================
Comprehensive agriculture operations, crops, pests, and rental management for Odoo.

Key Features
------------
* Manage crop requests, seed details, and location tracking
* Manage pest requests, pest details, and damage/loss records
* Manage vehicle and animal rentals with duration, payments, and reporting
* Dedicated analytical PDF reports for crop and pest requests

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.

Supported Editions & Deployment
-------------------------------
* Community Edition
* Enterprise Edition
* Deployed on: Odoo.sh, On-Premise

Frequently Asked Questions
--------------------------
* How to access agriculture features and rentals?
  Navigate to the Agriculture Management main menu to track crops, pests, machinery, and rentals.
