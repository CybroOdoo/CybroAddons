POS Timesheet
=============
Efficiently track employees' work hours in POS.

Key Features
------------

* Automatic Timesheet Logging
* Employee Activity Tracking
* Project and Task Integration

Installation
------------
No external dependencies.

Configuration
-------------
1. Navigate to Point of Sale -> Configuration -> Settings.
2. Under the Point of Sale section, enable the **Time Log** option.
3. Select the **Project** for recording timesheets and tasks.
