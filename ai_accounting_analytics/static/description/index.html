Up and Running in 3 Steps

1. Install

Install the module (the Accounting Kit is installed with it) and give the Chief Accountant group to the users who will ask questions.

2. Add Your API Key

In Accounting › Configuration › AI Analytics › My API Keys, add a key for Gemini, OpenAI, Claude or OpenRouter, choose a model and click Test Connection.

3. Ask Your Books

Open Accounting › AI Analytics, accept the one-time data notice and ask — tables, charts and insights stream in seconds.

Frequently Asked Questions

Which AI providers are supported?
Google Gemini (default), OpenAI (ChatGPT), Anthropic (Claude) and OpenRouter. Any OpenAI-compatible endpoint can be used by setting the provider’s base URL. Each user can pick the model per question.
Do I need my own API key? Who pays for the AI?
Yes. Each user adds a personal API key in Accounting › Configuration › AI Analytics › My API Keys. AI calls are billed by the provider on that key; the module shows the tokens and cost of every answer in the Usage & Cost dashboard.
Can the AI change my accounting data?
No. This version is strictly read-only: the AI can only call reporting and lookup tools, which run with the user’s own access rights. It never creates, edits or deletes records.
What data is sent to the AI provider?
The question and the figures needed to answer it (amounts and the names or details of the records involved). Technical and security data such as users, settings, passwords, tokens and API keys are never reachable. Users accept a one-time notice before their first question.
Are the figures calculated by the AI?
No. Every company figure is computed by Odoo itself, through the Accounting Kit reports and the ORM; the AI only chooses the tool, explains the result and adds insights. General explanations are marked as such.
How much does a question cost?
Usually a fraction of a US cent with the default Gemini Flash-Lite model. Compact tool results, prompt caching and short history summaries keep token usage low. The exact cost of each answer is shown below it.
Who can use AI Analytics?
Users of the Chief Accountant group of the Accounting Kit. Conversations and API keys are personal; administrators can see everyone’s usage and cost.
Does it work with several companies and branches?
Yes. Figures cover the companies selected in the company switcher, branches included. Companies using another currency are left out of the totals and the answer says so.
Does it work on Odoo Online and Odoo.sh?
No, it works on Odoo 20 Community Edition (on premise), like the Accounting Kit it depends on.

Setup Guide

From installation to your first answer in a few minutes.

1Install the module and give the Chief Accountant group (Accounting Kit) to the users who will use AI Analytics.
2Get an API key from Google AI Studio, OpenAI, Anthropic or OpenRouter.
3Open Accounting › Configuration › AI Analytics › My API Keys, create a key for the provider, choose your preferred model and click Test Connection.
4Optionally, in AI Providers use Fetch Models to import more models, and in Accounting › Configuration › Settings set the default model, maximum AI steps, history turns and maximum answer tokens.
5Open Accounting › AI Analytics, accept the one-time data sharing notice and ask your first question.
6Follow tokens and cost in Accounting › Configuration › AI Analytics › AI Usage & Cost.
