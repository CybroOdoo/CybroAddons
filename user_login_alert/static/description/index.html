Frequently Asked Questions

What is the purpose of the User Login Alert Module?

This module inform the users On Successful Logins.

Will users get a notification only after enabling the “Receive Login Notification” group?

Yes. Users will receive login notifications only if the “Receive Login Notification” group is enabled for them. If the group is not enabled, no notification will be sent.
