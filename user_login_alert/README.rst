User Login Alert
================
This module will help to send the notification to users on successful login to his account.

Key Features
------------

* Sends an email alert to the user after every successful login.
* Provides the login browser details for better account security.
* Helps users identify unauthorized or suspicious login activities.
* Improves Odoo account security by keeping users informed about account access.

Installation
------------
* This module requires the Python package httpagentparser
* pip install httpagentparser

Configuration
-------------
- www.odoo.com/documentation/20.0/setup/install.html
- Install our custom addon
- Set outgoing mail server, The Email will be send to Users related partners Email ID.
   So, give an email for user related partner and also make sure he has "Receive Login Notification" user group.
