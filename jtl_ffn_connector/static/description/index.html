Frequently Asked Questions

What is the purpose of the jtl_ffn_connector module?

It connects Odoo to the JTL Fulfillment Network so products, orders, tracking, and returns sync automatically between Odoo and JTL's outsourced warehouse fulfillment service.

Do I need to manually run every sync, or does it happen automatically?

Both — each feature runs automatically via cron, and also has a manual button for on-demand syncing.

How to configure jtl warehouse in odoo?

Map an Odoo warehouse to the real FFN Warehouse ID on the config profile's Fulfillment Warehouses tab.
