Restrict Journal for Users
==========================
This module restricts selected users from working with the chosen accounting
journals. The restricted journals are read-only for those users, while all
other journals remain fully accessible.

Installation
------------
- Install the module from the Apps menu.

Configuration
-------------
- Go to Settings -> Users & Companies -> Users and open the user.
- On the Access Rights tab, enable the Restrict Journals group.
- Open the Restricted Journals page and select the journals to restrict.

Usage
-----
- Restricted journals are hidden from the Register Payment wizard.
- Payments of restricted journals cannot be created or modified by the user.
- Opening a record that belongs to a restricted journal shows a validation
  error.
- Journals that are not restricted can still be used as usual.
