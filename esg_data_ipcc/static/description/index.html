ESG Data — IPCC EFDB

Seamlessly integrates the direct emission factor import from the IPCC Emission Factor Database (EFDB) into your ESG module. No API key required for this public database.

Key Highlights

Direct Downloads

Download and parse the IPCC EFDB XLS export directly within Odoo. Upserts data straight into your environmental emission factors.

Region Filters

Easily scope down your emission factor imports by selecting specific IPCC regions and compatible countries.

Smart Synchronization

Two syncing modes: "Import New Factors" skips existing data to save time, while "Import & Update" handles modifications to keep libraries fresh.
