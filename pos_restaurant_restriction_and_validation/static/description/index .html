Frequently Asked Questions

How can I restrict employees from deleting order lines or modifying orders in POS?

You can enable these restrictions from POS → Configuration → Settings.

How does manager PIN or password approval work for restricted POS actions?

When a restricted action is attempted, the system displays a PIN entry popup.

Do these restrictions apply to all POS users automatically?

Yes, once the restrictions are enabled in POS settings, they apply to all users operating that POS session.
