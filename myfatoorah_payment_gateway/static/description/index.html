MyFatoorah Payment Gateway

This module allows you to enable the MyFatoorah payment provider on your Odoo system. It supports API token configuration, test/live mode switching, payment journal selection, a confirmation page before payment, and seamless redirection to the MyFatoorah payment portal.

Generate MyFatoorah API Key

Log in to the MyFatoorah Merchant Portal, navigate to API Keys, and click + Add to generate an API key. If you are testing the integration, generate a Sandbox (Test) API Key; for production, generate a Live API Key. The screenshot below shows the Sandbox (Test) API Keys page. Copy the generated key and use it as the API Token when configuring the MyFatoorah payment provider in Odoo.

Payment Provider Form

Enter your MyFatoorah API token and choose test or live mode from the provider form.

Checkout – Pay Now

MyFatoorah appears as a payment option on the eCommerce checkout page.

Confirmation Page

MyFatoorah Payment Portal

The customer enters card details on the MyFatoorah portal and completes the transaction.

Payment Status Page

After a successful transaction the customer is redirected back to Odoo with a payment confirmation.

What is the MyFatoorah Payment Gateway module?

The MyFatoorah module integrates the MyFatoorah payment gateway with Odoo, enabling secure online payments for eCommerce orders and invoices.

Which payment methods are supported?

MyFatoorah supports multiple payment methods including credit/debit cards, Apple Pay, Google Pay, and local bank transfers.

Will payments be automatically confirmed in Odoo?

Yes. Payments are automatically validated and Odoo updates the order or invoice status upon successful payment.

How do I get a test API token for MyFatoorah?

You can obtain a test token by registering on the MyFatoorah developer portal at developer.myfatoorah.com. Enter the token in the provider settings and enable test mode.
