Frequently Asked Questions

What is the purpose of this app?

This app allows you to assign custom alphanumeric names (e.g., "Table-A", "VIP-01", "Balcony-B") to restaurant tables in the POS session and backend, instead of only using default numbers.

Can I set table names using both letters and numbers?

Yes! You can use any custom alphanumeric string to label your tables, giving you more flexibility in mapping your restaurant's layout.

Are the table name updates reflected in real-time?

Absolutely! Any table name modifications made in the backend or within the active POS edit plan view will update and sync across active sessions instantly.

Does this integrate with standard Odoo floor plans?

Yes, the module integrates database tables and floor plan UI components seamlessly with standard Odoo restaurant and POS modules.
