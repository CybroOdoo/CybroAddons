Wishlist Products In Backend
============================
Record All Wishlist Products In Backend

Key Features
------------
* Manage wishlist records from a dedicated backend menu
* Group wishlist by customers
* Group wishlist by products

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.

Supported Editions & Deployment
-------------------------------
* Community Edition
* Enterprise Edition
* Deployed on: Odoo.sh, On-Premise

Frequently Asked Questions
--------------------------
* How to access wishlist products in the backend?
  Navigate to Website > Reporting > Wishlist Products.
