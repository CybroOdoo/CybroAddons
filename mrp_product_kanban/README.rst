Manufacturing Product Kanban
============================

This module displays information about manufacturing orders, work orders, BOMs, unbuild orders, and scrap orders directly in the product kanban view.

Key Features
------------

* Visual overview of manufacturing data directly on product cards in kanban view.
* Quick access to related Manufacturing Orders, Work Orders, and Bill of Materials (BOM).
* View unbuild orders and scrap orders associated with each product.
* Seamless integration with the standard Odoo MRP workflow.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
