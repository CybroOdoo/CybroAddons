Base Machine Repair Management
==============================

Machine Repair Management is an application used to manage machine repairs. It also allows users to submit machine repair requests through the website, and these requests are created in the backend. In addition, it can manage work orders, machine diagnoses and repair teams.

Key Features
------------

* Create Requests from the Website
* Repair Request View in the Portal
* Check Request Status from the Portal
* Management of Diagnosis and Creation of Sales Quotations
* Machine Repair Team to Create Job Order / Work Order
* Add Machine Repair-Related Images
* PDF of Machine Repair Request Report
* Close Machine Repair Requests and Send Closing Email to Customers
* Customer Feedback

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
