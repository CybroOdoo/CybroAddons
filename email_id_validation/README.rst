Email Verification For Partner And Employee
===========================================
This module helps to validate the email of partners and employees.


Key Features
------------

*  Validates Email Addresses
*  Error is Displayed when an Invalid Email is Detected

Installation
------------
Requires Python package ``email_validator``:

.. code-block:: bash

    pip install email-validator

Configuration
-------------
No additional configuration is required.
Note: An internet connection is recommended for deliverability checks.
