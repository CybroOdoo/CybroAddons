Inventory Turnover Analysis Report
==================================

A module to generate the inventory turnover analysis report in PDF, XLSX, list view and graph view.

Key Features
------------

* Multi-Format Reporting
* Customizable Filters
* Interactive Graphical Analysis
* Seamless Data Navigation
* Stock and Turnover Metrics
* Multi-Warehouse and Multi-Company

Installation
------------
This module requires the ``xlsxwriter`` Python library, which is installed with Odoo by default.

Configuration
-------------
No additional configuration is required.
