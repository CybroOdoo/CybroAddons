What is the purpose of this module?

This module allows bulk importing of user data from Excel files into Odoo.

What happens if the imported file contains invalid access rights or user types?

The system will display a validation error and prevent importing incorrect data.

Which file format is supported for importing users?

The module supports Excel file formats for importing user records..
