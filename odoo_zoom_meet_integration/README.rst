Odoo Zoom Meet Integration
==========================

Seamlessly integrates Odoo Calendar with Zoom, allowing users to create, schedule, and join Zoom meetings directly from calendar events.

Key Features
------------

* Create and schedule Zoom meetings directly from Odoo Calendar.
* Automatically generate Zoom meeting link, meeting ID, and passcode.
* Share meeting details with attendees via email invitations.
* Synchronize meeting schedules with Odoo events.

Installation
------------
No external dependencies.

Configuration
-------------
Configure Zoom API credentials (Client ID, Client Secret, Account ID) under Settings / Zoom Meet Configuration.
