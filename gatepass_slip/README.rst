Delivery Gate Pass
==================

This module facilitates the creation of gate pass slips for users, which can be used as a pass to let a vehicle into a facility. The slips allow for the addition of driver and vehicle-related information.

Key Features
------------

* Generate and print Gate Pass slips directly from Delivery Orders (Stock Picking).
* Record driver and vehicle details such as Vehicle Number, Driver Name, Contact Number, and Corresponding Company.
* Option to include or exclude product order lines in the gate pass slip.
* Custom paper format tailored for gate pass tickets.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
