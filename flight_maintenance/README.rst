Flight Maintenance
==================
* This module provides aircraft maintenance management for the Flight
  Operations suite. It enables aircraft airworthiness validation,
  maintenance request integration with Odoo Maintenance, aircraft metric
  tracking, maintenance scheduling based on operational metrics, and
  maintenance status monitoring. It also includes automatic maintenance
  checks during flight operations, aircraft availability control, and
  maintenance history tracking to ensure safe and compliant flight
  operations.
