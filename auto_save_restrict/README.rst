Auto Save Restrict
==================

The Auto Save Restrict module restricts automatic saving behavior across all models in Odoo 20. When navigating away from modified records, a confirmation dialog prompts the user to save changes, stay on the page, or discard unsaved modifications.

Key Features
------------

* Restricts automatic saving in form and editable list views across all models.
* Confirmation popup dialog to save or discard unsaved changes when leaving views.
* Prevents auto-saving on browser tab switch or window minimize.
* Restricts auto-saving when clicking outside editable list cells.
* Confirms save before triggering smart buttons or action buttons on modified records.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
