Answers Before You Install

Q
What does the Auto Save Restrict module do?
A
The Auto Save Restrict module restricts Odoo's default automatic background saving, ensuring that record changes in form and editable list views are saved only when explicitly confirmed by the user.
 
Q
How does the confirmation dialog work?
A
Whenever a user modifies data in a form or editable list view and attempts to navigate away, the module displays a standard dialog with options to Save, Discard, or Stay on the current page.
 
Q
Why should I install this module in Odoo 20?
A
By default, Odoo saves changes automatically in the background, which can lead to accidental record overwrites. This module gives users complete control over their data by preventing automatic saving.
