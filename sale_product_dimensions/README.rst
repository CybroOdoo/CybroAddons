Sale Product Dimensions
=======================

This module helps to add product dimensions to sales, purchase, invoice and manufacturing.

Key Features
------------

* Length (mm), width (mm) and area (m²) on sales, purchase, invoice and manufacturing
* Area-based unit price (area × price per m²) on sales and purchase lines
* Dimensions carried from the sales order to the invoice
* Dimensions printed on the Sales, Purchase, Invoice and Manufacturing PDFs

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
