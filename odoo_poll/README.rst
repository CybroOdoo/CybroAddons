Odoo Poll
=========
This module allows users to create and manage interactive polls directly inside Discuss channels and chatter.

Key Features
------------

* Poll Creation in Discuss
* Single & Multiple Choice Support
* Live Voting & Instant Results
* Close & Reopen Polls

Installation
------------
No external dependencies.

Configuration
-------------
* No configuration is required
