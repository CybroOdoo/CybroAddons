Restrict POS Refund with Password
==================================
This module restricts Point of Sale refunds by requiring an authorization password before issuing any refund.

Key Features
------------

* Secure refund authorization popup.
* Global refund security password across all Point of Sale shops.
* Individual POS-specific refund passwords.
* Server-side password verification for enhanced security.

Installation
------------
No external dependencies required.

Configuration
-------------
* Configure a global refund password in Point of Sale General Settings, or
* Set a POS-specific refund password under Point of Sale Configuration.
