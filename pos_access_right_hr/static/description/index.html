Frequently Asked Questions

What does this module do in the POS system?
This module gives you fine-grained control over what POS buttons and features are accessible to specific users.
Can I assign different access levels to different POS users?
Yes, access rights and button restrictions can be configured per user, giving you full flexibility in managing roles.
Does this module support multi-user sessions?
Absolutely. Multiple users can operate under one POS session with their permissions enforced individually.
Can I disable specific POS buttons like Payment or Customer?
Yes, you can disable key interface buttons like Payment, Customer, Numpad, Discount, and more as per role.
Will the module interfere with default POS behavior?
No. It enhances access control without disrupting the POS flow or breaking standard features.
