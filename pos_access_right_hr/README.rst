POS Access Right
================
To enable or disable POS features depending on the access rights granted to the cashiers


Configuration
=============
* Navigate to **Point of Sale -> Configuration -> Settings**.
* Under Point of Sale, enable **Log in with Employees** (Multi Employees per Session) and choose the allowed cashiers/employees.
* Navigate to **Employees -> Employees**, open the cashier's employee form, and select the **Access Right** tab.
* Configure the desired POS restrictions for the employee:

  - **POS-Disable Payment**: Disables the payment button on the POS screen.
  - **POS-Disable Customer**: Disables customer selection on the POS screen.
  - **POS-Disable Plus-Minus**: Disables the +/- button on the POS keypad.
  - **POS-Disable Numpad**: Disables the number pad on the POS keypad.
  - **POS-Disable Qty**: Disables changing orderline quantity on POS.
  - **POS-Disable Discount**: Disables applying discounts on POS.
  - **POS-Disable Price**: Disables manual price changes on POS.
  - **POS-Disable Remove Button**: Disables the backspace / delete button on POS.
