Product Management System
=========================

This module enables powerful batch and mass operations for managing product templates efficiently.

Key Features
------------
* Bulk update list prices and cost prices for multiple products.
* Batch assign or modify product categories and website categories.
* Perform bulk publishing, unpublishing, and archiving operations.
* Manage vendors, taxes, routes, and lead times in batch.
* Manage product attributes, alternatives, accessories, and optional products in bulk.

Configuration
-------------
No additional configuration is required.
