Sale Order Versions
===================

This module helps to create multiple versions of a sale order and manage quotation revisions effectively.

Key Features
------------
* Create multiple versions/revisions of sent quotations
* Track quotation revisions with a dynamic smart button counter
* Promote confirmed versions into the main sale order and automatically cancel other versions
* Maintain complete version history without cluttering the main quotation list

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
