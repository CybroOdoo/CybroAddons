Users Restriction For Project And Task
======================================

This module is designed to specify and control which individuals or roles within an organization have permission to view or interact with project and task records.

Key Features
------------

* **User-Specific Project & Task Access**: Restrict access to specific projects and tasks based on designated allowed users.
* **Dedicated Security Group**: Includes the "View Limited Projects and Tasks" group to selectively apply restrictions to specific users.
* **Selective Access Assignment**: Assign authorized users directly via the "Access Limited Users" field on Project and Task forms.
* **Default Open Visibility**: Projects and tasks with no assigned limited users remain visible and accessible to all users.
* **Admin-Only Configuration**: Only system administrators can edit the "Access Limited Users" field, ensuring access controls cannot be altered by regular users.
* **Enhanced Data Privacy**: Maintain confidentiality for sensitive projects and tasks while ensuring standard collaboration workflows remain uninterrupted.

Installation
------------
No external dependencies.

Configuration
-------------
1. Navigate to **Settings > Users & Companies > Users**.
2. Select a user and enable the **View Limited Projects and Tasks** access right.
