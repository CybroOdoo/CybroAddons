OpenAI Odoo Base
================
This module adds a field in the Odoo General Settings to store your OpenAI API key.

Key Features
------------
* Configure your OpenAI API key directly within Odoo General Settings.
* Only administrators can view or change the key, and it is masked on screen.
* Other modules can read the stored key instead of asking for it again.

Installation
------------
This module has no external dependencies.

Configuration
-------------
* Go to **Settings > General Settings**.
* Under **Integrations**, locate the **OpenAI** section.
* Enter your OpenAI API key and click **Save**.
