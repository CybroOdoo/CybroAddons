Remove Order Line In POS
========================

Remove order lines from the Point of Sale cart with a single click, or clear
the whole cart at once with the Clear All button.

Key Features
------------

* A delete button on every line of the cart removes that line
* A Clear All button next to Note removes every line of the current order
* Clear All asks for confirmation before removing the lines
* Removing a combo item removes the whole combo, like the numpad does
* The delete buttons only appear in the cart, not on receipts, the orders list
  or the customer display
* Works with both Community and Enterprise editions

Installation
------------
No external dependencies. The module depends only on Point of Sale
(``point_of_sale``).

Configuration
-------------
No additional configuration is required.
