Overview

This module helps to synchronize your contact list, campaign, templates between Odoo and MailChimp.

This module uses an external python dependency 'mailchimp-marketing'. Before installing the module, install the required python package first. The required python package can be installed using the following command: 

pip install mailchimp-marketing

Features

Available in Odoo 16.0 Community & Enterprise
Import Lists/Audiences from MailChimp to Odoo
Import Member/contacts from MailChimp to Odoo
Import Templates from MailChimp to Odoo
Import Campaigns from MailChimp to Odoo
Export Lists/Audiences from Odoo to MailChimp
Export Member/contacts from Odoo to MailChimp

Mailchimp Integration with Odoo

Create a Mailchimp Developer account
Go to https://mailchimp.com/developer/
Click Sign Up (or Sign In if you already have an Intuit account).

Click on "API Keys"

Click on "Create A Key"

Click on "Copy To Clipboard"

Click on the Mailchimp menu for configuring Mailchimp Account.

Click on the sub menu Mailchimp Accounts.

Add the API Key from Mailchimp Account

Add the API Key and click on the CONNECT button for connecting with Mailchimp Account.

Click on the Operations menu for Importing Exporting records.

There is the wizard including contents for import and export.

Select the Mailchimp Account and List/Audience then click on the IMPORT button for importing the List/Audience to Odoo.

Imported the List/Audience from Mailchimp to the Mailing List of Odoo.

Select the template option for importing templates from Mailchimp to Odoo.

Imported Templates from Mailchimp to Odoo in the Templates menu.

Select Campaign option for importing campaign from Mailchimp to Odoo.

Imported Campaigns from Mailchimp to Odoo.

Select Export List/Audience option for exporting List and members from Odoo to Mailchimp.

Exported List/Audience from Odoo to Mailchimp.

Select the template from mailing and add the template in to the Mail body.

Select Auto sync list for importing lists and members automatically.
