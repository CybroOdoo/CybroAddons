Dynamic Report Operations
=========================
This module enables users to easily perform multiple report operations across records in Sales, Purchase, Inventory, and Invoicing.

Key Features
------------

* Define various actions for PDF reports easily through a unified wizard interface.
* Print, Download, Open, and Share by Email options for all generated documents.
* Seamlessly available across Sales, Purchase, Inventory (Stock Pickings), and Invoicing.
* Dedicated systray icon for fast access to report action wizards from any view.

Installation
------------
* Ensure standard Odoo PDF report rendering dependencies are installed in the Python environment.

Configuration
-------------
No additional configuration is required.
