Theme Propelle
==============
A website theme for a real estate brokerage: a floating glass header, a hero
with a Buy / Rent search panel, listings to buy and rent, new developments,
valuation requests and a four step request of viewings sent to CRM as leads.

Configuration
=============
* Install the theme from Website > Configuration > Settings > Choose a Theme.
  The menu, the header, the footer, the logo and the pages (Home, About, Sell,
  Contact) are set up automatically.
* The Real Estate menu (Website > Configuration > Real Estate) holds the
  listings, the new developments and the cities. Publish a listing or a project to show it on the
  Buy, Rent and Projects pages. The six cities are loaded with the theme; sample
  listings and projects are demo data and are only loaded in a demo database.
* Viewing and valuation requests made on the Booking page create a lead (CRM)
  with the property or address, the preferred day and time (9 to 5 on weekdays,
  10 to 3 on Saturday, closed on Sunday) and the contact details; an agent
  confirms the time with the visitor.
* The Buy and Rent pages show 12 listings per page (standard pager); the
  filters and the sorting are applied by the server and kept in the URL.
* The contact and project registration forms and the listing alert form create
  leads (CRM) too. The newsletter subscribes to the default
  mailing list.
* The Propelle blocks are in the Propelle group of the website builder.
* The photographs come from Unsplash and the text is a sample: replace them
  from the website builder.
