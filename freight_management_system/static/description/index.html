FREQUENT QUESTIONS

Q
Is this module compatible with Odoo 20?
A
Yes. This module is built for Odoo 20 and tested on the Community edition. It uses only standard Odoo modules.
 
Q
Do I need any additional configuration after installation?
A
Create the master data (ports, pricing lists, route operations, services and containers) from the Configuration menu and assign the Freight User or Freight Manager group to your users.
 
Q
Can I get support if something doesn't work as expected?

Yes. Contact Cybrosys Technologies at odoo@cybrosys.com or via WhatsApp for dedicated support within the warranty window.
