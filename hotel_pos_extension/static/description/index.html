Add Room button in the Odoo POS

The "Add Room" button in Odoo POS allows users to quickly select and assign a room while creating an order.

Choosing the Pay at Checkout Option

Can select the “Pay at Checkout” option if you prefer to complete the payment during the checkout process.

Selecting a Room for Placing an Order in Odoo

After selecting a room and adding a customer, the order is created and displayed with the selected room and customer name in the POS screen.

Added Customers and Placed Orders in Odoo POS

While placing an order in Odoo, clicking the button opens a popup displaying all available rooms from the backend. Users can easily select the required room.

Pay at Checkout Option in Odoo POS

The "Pay at Checkout" option allows customers to complete the payment at checkout time. Users can select this option and proceed with payment when finalizing the order.

Popup Message for Invoice Selection in Checkout Payment

If the invoice option is not selected while choosing checkout payment, a popup message will appear to notify the user to enable invoicing before proceeding.

Associate POS Order with Room Booking

The POS order can be linked with the selected room booking, allowing users to manage and track orders based on room allocation.

POS Invoice Payment Status

The invoice payment status is shown as "Not Paid" until the payment is completed.

Computing Bill on Checkout

Clicking the checkout button opens a wizard to compute the bill and generate a printable PDF report.

Separate View for Sale Orders and POS Orders

Sale orders and POS orders can be viewed separately, allowing users to manage and track them independently.

Computed Bill Invoice

The computed bill is generated as an invoice, providing a clear summary of all charges for the order.

Separate POS Order Bill and Sale Order Bill

POS order bills and sale order bills are generated separately, allowing clear and independent billing for each type of order.

Frequently Asked Questions

Can I link POS orders with hotel room reservations?

Yes. POS orders can be directly linked to booked hotel rooms for seamless service management.

Can I select a room while creating a POS order?

Yes. You can select or add a room using the Add Room button in the POS screen.
