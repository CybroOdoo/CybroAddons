# Changelog

All notable changes to the `custom_robots_txt` module will be documented in this file.

## [20.0.1.0.0] - November 2026

### Added
- Initial release for Odoo 20 Website Robots.txt.
- Three robots.txt indexing modes: Allow All, Disallow All, and Custom.
- Dynamic pre-population of robots.txt directives in the wizard.
- Persistence of selected mode and custom rules on the active website record.
