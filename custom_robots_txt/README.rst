Website Robots.txt
==================
This module enables users to customize their robots.txt file directly from
the Odoo 20 Website backend. It provides three indexing modes — Allow All,
Disallow All, and Custom — giving full control over how search engine crawlers
interact with the website.

Key Features
------------

* Three robots.txt modes: Allow All, Disallow All, and Custom.
* Instantly pre-populates the robots.txt content when a mode is selected.
* Custom mode allows free-form editing of robot directives.
* Persists the selected mode and custom content to the website record.
* Includes a helper link to Google's official robots.txt documentation.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
