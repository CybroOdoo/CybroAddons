Advanced Chatter View
=====================
Advanced Chatter View enhances the standard Odoo chatter interface by
providing quick-action icons and collapsible panels for messages, log notes,
and scheduled activities.

Key Features
------------

* Available in Odoo Community and Enterprise
* Show and Hide Chatter
* Easy to use and manage

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
