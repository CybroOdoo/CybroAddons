Website Custom Contact Us
=========================
This module allows you to configure the visibility of company details on the website
contact us page.

Key Features
------------
* **Company Details Control**: Toggle visibility of company name, address, phone number, email address, website URL, and Tax/VAT ID on the website's Contact Us page.
* **Flexible Address Formatting**: Choose between single-line and multi-line address display layouts.
* **Icon & Flag Options**: Control the visibility of address marker icons, phone icons, and the country flag image.
* **Social Media Link Management**: Show or hide individual social media profile links (Facebook, Twitter, LinkedIn, Instagram, and GitHub) along with custom profile URLs.
* **Centralized Configuration**: Easily configure all visibility settings and social links directly within the Website form settings in the backend.

Installation
------------
No external dependencies.

Configuration
-------------
1. Navigate to Website -> Configuration -> Settings or open the Website record in Website -> Configuration -> Websites.
2. Open the Contact Us tab on the Website form.
3. Configure Company Data Visibility, Address/Phone Options, and Social Links as desired.
