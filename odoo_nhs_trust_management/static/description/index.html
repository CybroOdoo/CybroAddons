Frequently Asked Questions

Does the module validate ODS codes for both NHS England and NHS Scotland?

Yes. The system automatically detects the selected health system and runs validation rules specific to each region (e.g., alphanumeric format checks for England, and specific code prefixes for Scotland Health Boards) while enforcing global database uniqueness to prevent duplicate records.

How does the module handle geographic access control for regional users?

Through field-based record rules. Section 1.2 (Geographic Security) and Section 5.13 (res.users extension) specify that standard users (NHS Trust User group) are assigned allowed Integrated Care Boards (ICBs) for England and allowed Health Boards for Scotland. Record rules automatically filter views so they can only see trusts in their assigned region, while Managers and Administrators bypass this restriction to see all trusts globally.

Can a user change a Trust's state directly on the record?

No. Users cannot directly edit the Trust state field from the form view. All state changes must be performed through the State Change Wizard, which validates workflow rules and requires a mandatory justification before applying the transition.
