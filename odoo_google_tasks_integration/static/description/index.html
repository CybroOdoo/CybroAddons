Frequently Asked Questions

Is this module compatible only with the Odoo 19 Enterprise edition?

No, this module is compatible with both the Enterprise and Community editions of Odoo 19.

How do I install the Google Task Integration module?

To install the module, navigate to the Apps menu in Odoo, search for "Sync Google Task With Project Task" and click the "Install" button.

How do I configure the Google Tasks Integration module?

After installing the module, navigate to Project > Configuration > Google Task Credential . Provide the necessary details, including the Client ID, Client Secret, and Authorized Redirect URIs, to enable integration with Google Tasks.
