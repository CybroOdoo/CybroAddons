Frequently Asked Questions

Can I search using multiple conditions at the same time?

Yes, the module supports multiple search queries, enabling users to apply different conditions across various fields simultaneously for more precise results.

Does the module support date range filtering?

Yes, fields of type date and datetime can be filtered using custom date ranges, making it easier to locate records within specific time periods.

What types of fields are supported in quick search?

The module supports searching across multiple field types, including text, date/datetime, many2one (relational fields), and numeric fields like integer and float.
