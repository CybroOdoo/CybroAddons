Receipt

Scan Barcodes for Receipts

To create a new receipt operation, scan the operation barcode of Receipts (WH-RECEIPTS) using your barcode scanner.

View Receipts

To view receipts that are in the ready state, navigate to View Receipts.

Scan Product / Serial or Lot Number

Start by scanning the product's barcode or serial/lot number. The stock move will automatically update the product's quantity. To adjust the quantity, scan the product's barcode again. If the scanned product is not listed in the operation, it will be added as a new stock move.

Scan Destination Location

To assign a destination location for the scanned products, scan the destination location barcode. The updated location will reflect immediately. By default, it is set to WH/Stock or another predefined location.

Finalize the Receipt

After scanning the destination location, you can: Add more products to the receipt. Finalize the receipt by clicking the Validate button. Once validated, the receipt is confirmed, and the picking process is marked complete.

Delivery

Scan Barcodes for Delivery

To create a new delivery operation, scan the operation barcode of Delivery (WH-DELIVERY) using your barcode scanner.

View Delivery Orders.

To view delivery orders that are in the ready state, navigate to View Delivery Orders.

Scan Product / Serial or Lot Number

Start by scanning the product's barcode or serial/lot number. The system will automatically update the product's quantity and add the product to the delivery order if it’s not already listed. For more details on configuring or scanning serial/lot numbers, refer to the "Scan Barcodes for Receipts" section.

Apply Source Location

Assign a source location to the delivery order by scanning the source location barcode. By default, the location is set to WH/Stock (or another specified location). Scanning the barcode will update the source location, which will then be displayed on the screen.

Finalizing the Process

You can either add more products to the delivery order or finalize it by clicking the "Validate" button. Once validated, the delivery is confirmed, and the picking process is marked as complete.

Internal Transfers

Scan Barcodes for Internal Transfers

To create a new internal transfers operation, scan the Internal Transfers barcode using your barcode scanner.

View Internal Transfers

To view internal transfers that are in the ready state, navigate to View DeView Internal Transfers.

Scan Product / Serial or Lot Number

To assign a source location, scan the source location barcode using the scanner. If no source location is scanned, the default location will be used. Once scanned, the source location will be updated and displayed on the screen.

Apply Source Location

Assign a source location to the delivery order by scanning the source location barcode. By default, the location is set to WH/Stock (or another specified location). Scanning the barcode will update the source location, which will then be displayed on the screen.

Finalizing the Process

You can either add more products to the internal transfer order or finalize it by clicking the "Validate" button. Once validated, the internal transfer is confirmed, and the picking process is marked as complete.

Resupply Subcontractor

Scan Barcodes for Resupply Subcontractor

To create a new resupply subcontractor operation, scan the operation barcode of Delivery (WH-RESUPPLY) using your barcode scanner.

View Resupply Subcontractor.

To view resupply subcontractor orders that are in the ready state, navigate to Resupply Subcontractor Orders.

Scan Product / Serial or Lot Number

Start by scanning the product's barcode or serial/lot number.

Apply Source Location

Assign a source location to the resupply subcontractor order by scanning the source location barcode.

Finalizing the Process

You can either add more products to the resupply subcontractor order or finalize it by clicking the "Validate" button. Once validated, the delivery is confirmed, and the picking process is marked as complete.

Inventory Adjustment

Scan Barcodes for Inventory Adjustment

Open the Inventory Adjustment tab to proceed.

View Inventory Adjustment

Users can utilize a barcode scanner in this view to add products by scanning their barcodes or lot/serial no and adjust stock quantities by rescanning the same barcode. by scanning it again to adjust the stock levels.

Scan Location then Scan Products

Scan the location first, then the products stored there, or scan a new product to assign it to the current location. The instructions make the next step easy to follow.

Manual Adjust Quantity

User can also adjust the counted quantity manually

Finalizing the Process

select the products you wish to adjust. The selected items will be visually highlighted in a darker color to indicate they have been chosen. This helps ensure accuracy before proceeding with the adjustment process. Click the APPLY button to confirm the inventory adjustment.

Batch Transfer

Scan Barcodes for Batch Transfer

Open the Batch Transfer tab to proceed.

View Batch Transfer

Users can utilize a barcode scanner in this view to add operations by scanning their barcodes

Manual Adjust

User can also edit or delete the operation from batch

Finalizing the Process

select the operation you wish to batch. Click the Validate button to confirm the Batch Transfer.
