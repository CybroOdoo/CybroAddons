LocationLink POS
================

The LocationLink POS module helps to enhance the management of products within the POS system by showing only the products stocked in a selected inventory location.

Key Features
------------

* Display only the POS products that have stock in the selected location.
* Improve stock visibility and picking efficiency for POS cashiers.

Installation
------------
No external dependencies.

Configuration
-------------
Go to Point of Sale > Configuration > Settings, open the Inventory section, and select the Stock Location.
