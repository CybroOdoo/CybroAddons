Advanced Email Configurator
===========================
* Automatic setup of Outgoing and Incoming Mail Servers.

Key Features
------------
* Outgoing and incoming mail servers are configured automatically from Preferences.
* Retrieve emails automatically every minute.


Installation
------------
No external dependencies.

Configuration
-------------
Enable *Auto Generate Mail Server* in the general settings to make the email, app password and provider required on the user form. Administrators manage the providers under Settings > Technical.
