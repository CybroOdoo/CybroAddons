Frequently Asked Questions

Where does my request data go?
When you click Submit, the details you entered — name, email, phone, subject, description and attachments — are sent over HTTPS to the Cybrosys support server, where a ticket is created. Nothing is sent until you click.
Do I need to configure anything after installing?
No. The support server URL is preset. If you ever need to change it, edit the system parameter cybrosys_support_client.endpoint_url under Settings → Technical → System Parameters.
Can I attach files? Are there limits?
Yes — attach multiple files such as logs and screenshots. The support server accepts up to 5 files, 10 MB each; oversized uploads are reported clearly so you can retry.
What does the WhatsApp button do?
It opens a WhatsApp chat with the Cybrosys support number, pre-filled with your name, email and description — handy when you prefer a quick conversation.
Which Odoo editions and versions are supported?
Odoo 19, both Community and Enterprise, on On-Premise and Odoo.sh deployments.
