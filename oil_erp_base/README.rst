Oil & Gas Core
==============
* Oil & Gas Core is a centralized solution designed to manage upstream, midstream, and downstream operations efficiently within Odoo.
* It is an open-source module developed to extend Odoo with industry-specific functionalities tailored for oil and gas businesses.
* Oil & Gas Core provides a set of integrated modules covering operations, ESG tracking, sales, purchase, and inventory management.
* The Core module acts as a unified layer that connects and standardizes all individual Oil ERP modules into a single system.
* It follows a selective installation approach, allowing users to enable additional features and modules based on business requirements.

=============
