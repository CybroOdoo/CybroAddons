What does this module manage?
It manages the base layer of the Oil ERP suite, including settings, dashboard access, module activation, shared menus, and integration controls.
Which operational areas can be enabled?
The settings page is grouped into E&P Operations, Pipeline & Transport, Refinery Operations, and Integrations so each area can be activated from one place.
How do live dashboard feeds work?
Real-time energy benchmarks can be enabled directly in settings, while live news requires the news integration to be enabled with a valid GNews API key.
