Lunch Orders - PDF
==================
This module allows users to generate and print custom PDF reports for lunch orders with specific filters.

Key Features
------------
* Filter lunch orders by date period (start date and end date).
* Filter by users, vendors (suppliers), locations, and companies.
* Filter by specific products or product categories.
* Group orders in the PDF report by user, vendor, product, company, or status.

Installation
------------
No external dependencies.

Configuration
-------------
The user should be added to the security group: Administrator (Human Resources / Lunch) in order to get access to the report menu.
