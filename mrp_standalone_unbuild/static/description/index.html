Frequently Asked Questions

Can I create an Unbuild Order without selecting a Manufacturing Order?

Yes, the Yes. This app makes the Manufacturing Order field optional, allowing standalone unbuild operations.

Do I still need to select a product and bill of materials?

Yes. You should select the product and related Bill of Materials so Odoo can identify the components involved in the unbuild process.

Can I manually add components to the unbuild order?

Yes. The app adds a Components tab where you can manually define component products, quantities, units of measure, and lot or serial numbers.

Does this app affect the standard Odoo unbuild process?

No. If a Manufacturing Order is selected, the standard Odoo unbuild flow can still be used.

What happens when no Manufacturing Order is selected?

The unbuild order works as a standalone operation and uses the selected product, Bill of Materials, and component lines to process stock movements.
