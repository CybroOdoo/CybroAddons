Magic Note
==========
This module aims to automatically update the background color of notes/tasks
in the To-do kanban view based on configured deadline date intervals.

Installation
------------
- Install our custom addon

Configuration
-------------
After installing this module, configure colors and intervals:

1. Under **Project > Configuration > Settings**, configure:
   * Default note color when no deadline is set
   * Color applied when the task crosses the deadline date
   * Fallback color when the deadline does not match any date interval

2. Under **Project > Configuration > Color Interval**, create intervals:
   * Set a name/criteria for the interval
   * Select a color from predefined colors
   * Set start date and end date for the interval

Features
--------
* Automatically updates note background color in To-do kanban view
* Configure date intervals with start date, end date, and color
* Set default color for notes without a deadline
* Set alert color for notes that passed their deadline
* Set fallback color for notes outside configured intervals
