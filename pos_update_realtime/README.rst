POS Realtime Update
===================
* The POS Realtime Update module enables real-time product updates across all active POS sessions.
* Any change made to a product is instantly synchronized without restarting or refreshing POS sessions.
* Ensures consistent and up-to-date product information across all POS terminals.


Key Features
------------

* Realtime Product Updates
* Realtime Product Addition

Installation
------------
* No external dependencies.

Configuration:
--------------
No additional external application is required.

Before installing this module:
 * Make sure the Point of Sale module is installed.

After installing this module:
 * Open your POS configuration.
 * Start a POS session.
 * Any product updates (such as price or name) will be reflected in all active sessions in real time.
