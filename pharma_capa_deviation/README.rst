Pharmaceutical ERP — CAPA & Deviations
======================================
Quality deviation and Corrective & Preventive Action (CAPA) management for the Pharmaceutical ERP suite.

Key Features
------------
* Deviation records classified by phase (Manufacturing, QC, Packaging) and severity (Critical, Major, Minor).
* Root-cause categorisation across Human, Equipment, Material, Method and Environment.
* Corrective and Preventive Action (CAPA) records linked to the originating deviation.
* CAPA lifecycle from Open through In Progress and Verified to Closed.
* Deviations raised directly from BMR steps, IPQC results and QC test orders.
* Full chatter tracking and activity scheduling on every deviation and CAPA.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
