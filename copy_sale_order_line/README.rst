Copy Sale Order Line
====================
Easily copy sale order lines with a single click

Key Features
------------
* Duplicate any quotation or sales order line with a single button click directly from the document order lines tab.
* Automatically preserves product, description, quantity, unit price, discounts, and taxes while maintaining proper sequence ordering.
* Fully integrated into Quotations and Sales Orders in Odoo 20 Sales.

Installation
------------
No external dependencies.

Configuration
-------------
No additional configuration is required.
